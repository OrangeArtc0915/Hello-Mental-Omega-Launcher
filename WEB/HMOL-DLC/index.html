HMOL DLC
插件包与扩展内容

官方 DLC 包合集，包含程序拓展、主题包、工具等追加内容，自由安装与管理。 DLC 分普通版（含个性化设置 / 美化支持）和 Wine 版两种格式，按需选择。

了解格式 下载 DLC
DLC Package

DLC 分两种格式，对应 HMOL 普通版与 Wine 版，请根据你的启动器版本选择

DLC 配置格式

两种格式的配置文件结构，照着写即可制作自己的 DLC。

HMOL 普通版 DLC (DLC.json)

支持个性化设置 / QSS 美化

{ "name": "示例主题包", "version": "1.0.0", "description": "展示主题包的基本结构。包含自定义QSS样式。", "author": "YourName", "contact": "qq:123456789", "main": "bin/example.exe", "type": "美化", "has_qss": true, "qss_file": "theme/style.qss" }

HMOL Wine 版 DLC (DLC-wine.json)

不含个性化设置，仅核心扩展功能

{ "name": "Hello World 示例", "version": "v1.0.0", "description": "一个 DLC 示例项目，展示 DLC 的基本结构。", "author": "制作人：你的名字", "contact": "QQ群：1034243331", "main": "HelloWorld.bat" }

字段说明

name — DLC 显示名称

version — 版本号

description — 简要描述

author — 作者

contact — 联系方式

main — DLC 主入口文件（相对路径）

has_qss / qss_file — 仅普通版，是否包含 QSS 样式文件

type — 仅普通版，分类标签（如"美化""工具"）
