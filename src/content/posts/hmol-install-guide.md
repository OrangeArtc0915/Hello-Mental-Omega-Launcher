# HMOL 安装与初始化指南

> [!NOTE]
> 本文对应**当前版本**：C# / .NET 8 版 `v1.0.0`，以自包含压缩包形式发行。
> 界面、目录与操作步骤均以当前版本为准。

## 环境要求

| 项目 | 要求 |
|------|---------|
| 操作系统 | Windows 10 1809+ / Windows 11（仅 64 位 x64） |
| 运行时 | **无需安装** —— .NET 8 运行时已打进单文件 `HMOL.exe` |
| 磁盘 | 含 `runtime\` 组网组件，建议预留 1 GB 以上 |
| 权限 | 普通权限即可（双击不弹 UAC）；安装 TAP 虚拟网卡等少数操作会单独提权 |
| 其他 | 无需安装任何额外运行库或框架 |

## 安装步骤

### 第一步：下载发行包

从官方渠道下载最新版发行包，文件名形如 `HMOL-v1.0.0-win-x64.zip`：

- **GitHub Releases**：推荐海外用户
- **Gitee Releases**：推荐国内用户

### 第二步：完整解压

把压缩包**整体解压**到一个可写目录（例如 `D:\HMOL\`）。

> [!WARNING]
> 不要只把 `HMOL.exe` 单独拖出来。组网组件（EasyTier / n2n / TAP 驱动等第三方二进制）与 7-Zip 不内嵌进 exe，而是随包放在 `runtime\` 目录里；少了它，联机功能与 `.7z` 导出都不可用。

### 第三步：双击运行

双击目录内的 `HMOL.exe` 启动。程序按普通权限运行，双击**不会弹 UAC**；未签名程序被 SmartScreen 拦下时选「仍要运行」。

程序是**单实例**的：已经有一个 HMOL 在运行时，再次双击只会提示并退出，请在任务栏或系统托盘里打开已运行的窗口。

### 第四步：首次启动

启动后按左侧导航熟悉六个页面：**主页 / 游戏实例 / 包管理 / 联机 / 运行日志 / 设置**（「关于」是独立窗口）。

- 设置、实例、资源包与日志都保存在**启动器目录内的 `Data\`** 下（可用环境变量 `HMOL_DATA` 重定向）；卸载时直接删除整个目录即可。
- 想让程序开机自启，可在「设置 → 开机自启」里开启；自启拉起时只驻留系统托盘、不弹主窗口，点托盘图标才会打开界面。

### 第五步：备份原版游戏文件

打开「游戏实例」页面，点「备份原版游戏」，选择原版游戏根目录并等待完成（视机器性能约 1~3 分钟）。原版备份固定放在 `backup\MO`，是后面「选择性卸载 / 全量恢复」的依据。

### 第六步：添加游戏实例

在「游戏实例」页新建实例，游戏目录指向心灵终结的安装根目录（目录里应有 `MentalOmegaClient.exe`，或存在 `Mental_Omega` 子目录）。程序不会全盘扫描自动找游戏路径，需要你手动指定。

### 第七步：安装资源包

1. 进入「包管理」页。
2. 点「导入包」选择文件，或点「打开包目录」把资源包（`.zip` / `.7z` / `.rar` / 单个 `.map`）放进对应分类目录。
3. 确认当前实例后点「安装」。同名文件会先备份为 `.bak-<时间戳>`，安装过程可取消、失败会自动回滚。

> [!TIP]
> 「包管理」按**四类包**组织：INI / 地图 / 任务 / 插件。每类只认自己的目录与扩展名。

## 常见安装问题

- **杀毒误报 / 被 SmartScreen 拦截**：把 HMOL 目录加入白名单，或临时关闭实时保护；未签名程序需选「仍要运行」。
- **提示缺少 DLL、或要求安装运行库**：不需要。发行包是自包含单文件 exe，自带 .NET 8 运行时；出现这类提示通常是**没有完整解压**（`runtime\` 与 `HMOL.exe` 必须在一起）。
- **联机功能不可用**：确认解压时保留了 `runtime\`（含 `easytier\`、`n2n\`、`tap\` 等），缺这个目录时联机页会明确提示重新解压完整发行包。
- **游戏目录无效**：确保目录下存在 `MentalOmegaClient.exe`（或 `Mental_Omega` 子目录）。
- **需要看日志**：所有运行日志在 `Data\Log\` 下（每次启动一个文件），可在「运行日志」页查看并导出 TXT / CSV。
