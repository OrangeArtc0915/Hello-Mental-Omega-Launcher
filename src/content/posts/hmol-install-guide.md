# HMOL标准版 安装与初始化指南

## 环境要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Windows 7 SP1 (64位) | Windows 10/11 (64位) |
| 内存 | 4 GB | 8 GB+ |
| 磁盘 | 200 MB | 500 MB+ SSD |
| 运行库 | VC++ 2015+ | 完整运行库合集 |

## 安装步骤

### 第一步：下载

从以下渠道下载最新版 HMOL.exe：

- Github Releases：推荐海外用户
- Gitee Releases：推荐国内用户

### 第二步：放置文件

将 `HMOL.exe` 放到**游戏根目录**（和 `gamemd.exe` 同级）：

```
红色警戒2/
├── gamemd.exe           ← 游戏主程序
├── HMOL.exe              ← 启动器（放这里）
├── ra2md.exe
└── ...
```

### 第三步：首次启动

1. 右键 HMOL.exe → **以管理员身份运行**
2. 首次启动会自动注册账号（离线模式无需）
3. 按提示完成运行环境安装

### 第四步：配置游戏路径

如果 HMOL 不在游戏根目录，打开设置页面，手动指定游戏路径。设置完成后点击「检测游戏文件」确认配置正确。

### 第五步：安装插件包

1. 访问笨蛋广场 → 游戏资源下载
2. 下载你需要的插件包
3. 解压到 `DLC` 目录
4. 重启 HMOL 即可在设置页看到已安装的插件

## 常见安装问题

- **杀毒误报**：将 HMOL 目录加入白名单，或临时关闭实时保护
- **运行库缺失**：笨蛋广场 → 运行环境 → 一键安装
- **路径不存在**：确保游戏根目录下有 `gamemd.exe` 和 `ra2md.exe`
