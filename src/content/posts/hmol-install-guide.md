# HMOL标准版 安装与初始化指南

## 环境要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Windows 10/11 (64位) | Windows 10/11 (64位) |
| 内存 | 4 GB | 8 GB+ |
| 磁盘 | 200 MB | 500 MB+ SSD |
| 运行库 | VC++ 2015+ | 完整运行库合集 |

## 安装步骤

### 第一步：下载

从以下渠道下载最新版 HMOL.exe：

- Github Releases：推荐海外用户
- Gitee Releases：推荐国内用户

### 第二步：安装

1. 左键双击 HMOL.exe 
2. 按提示完成安装

### 第三步：首次启动

1. 右键 HMOL.exe → **以管理员身份运行**
2. 首次启动会自动注册账号（离线模式无需）
3. 按提示完成运行环境安装

### 第四步：备份原版游戏文件

打开实例管理页面，点击「备份原版」，找到原版游戏根目录，等待备份完毕（这个过程可能会持续1-3min，看自己电脑配置喽~）

### 第四步：配置游戏路径

打开实例管理页面，添加游戏实例。

### 第五步：安装资源包

1. 访问笨蛋广场 → 游戏资源下载
2. 下载你需要的资源包
3. 进入「包管理」页面，点击「导入」，然后选择游戏实例，再选择资源部后点击「安装」。


## 常见安装问题

- **杀毒误报**：将 HMOL 目录加入白名单，或临时关闭实时保护
- **运行库缺失**：笨蛋广场 → 运行环境 → 一键安装
- **路径不存在**：确保游戏根目录下有 `gamemd.exe` 和 `MentalOmegaClient.exe`
