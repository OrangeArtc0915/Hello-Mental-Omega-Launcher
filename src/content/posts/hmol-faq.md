# HMOL标准版 常见问题解答

## 启动与运行

**Q: 双击 exe 后没有反应？**

A: 尝试右键「以管理员身份运行」。如果仍然无效，检查杀毒软件是否拦截了 HMOL.exe。可以将 HMOL 程序目录加入白名单后重试。

**Q: 启动后提示缺少 DLL 文件？**

A: 打开笨蛋广场 → 运行环境，下载并安装 Visual C++ 运行库合集。运行 HMOL 需要 VC++ 2015-2022 可再发行组件包。

**Q: 启动界面一闪而过？**

A: 查看 HMOL 程序目录下的日志文件，根据错误代码对照错误代码文档排查。大多数情况下是配置文件损坏，删除 `HMOL_config.json` 后重新启动即可恢复默认配置。

## 更新与下载

**Q: 检查更新失败或超时？**

A: 在更新对话框中切换到 Gitee 线路重试。如果两条线路都不可用，请前往 Github 或 Gitee Releases 页面手动下载最新版。

**Q: 下载进度卡住不动？**

A: v2.6.2 已修复此问题。如果仍在使用旧版本，请手动下载最新版本覆盖安装。

**Q: 提示: WinError 740**

A: 右键「以管理员身份运行」。

## DLC 插件包

**Q: 放入 DLC 文件夹后没有显示？**

A: 检查插件包文件夹内是否包含有效的 `DLC.json` 文件。确认 JSON 格式正确、`name` 和 `main` 字段已填写。参考 `DLC/Example_MyTheme/` 中的示例配置。

**Q: 插件包启动失败？**

A: 确认 `main` 字段指向的 exe 文件存在于插件包目录内。路径为相对于 DLC 文件夹的路径，不包含盘符和上级目录引用。

## 游戏运行

**Q: 启动游戏后黑屏？**

A: 在资源中心下载黑屏补丁。如果问题仍然存在，尝试切换 CnC-DDRAW 渲染器或更新显卡驱动。

**Q: 游戏帧率低、卡顿？**

A: 确保游戏运行时有足够的可用内存。关闭不必要的后台程序也有帮助。
