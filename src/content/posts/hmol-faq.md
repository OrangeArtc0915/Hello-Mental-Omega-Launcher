# HMOL 常见问题解答

> [!NOTE]
> 本页对应**当前版本**：C# / .NET 8 版 `{{HMOL_VERSION}}`。
> 更多问答见文档的 [常见问题 FAQ](/docs/faq/) 与 [联机 · 常见问题](/docs/multiplayer/faq/)。

## 安装与解压

**Q: 双击 exe 后没有反应，或提示程序已经在运行？**

A: 程序是单实例的：已经有一个 HMOL 在运行时，第二次双击只会提示并退出，请在任务栏或系统托盘里点开已运行的那个窗口。如果完全没反应，检查杀毒软件是否拦截了 `HMOL.exe`，把 HMOL 目录加入白名单后重试；从压缩包里直接双击是不行的，请先完整解压。

**Q: 提示缺少 DLL，或要求安装运行库？**

A: 不需要任何运行库。发行包是**自包含单文件** `HMOL.exe`，.NET 8 运行时已经打进去。出现这类提示通常是**没有完整解压**：请确认压缩包里的 `runtime\` 目录与 `HMOL.exe` 在同一层，不要只拖出 exe。

**Q: 提示「Windows 已保护你的电脑」（SmartScreen）？**

A: `HMOL.exe` 已做**代码签名**（自签证书 `CN=mmm`）。但证书由发布方自建、不是公共 CA 签发，没把它装进本机「受信任的根证书颁发机构 / 受信任的发布者」的机器上，SmartScreen 仍可能拦一次：点「更多信息 → 仍要运行」即可继续；也可以先核对 Release 页面公布的 SHA-256 校验值。

## 启动与运行

**Q: 启动界面一闪而过？**

A: 看 `Data\Log\` 下最新的日志文件，或重新打开程序后到「运行日志」页导出 TXT / CSV 排查。若是配置损坏，可以删掉 `Data\Settings.json` 重新启动，程序会用默认设置重建（实例与备份不受影响）。

**Q: 提示「未能验证启动授权，已禁用启动」？**

A: 这是程序启动前的**联网授权校验**：断网、被墙或超时都会读不到结果，因此会拦住启动并给出错误代码。请确认网络可用后重新打开；若一直如此，请到 QQ 群或 GitHub Issues 反馈。

**Q: 开机自启后只看到托盘点不到窗口？**

A: 这是设计如此。以开机自启方式启动时，程序只驻留系统托盘、不弹主窗口；点托盘图标，或托盘右键菜单里的「显示主窗口」即可打开界面。

## 包管理

**Q: 导入的资源包没有出现在列表里？**

A: 「包管理」页按四类分开：**INI / 地图 / 任务 / 插件**，每类只认自己的目录与扩展名。请确认：

- 文件放进了正确的分类目录（页面上的「包目录」会显示当前分类的实际路径）；
- 扩展名在允许范围内：INI / 任务 / 插件只接受 `.zip` / `.7z` / `.rar`，地图类额外接受单个 `.map`；
- 压缩包**不能再套一层文件夹**——解压后应直接是 `INI\`、`MapsMO\` 等目录或散装文件。

**Q: 安装或卸载时提示目标已存在 / 检测到文件冲突？**

A: 说明要装进去的目录里已经有同名文件。按提示选择「覆盖全部」「跳过已有」或「取消」；被覆盖的旧文件会先备份为 `.bak-<时间戳>`，安装中途取消也会自动回滚。

**Q: 卸载后游戏里还有旧内容？**

A: 优先选「选择性卸载」：它按安装记录精确删除该包装进游戏目录的文件，并把被覆盖的原版文件从 `backup\MO` 还原。没有安装记录、或没有原版备份时只能「全量恢复原版」——那会把当前实例的游戏目录整体换回原版，实例上装的**所有**包都会被移除。

## 备份与还原

**Q: 「备份原版游戏」和普通「备份」有什么区别？**

A: 「备份原版游戏」固定存到 `backup\MO`（名称不可改），是选择性卸载与全量恢复的依据；普通「备份」是你自己命名的存档，放在 `backup\game\<名称>` 下，可随时还原覆盖回游戏目录。

**Q: 备份很慢、占用很大？**

A: 备份是整目录复制。游戏目录通常有好几个 GB，视磁盘性能可能需要几分钟；请预留足够空间，尽量不要备份到与游戏同一块慢盘。

## 联机

**Q: 选 n2n 方案时提示需要 TAP 虚拟网卡？**

A: n2n 是二层组网，依赖 TAP 虚拟网卡；系统里没检测到时会引导你安装驱动。安装驱动需要管理员权限，程序会先说明要做什么，再由你确认后**单独提权**执行。EasyTier 是三层组网、免装驱动，推荐优先使用。

**Q: 进了房间但游戏里看不见对方？**

A: 常见原因是防火墙拦了局域网广播（UDP）。可以在「联机 → 工具箱」里检查并临时关闭防火墙（需要提权），联机结束后记得恢复；也可以调整虚拟网卡的接口跃点数，让游戏的局域网流量优先走虚拟网卡。

**Q: 分享文本 / 一键加入怎么用？**

A: 在「联机」页复制分享文本发给队友，队友在「联机」页点「一键加入」即可（程序会从剪贴板读取）。分享文本里带版本号，双方版本不一致时会明确提示先对齐版本。

## 界面与外观

**Q: 主页的小组件能自己加吗？**

A: 能。除了内置的日历 / 天气 / 常用网站，还可以放**扩展小组件**：在「设置 → 扩展模块」里用表单新建，或把一个 `.json` 清单放进 `Data\extensions\` 后点「重新加载」。扩展是纯声明式配置，不会被执行，也不会读写你的文件。

**Q: 怎么改主题、背景和主页布局？**

A: 「设置」里可以换明暗模式与强调色；背景支持图片与 Wallpaper Engine 壁纸包（`.pkg` / `.mpkg`），可调模糊与暗化；还能在「设置 → 自定义布局」里打开布局编辑器，调整左侧导航的顺序与显隐，以及主页控件的自由定位，方案存放在 `Data\layouts\` 下。

## 其他

**Q: 怎么检查更新？**

A: 程序**自带在线更新**：默认在启动后自动检查一次（可在「设置 → 程序更新」里关掉），也可以在那里点「检查启动器更新」手动检查；线路可选 GitHub 优先 / Gitee 优先 / 自动切换。

更新**只替换 `HMOL.exe` 本体**——`Data\` 里的设置、实例、缓存与游戏文件都不会被动；替换由临时脚本在程序退出后完成，失败会自动还原旧版本，并在下次启动时给出中文提示。想手动更新的话，也可以到 GitHub / Gitee 的 Release 页面下载 `HMOL-v*-win-x64.zip` 完整解压覆盖，`Data\` 留着不影响。

**Q: 卸载 HMOL 要删什么？**

A: 程序与数据都在同一个目录里，直接删掉整个 HMOL 目录即可。若开启过开机自启，先到「设置 → 开机自启」关掉，程序会自动清理注册表里的自启项。
