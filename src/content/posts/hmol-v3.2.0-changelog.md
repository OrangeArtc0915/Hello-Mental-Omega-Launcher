# HMOL wine版 v3.2.0 更新日志

### 🆕 新增功能

- **后台下载中心**：默认在前台下载（页面内实时显示进度）；点击"后台下载"后，右下角出现悬浮迷你窗，可实时查看每个文件的进度、速度与剩余时间，支持拖动、折叠/展开、单个任务取消与"全部停止"；切换到其他页面时下载仍在后台继续运行。
- **高速模式开关**（设置 → 下载设置）：默认关闭（保守）。开启后可进一步提高下载并发数与分片数，下载更快，但更占用带宽与 CPU。
- **磁盘空间预检查**：开始下载前检查磁盘剩余空间，空间不足时提前提醒，避免下载中途写满磁盘。

### 🚀 性能优化

- **OneDrive 下载全面提速**：
  - 多文件并行下载 + 单文件多线程分片下载（并发量自适应）
  - 断点续传：中断后可继续，无需重新下载
  - 网络连接池扩容、失败自动重试（502/503/504）
  - Range 探测结果缓存，避免重复探测拖慢下载
  - 下载完成后精确校验文件大小，防止损坏文件入库

### ✨ 体验改进

- 下载完成或出错时弹窗提示结果（成功 / 失败 / 取消数量）
- 悬浮窗在全部任务结束后自动隐藏并清理记录

# HMOL标准版 v3.2.0 更新日志

### OneDrive 下载大幅提速（多线程分片 + 高速通道）

针对启动器内置 OneDrive（SharePoint）下载速度过慢的问题，本次对下载链路做了整体优化：

- **多线程 Range 分片**：大文件（≥64MB）拆分为最多 16 段并发下载。经实测，该租户按连接数限速（单连接约 0.5-0.8 MB/s），聚合吞吐随连接数单调上升，16 连接最优（直链 2/4/8/12/16 连接 = 1.1/1.7/3.5/4.1/8.0 MB/s）。
- **download.aspx 高速通道优先**：实测同连接数下 `download.aspx` 比直链（`?download=1`）快约 45%（16 连接：10.07 vs 8.02 MB/s），故优先使用，直链作为后备。
- **实测效果**：196.9MB 大文件从单连接约 0.8 MB/s（约 4 分钟）提升到约 7.66 MB/s（25.7s），**提速约 9.6 倍**（纯网络传输 12.6 倍）。
- **小文件保突发**：<64MB 文件自动回退单连接直下，保持原有突发带宽（48MB 文件实测 14.1 MB/s），无回归。


### 断点续传

- 下载写入 `.part` 半成品文件，进度元数据每 8MB 原子持久化（多线程安全）。
- 下载中断/取消/失败均保留已下载部分；再次下载时弹窗显示已下载百分比并询问是否从断点继续。
- 分片下载按段跳过已完成字节，单连接按 `Range: bytes=N-` 偏移续传；下载成功后自动重命名为最终文件。

### 下载交互升级（前台/后台二选一）

- 点击下载后弹出**下载确认窗**（`DownloadInfoDialog`）：显示文件名、大小、保存位置，并提供「下载」与「后台下载」两个按钮，确认后才真正开始下载。
- **前台下载（默认）**：模态进度窗口（`QProgressDialog`，带取消按钮），实时显示进度与速度，完成后弹出下载完成提示——适合希望盯着下载完成的场景。
- **后台下载**：点「后台下载」转入右下角无边框悬浮窗（`DownloadFloatingWidget`）：始终置顶、可拖动、右上角「×」仅隐藏（下载继续）、可随时取消；实时显示文件名、进度条、速度与剩余时间，期间可正常使用启动器其他功能。
  - 下载完成后悬浮窗显示成功状态约 2-3 秒自动淡出；取消则显示「⏸️ 已暂停」立即收起（临时文件保留，可稍后续传）。
- **退出自动停止**：关闭启动器时自动停止下载（设置取消标志并等待下载线程退出），`.part` 半成品保留，下次启动可续传。
- **防重复下载**：同一文件下载进行中再次点击下载会提示「已有文件正在下载中」，避免多个下载线程写同一临时文件导致数据损坏。

## 改进

- **磁盘空间预检**：下载前检查目标磁盘剩余空间，不足时提示并中止，避免下载到一半失败。
- **失败重试**：下载失败弹窗询问是否重试，选择重试后自动从断点续传已下载部分，并保持原下载模式（前台/后台）。
- **断点恢复询问**：检测到未完成的下载时显示已下载百分比（临时文件 + 已下载大小），询问是否继续。
