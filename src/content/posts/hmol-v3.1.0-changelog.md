# DLC更新

HMOL联机模块 v3.1.0 更新日志

### 新增

- **第三组网方案 ZeroTier（三层 · API 建网）**，与 EasyTier、n2n 并列，共三种方案可选。
  - 房主：在网络设置页填写自己的 API ，连接时自动创建或复用网络、自动授权自己，并后台轮询自动授权新成员，全程零网页操作。
  - 成员：无需令牌，收到分享文本中的网络 ID 即可加入，等待房主授权后自动获取虚拟 IP。
  - 内置无界面 zerotier-one 核心服务：官方 MSI 静默安装,无本地安装包时自动在线下载。
  - 默认虚拟网段 172.2xxx.0/24，避开 EasyTier（x0.0.0.x）与 n2n（192.168.100.x）网段。
- 网络设置页新增 ZeroTier 专属面板（仅选 ZeroTier 方案时显示）：
  - API 令牌输入框（掩码显示）+ "打开官网" 直达 my.zerotier.com。
  - "ZeroTier 工具"：安装 / 启动 / 停止核心服务、保存令牌、调 Central API 校验令牌有效性。
- ZeroTier 方案下"节点"栏自动切换为"网络 ID（16 位 hex）"，支持手动编辑。
- 分享文本支持 ZeroTier 方案与网络 ID 传递；分享版本号升级为 v3.1.0（版本不一致拒绝联机）。

### 修复 / 优化

- EasyTier 旧默认节点 tcp://39.1xx.x2.xxx8:1xxx 已被防火墙拦截，配置自动迁移为同主机 UDP 协议（udp://3xxxx0），避免用户一直连不上。
- DLC 描述由"EasyTier/n2n 双方案"更新为"EasyTier/n2n/ZeroTier 三方案"。

# HMOL wine版 v3.1.0 更新日志

## 核心亮点

v3.1.0 在 v3.0.0 性能优化的基础上，围绕**交流入口、启动体验、资源下载**做了三项实用性升级，并修复了一个特殊文件夹导致的文件列表加载失败问题。

### 1. 关于页面补充 QQ 2群

- 反馈与建议卡片新增「QQ 2群：109xxxxxx90」，支持一键复制群号与一键加群。
- 原「官方 QQ 群」更名为「QQ 1群」，两个群并列展示。

### 2. 主页新增启动方式选择

- 「启动游戏」按钮上方新增启动方式下拉框：
  - `!1运行本脚本启动客户端.vbs`（默认，经 wscript 启动客户端）
  - `从 MentalOmegaClient.exe 启动`（直接启动游戏可执行文件）
- 选择会记忆到配置文件，下次打开自动沿用。

### 3. Wine 兼容保障（启动可靠性）

- vbs 启动优先 `wscript.exe`；Wine 环境缺失 wscript 时自动回退 `os.startfile`（等价双击打开）。
- 实例目录中不存在启动脚本时，弹窗确认后自动改用 exe 方式启动，确保始终可以进入游戏。

### 4. 笨蛋广场新增下载线路选择

- 游戏资源 / 运行环境 / 程序DLC 三个页面工具栏新增「🌐 用浏览器打开」按钮。
- 点击后弹出线路选择窗口，可从 **OneDrive（原链接）/ 123云盘 / 百度网盘 / 移动云盘** 中任选一条在浏览器中打开。
- 打开失败时自动给出可复制链接，方便手动访问。

### 5. 其他

- 游戏资源下载链接更新。
- 修复：打开名称含 `#` 等特殊字符的文件夹（如「#社区资源」）时文件列表报 `Files HTTP 400` 的问题。根因是文件夹路径未做 URL 编码，`#` 被当作链接片段截断请求，现对路径统一编码后恢复正常。

# HMOL标准版 v3.1.0 更新日志

### Wallpaper 壁纸包（.mpkg）支持

自定义背景现在可以直接导入 Wallpaper Engine 导出的 `.mpkg` 壁纸包：
- **使用方式**：设置 → 个性化设置 → 背景 → 「浏览」选择 `.mpkg` → 设为当前背景 → 「应用背景」生效
- **推荐做法**：在 Wallpaper Engine 中右键壁纸 →「导出 .mpkg 文件」，视频壁纸选择「预渲染·高性能」，场景壁纸也会被渲染成视频；

### 笨蛋广场下载线路选择

笨蛋广场各页面（游戏资源/运行环境/程序DLC）的「🌐 在浏览器中查看」按钮改为弹出线路选择窗口：

- **OneDrive**：原共享文件夹链接
- **123云盘 / 百度网盘 / 移动云盘**：点击后在浏览器打开对应镜像
- 打开失败时给出可复制链接提示

### 游戏资源下载改为类别浏览

- 「游戏资源下载」页进入后先显示类别选择页（3 列卡片：图标 + 名称 + 简介），点击类别卡片再进入对应的 OneDrive 文件列表
- 类别：INI包 / 插件包 / 地图包 / 美化包 / 任务包 / 音乐包 / 游戏本体 / 游戏实例 / 语音包
- 各类别文件列表页保留搜索、刷新、「在浏览器中查看」线路选择能力，「返回」回到类别选择页
- 新增「社区游戏资源下载」侧边栏入口，链接指向社区上传文件夹；游戏资源下载链接同步更新

## 改进

**壁纸播放性能优化**

视频/GIF 背景原先每帧执行 `QPixmap.fromImage` + 全分辨率平滑缩放（`SmoothTransformation`），高帧率或高分辨率壁纸会拖垮 UI 线程，导致壁纸卡顿、启动器偶发未响应。本次优化：

- 视频/GIF 背景帧率节流至 30fps（背景 30fps 视觉足够），跳过中间帧
- 视频帧改由 `QPainter.drawImage` 直接绘制，并改用 `FastTransformation` 快速缩放，替代每帧的高开销转换路径
- 静态图与模糊背景逻辑保持不变

## 移除

**背景 URL 直链导入**

- 移除「🌐 从URL导入...」按钮与 `_settings_import_bg_from_url` 下载导入逻辑
- 移除「📖 如何获取壁纸直链？」教程按钮与方法
- 背景设置页现仅支持：本地图片 / GIF / 视频（JPG/PNG/WebP/GIF/MP4/WebM）、Wallpaper 壁纸包（.mpkg）、默认背景
