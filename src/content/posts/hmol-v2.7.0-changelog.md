# HMOL wine版 v2.7.0 

## 核心亮点：全面性能优化（适配渣机/老设备）

v2.7.0 的优化重点是**启动速度**。开发过程中对启动各环节做了插桩实测，定位到**主窗口构建（MainWindow）是最大的启动瓶颈**（约占启动总耗时的一半），并针对性地实施了两项深度优化：

### 1. 页面懒加载

- 此前启动时会**一次性构建全部 10 个页面**（主页 / 账号 / 实例管理 / 包管理 / OneDrive×3 / DLC / 教程 / 设置），其中教程页（约 0.22s）、设置页（约 0.16s）、实例页（约 0.10s）是主要开销。
- 现在**启动时只构建主页**，其余 9 个页面改为在**首次导航时才按需构建**（`_switch_page` 中懒加载，未知页面安全返回不报错）。

### 2. 侧边栏延迟构建

- 侧边栏此前会在启动时同步创建 14 个 ttk 控件（8 个导航按钮 + 2 个分组标题 + 4 个分隔符）。实测发现**第一个 ttk 按钮的创建会触发 tkinter 主题引擎的一次性初始化，单次耗时约 0.31 秒**。
- 现在除"主页 / 退出"两个必要按钮外，其余导航项通过 `after()` **延迟到首帧显示后分 2 批填充**（每批最多 8 项），窗口先呈现完整主界面，导航在约 0.2 秒内渐进补齐。
- 侧边栏布局编辑器的持久化设置（顺序 / 重命名 / 隐藏 / 宽度）在所有项目注册完成后统一应用，行为与旧版一致。

### 实测性能数据

以下数据来自新增的**性能诊断工具**（开发机，Windows 10，Python 3.14）：

| 指标 | v2.6.2 | v2.7.0 | 提升 |
|---|---|---|---|
| 主窗口构建（MainWindow） | 1.556s | **0.612s** | **-61%** |
| 模块导入（进程启动 → main()） | 0.032s | 0.029s | ≈ 持平 |
| 启动到窗口出现（打包产物实测） | — | 约 2s | — |

> 在低配机器上，tkinter 控件创建成本会成倍放大，懒加载的收益比开发机更明显；页面构建成本也从"启动时一次付清"变为"用到才付"。

## 新增

- **性能诊断工具**：新增 `HMOL_perf_diag.py` 与 `性能诊断.bat`，双击一键检测并输出 `HMOL_perf_report.txt` 报告。覆盖指标：
  - 各依赖模块导入耗时（tkinter / PIL / py7zr / rarfile / msal / requests / cryptography / HMOL_tk）
  - 主窗口构建耗时（约 250-400 个控件 + 主题应用 + 实例遍历 + 背景渲染）
  - PBKDF2 密钥派生（600,000 次迭代）耗时
  - 网络连通性检测（socket 直连微软登录端点，5 秒超时）
  - 打包产物体积统计与 Top 10 大文件
  - 便于在后续版本中持续定位性能问题。
- **启动流程重构**：网络检查放入**后台线程**执行、主线程轮询等待（最长 6 秒），期间 UI 保持可响应；EULA 对话框尽可能早弹出，登录对话框在窗口渲染完成后才显示。

## 优化

- **渐变背景渲染缓存**：同色同尺寸的渐变背景只生成一次位图并缓存复用（用 PIL 生成 1 像素宽的渐变列再横向拉伸，避免逐像素重绘），切换页面时不再重画数百个矩形，背景渲染耗时由毫秒级降至约 0.004s。
- **依赖精简**：tkinter 版构建时彻底排除 PySide6、PyQt5、PyQt6、numpy、scipy 等模块，启动过程不再加载任何 Qt DLL，安装体积更小。
- **资源包分类整合**：所有资源包统一归入单一"资源包"分类，简化浏览流程（Wine 版性能优化）。
- **离线模式适配延迟构建**：离线禁用状态与当前页高亮在侧边栏延迟构建完成后统一补应用，功能完整性与旧版一致。

## 修复

- 修复页面懒加载暴露的 3 处初始化依赖问题（此前依赖"启动时预构建所有页面"，懒加载后改为页面首次打开时同步刷新）：
  1. 包管理页的"当前实例"信息在页面首次打开时同步刷新；
  2. 实例管理页的实例列表在页面首次打开时同步刷新；
  3. DLC 列表刷新增加守卫，页面未构建时跳过后台解压完成后的刷新回调，进入页面后再刷新，避免空引用报错。

## 已知问题

- 更新至 v2.7.0 后需重新接受一次使用协议（EULA 版本号随启动器版本更新，属预期行为）。
- 部分低配设备上首次进入 OneDrive / DLC 页面时会有短暂加载过程（页面改为按需构建所致），后续访问无影响。
- 首次启动时侧边栏导航项会在首帧后约 0.2 秒内渐进补齐，属预期视觉效果。

# HMOL v2.7.0

### Bug 修复

**更新检查无法启动**

修复更新检查对话框启动时报 `NameError: name 'QRadioButton' is not defined` 的问题。更新对话框中的"下载线路"选择器使用了 `QRadioButton`（Github / Gitee 双线路），但 [HMOL_updater.py](HMOL_updater.py) 的 PySide6 导入列表中缺少该控件，导致点击"检查更新"或启动自动更新检查时直接崩溃。现已补齐 `QRadioButton` 导入，更新检查可正常打开。

### 改进

- 全局版本号统一升级至 v2.7.0（大版本更新）
- 更新 manifest 版本、发布日期及更新内容说明同步至 v2.7.0

### 升级说明

v2.6.2 → v2.7.0 属于大版本更新（minor 变化），启动器会将其标记为强制更新。
