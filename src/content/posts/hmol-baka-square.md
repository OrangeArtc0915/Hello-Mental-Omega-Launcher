# HMOL标准版 笨蛋广场资源站使用指南

笨蛋广场是 HMOL 内置的资源下载中心，通过微软 OneDrive 提供高速文件分发。

## 三大板块

### 游戏资源下载

提供游戏相关的各类资源：

- 插件包（地图编辑器扩展、AI 增强等）
- 地图文件
- 皮肤和主题
- 社区制作的各类 MOD

### 运行环境

游戏运行所需的系统组件：

- DirectX 运行库
- Visual C++ 可再发行组件包
- .NET Framework
- 其他游戏启动必要的依赖项

### 程序 DLC 下载

HMOL 程序扩展和辅助工具：

- 地图编辑器（FinalAlert 2）
- 内存优化工具
- 文本编辑器
- 模型转换工具

## 使用方式

1. 打开 HMOL 主界面，切换到「笨蛋广场」标签页
2. 选择需要的资源板块
3. 浏览文件列表，点击下载按钮
4. 下载完成后按照板块说明进行安装

所有资源托管在 OneDrive，国内用户也可获得稳定的下载体验。
