# HMOL wine版 v3.0.0

## 核心亮点：全方位性能优化

v3.0.0 对启动速度、UI 响应、内存占用、打包体积四个维度做了系统性优化，并新增**内置性能监控体系**，让后续优化有据可依。所有改动均围绕 **Wine 兼容性**设计，不依赖任何 Windows 专属 API。

### 1. 性能监控体系（新增）

- 新增轻量级性能监控模块 `HMOL_perf.py`（零外部依赖，微秒级开销，失败静默降级）：
  - **启动里程碑计时**：记录 `main 进入 → 窗口创建 → 认证就绪 → EULA 完成 → 网络检查 → 登录完成 → 主循环启动` 全链路耗时
  - **区间计时**：上下文管理器测量任意代码块耗时，页面构建超过 100ms 自动记录慢日志
  - **UI 心跳卡顿检测**：每秒心跳，检测主线程事件循环阻塞
  - **跨平台内存采样**：Windows 走 psapi、Linux 走 /proc，不依赖 psutil
- 设置页新增「性能」卡片：可开关监控、一键生成性能报告。

### 2. 启动速度优化

- **模块惰性加载**：`py7zr`、`rarfile`、`msal`、`requests`、更新检查器全部移出启动关键路径，首次使用时才加载。实测模块导入从约 **1s 降至 0.16s**。
- **认证初始化后台化**：`AuthManager`（含 PBKDF2 60 万次密钥派生与 MSAL 初始化）移入后台线程，启动流程不再等待，登录前通过 `wait_ready()` 同步。
- 效果：认证就绪里程碑在窗口创建后**立即完成**（原为阻塞式等待）。

### 3. UI 响应优化

- **修复心跳卡顿误报 Bug**：原检测逻辑把 1s 正常心跳周期误判为卡顿（空闲时每秒报一次假卡顿），现改为检测「超出预期周期的延迟」，空闲实测从 6 次假卡顿降为 0。
- **实例大小扫描后台化**：首次计算游戏目录大小时不再阻塞主线程，界面先显示「计算中…」，完成后自动回填。
- 页面导航实测 **0 卡顿**，最大页面构建约 165ms。

### 4. 内存占用优化

- 首页渐变背景改用 `Image.linear_gradient + ImageOps.colorize` 生成（更快），并**显式释放中间 PIL 图像**，降低峰值内存。
- 新增**超大尺寸回退**：4K 高分屏下全尺寸渐变位图可达数十 MB，现超过 1600×1200 自动切换为轻量矩形绘制（实测 3200×1800 下仅增加 0.3MB）。

### 5. 打包体积优化

- 程序本体从 **75.5MB 降至 48.4MB（-36%）**：
  - 排除未使用的 `PIL._avif` 插件（7.5MB）
  - 排除无依赖方的 `pycryptodome`（1.5MB）、`sqlite3`
  - 排除未使用的 `PIL.ImageCms / ImageMath` 及 21 个罕见格式插件
  - 排除标准库冗余（unittest / pydoc / idlelib / venv 等）
  - 启用 `--optimize=2` 字节码优化
- 打包 EXE 冒烟测试通过：启动、认证、页面导航、退出全流程正常，内存峰值约 68MB。

### 6. Wine 版主题简化

- Wine 版移除 6 套个性化主题，固定一套打磨过的蓝紫渐变主题，界面自动跟随系统深色/浅色模式，观感保持一致且不拖慢性能。

### 7. 新增：QQ 2群 与 启动方式选择

- **关于页面补充 QQ 2群**：反馈与建议卡片新增「QQ 2群：1092671790」（原官方群更名为 QQ 1群），支持一键复制群号与一键加群。
- **主页新增启动方式选择**：「启动游戏」按钮上方可切换启动方式：
  - `!1运行本脚本启动客户端.vbs`（默认，经 wscript 启动客户端）
  - `从 MentalOmegaClient.exe 启动`（直接启动游戏可执行文件）
  - 选择会记忆到配置文件，下次打开自动沿用上次的选择。
- **Wine 兼容保障**：vbs 启动优先 `wscript.exe`，Wine 环境缺失 wscript 时自动回退 `os.startfile`（等价双击打开）；若实例目录中不存在启动脚本，弹窗确认后自动改用 exe 方式启动，确保始终可以进入游戏。

## Bug 修复

**修复 7z 打包产生绝对路径条目（严重）**

打包向导此前使用 `py7zr.writeall(arcname="")` 打包 7Z，实际会写出**绝对路径条目**（如 `C:/Users/.../package/DLC.json`），解压时 py7zr 直接报 `Bad7zFile`，导致 7Z 包完全无法被 DLC 自动解压识别。现已改为手动遍历目录写入相对路径条目，DLC.json 平铺在包根，验证 `['DLC.json', 'sub/data.bin']` 解压正常。

**修复打包向导路径校验漏洞**

main 路径校验此前只拦截 `..` 与双反斜杠开头，存在两个缺口：`C:\...` 盘符绝对路径（会导致资源复制到错误位置）与 `/` 前导分隔符（normpath 后为单反斜杠开头未被拦截）均可绕过。现已全面拦截：`..` 开头、`\`/`/` 开头、盘符开头，并附带运行时测试验证。

**修复视频背景黑屏（严重）**

视频背景此前使用 `QVideoWidget` 渲染，依赖 RHI 渲染管线（D3D11/OpenGL）。在无 GPU 或特殊显卡驱动环境下 RHI 初始化失败，视频解码正常（时间轴播放、无报错）但画面全黑。已改用 `QVideoSink` 自绘渲染：解码器每帧经 `toImage()` 转 QImage，由主页 paintEvent 直接绘制（纯 CPU 渲染），兼容无 GPU 环境；视频帧自动跳过背景模糊以保证帧率。实测 4K 视频约 28fps 正常显示，并移除全部 QVideoWidget 相关代码。
