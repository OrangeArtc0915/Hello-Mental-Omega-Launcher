# HMOL标准版 v2.6.2 更新日志

## Bug 修复

**下载资源时启动器卡死**

修复了从 OneDrive 下载文件时进度回调在后台线程直接操作 UI 控件导致的卡死问题。所有 UI 更新现已统一通过 `QMetaObject.invokeMethod` 投递到主线程执行，用户取消下载时可立即中断网络流并清理半成品文件。

**备份游戏不包含已安装插件包信息**

`_backup_game_impl` 写入 `backup_info.json` 时现在会完整记录 `installed_packages` 字段。恢复备份时不再丢失已安装的插件包列表，真正做到一键还原完整游戏环境。

**双击 exe 静默后台不显示主页面**

新增全局异常钩子，覆盖主线程和 Qt 工作线程。任何未捕获异常都会弹出可见的错误对话框。实现三级降级错误显示（QMessageBox → tkinter → Windows 原生 MessageBox），即使 Qt 初始化失败也能让用户看到错误信息。

## 新功能

**双线路更新系统**

更新检查支持 Github 和 Gitee 两条下载线路。用户可在更新对话框中自由切换，选择速度更快的线路下载更新。启动时自动检查更新会依次尝试两条线路，确保国内用户也能稳定获取新版本。

**DLC 插件包系统**

新增标准化的 DLC 配置文件规范，支持美化、优化、功能三种类型的插件包。程序启动时自动扫描 `DLC` 目录并加载。

## 改进

- 全局版本号统一升级至 v2.6.2
- 优化更新模块错误提示，失败时同时显示 Github 和 Gitee Releases 地址
- 完善 DLC 示例文件，附带完整字段说明

# HMOL wine版 v2.6.2 更新日志

## 新增

- **实例导出/导入支持 7Z 格式**：实例导出现已支持 ZIP、7Z、RAR 三种压缩格式，7Z 提供更高的压缩比，适合大体积游戏目录的迁移。
- **QQ 喊话速率限制优化**：喊话频率限制调整为 5 次/分钟，超出后自动提示等待剩余秒数，避免误触 API 限流。
- **DLC 启动器子进程监控增强**：DLC 启动后新增子进程状态实时监控，异常退出时自动弹出错误码提示。

## 修复

- 修复了 7Z 格式插件包解压时 `py7zr` 版本兼容性问题，现支持 `py7zr >= 0.21` 全系列版本。
- 修复了侧边栏布局编辑器在特定窗口缩放比例下拖拽偏移的 Bug。
- 修复了 OneDrive 资源浏览中 `nextLink` 解析失败导致分页中断的问题。
- 修复了备份还原流程中 `manifest.json` 校验和不匹配时静默失败的问题，现在会给出明确的错误提示。

## 优化

- 启动器冷启动时间缩短约 15%，优化了模块懒加载逻辑。
- 日志系统重构：日志文件自动按日期轮转，单文件上限 5MB，最多保留 7 天。
- 错误码手册更新至 149+ 条，补充了 E8（DLC 启动）和 E10（EULA/启动）分类下的新增条目。
- 主题切换性能提升，深色/浅色主题之间切换不再出现短暂白屏。

## 已知问题

- RAR 格式插件包依赖系统安装的 `unrar` CLI 工具，Wine 环境下需手动配置路径。
- 部分高 DPI 缩放比例下（> 200%）侧边栏图标可能出现轻微模糊，将在下个版本修复。
