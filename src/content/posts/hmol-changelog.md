# HMOL 版本说明（v1.0.0）

HMOL 是面向《心灵终结》（Mental Omega）玩家的 Windows 桌面启动器，基于 **C# / .NET 8 / WPF**，
以**自包含单文件** `HMOL.exe` + `runtime\` 组网组件的压缩包形式发行（`HMOL-v1.0.0-win-x64.zip`）。

> [!NOTE]
> 当前版本**没有内建在线更新器**，也没有逐条发版记录。本页只说明这一版**已经具备**的能力，
> 不虚构更新条目；具体发版内容请以 Release 页面为准。

### 当前版本具备的能力

- **主页**：当前实例总览与一键启动 / 停止（同一时间只允许一个游戏进程）、切换实例、运行状态；小组件含现实月历、现实天气（Open-Meteo，可设城市、30 分钟缓存）与常用网站；控件支持按方案自由定位。
- **游戏实例**：实例的增删改查与重命名、设为当前、打开目录、体积统计，实例导出（`.zip` / `.7z`）与导入，用户备份 / 原版备份 / 还原 / 完整性抽样校验。
- **包管理**：INI / 地图 / 任务 / 插件**四类包**的可用与已安装列表、导入与移除、安装（文件冲突可选「覆盖全部 / 跳过已有」）、选择性卸载与全量恢复；覆盖前留 `.bak-<时间戳>`，安装失败自动回滚。
- **联机**：EasyTier（三层，免装驱动）与 n2n（二层，需 TAP 驱动）两种组网方案，公共节点与自定义节点、节点测速、房间名与密钥、自动 / 手动虚拟 IP；MQTT 大厅（在线玩家、公开房间、大厅聊天、入房邀请）、房间聊天与房主踢人 / 拉回、收藏队友、文件传输、游戏 HUD 浮窗，以及网络工具箱（PING、TCP / UDP 测速、NAT 类型、防火墙开关、网卡跃点数、TAP 驱动安装、自建 supernode）。
- **运行日志**：内存日志与日志文件两种视图、导出 TXT / CSV、打开日志目录、清理旧日志。
- **设置**：明暗模式与强调色、联机昵称、天气城市、常用网站、背景与壁纸包（`.pkg` / `.mpkg`，可调模糊与暗化）、背景音乐、自定义布局编辑器、扩展模块、开机自启。
- **扩展模块**：一份 JSON 清单即可在主页加一张小组件卡片；纯声明式、不执行代码、数据源只做只读 GET。
- **发行与安全**：自包含单文件发行、单实例运行、系统托盘常驻、开机自启只在托盘驻留、按需提权（默认 `asInvoker`，双击不弹 UAC）、启动安全自检（只记录日志告警，不拦截启动）。

### 尚未实现（本版不含）

- **在线更新**：没有内建的更新检查 / 下载 / 自动替换；
- **窗口透明度与界面缩放**：设置页目前只列出占位说明，尚无对应设置项；
- **首次启动的 EULA 确认页**：当前版本没有这个步骤；
- **自动检测游戏路径**：需要在实例里手动指定游戏目录。
