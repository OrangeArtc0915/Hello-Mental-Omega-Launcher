# HMOL 版本说明（v1.5.8）

HMOL 是面向《心灵终结》（Mental Omega）玩家的 Windows 桌面启动器，基于 **C# / .NET 8 / WPF**，
以**自包含单文件** `HMOL.exe` 的压缩包形式发行（`HMOL-v1.5.8-win-x64.zip`）；
组网组件与 7-Zip 不再随包分发，首次使用联机时在「下载」页按需下载到 `runtime\`。

> [!NOTE]
> 本页说明这一版**已经具备**的能力，并附最近一次修订的变化，不逐条罗列提交记录；更细的发版内容请以 Release 页面为准。

### 当前版本具备的能力

- **主页**：当前实例总览与一键启动 / 停止（同一时间只允许一个游戏进程）、切换实例、运行状态；小组件含现实月历、现实天气（Open-Meteo，可设城市、30 分钟缓存）与常用网站，另有可选的**时钟 / 便签 / 音乐控制**。整页支持**自由排版**——欢迎横幅、当前实例卡、切换实例卡、底部提示、三块小组件、扩展区、附加小组件共 12 个区块，都能在布局编辑器里**拖动、缩放、隐藏**，拖动时带对齐辅助线（不做网格吸附）；方案可**导出 / 导入 JSON**，方便备份与分享。另有**默认 / 简洁两种显示模式**——简洁模式像 HMCL，只留右下角一个启动入口与实例切换小箭头，其余留空以尽量露出背景图。
- **游戏实例**：实例的增删改查与重命名、**游戏类型区分**（心灵终结 / 原版红警 2 / 尤里的复仇 / 其它红警 Mod，各自用对应图标）、**自定义可执行主程序**（指向哪个 exe 由你定，方便挂非 MO 的 Mod）、设为当前、打开目录、体积统计，实例导出（`.zip` / `.7z`）与导入，用户备份 / 原版备份 / 还原 / 完整性抽样校验。
- **包管理**：INI / 地图 / 任务 / 插件**四类包**的可用与已安装列表、导入与移除、安装（文件冲突可选「覆盖全部 / 跳过已有」）、选择性卸载、**按文件删除**、**回到某个时间点**与全量恢复；覆盖前留 `.bak-<时间戳>`，安装失败自动回滚。
- **联机**：EasyTier（三层，免装驱动）、n2n（二层，需 TAP 驱动）与 **樱花 Frp（端口映射直连）** 三种组网方案，公共节点（含 4 个小组名固定为 `fox` 的 n2n 节点）与自定义节点、节点测速、连接前探测与失败自动换节点、房间名与密钥、自动 / 手动虚拟 IP；樱花 Frp 可填访问密钥查账号 / 节点 / 隧道、一键新建 TCP 隧道（映射本机 1233）并把「口令」发给队友，队友在客户端局域网大厅底部地址框粘贴即成；MQTT 大厅（在线玩家、公开房间、大厅聊天、入房邀请）、房间聊天与房主踢人 / 拉回、收藏队友、文件传输、**游戏 HUD 浮窗（可单独调透明度、可只显示本房间对端）**，以及网络工具箱（PING、TCP / UDP 测速、NAT 类型、防火墙开关、网卡跃点数、TAP 驱动安装、自建 supernode）。**联机昵称与 CnCNet 客户端的玩家名共用同一个值**。组网组件不再随包分发，缺哪个会在连接前提示并自动下载到 `runtime\`。
- **下载**：运行库（EasyTier / n2n / TAP / WinIPBroadcast 组网组件与 7-Zip）与启动器补丁的统一下载入口，缺哪个下哪个，下载线路与更新共用。首次装 7-Zip 会在配置向导之前提示。「更多下载」列表里的文件**可自选保存目录**（默认仍为 `%LOCALAPPDATA%\HMOL\Downloads`）；大文件**多线程分片并发下载**，可在设置里关闭。还能读取仓库 `survive` 分支的 `download.json` 动态列出下载条目（支持条目说明与多分卷），不改启动器即可增删。列表里还放了常用游戏运行库：**DirectX 9.0c、.NET 桌面运行时、Visual C++ 运行库、XNA 4.0、.NET Framework、以及红警系列黑屏补丁（cnc-ddraw / wined3d / 旧版 ddraw）**。**只提供运行库与启动器补丁，不提供任何游戏资源。**
- **运行日志**：内存日志与日志文件两种视图、导出 TXT / CSV、打开日志目录、清理旧日志。
- **设置**：左侧侧栏**分两级**——先选「个性化 / 更新与下载 / 联机 / 其他」四个大类，点进去再看该类下的具体项，一次不会堆十几个入口。可调：明暗模式与**自定义强调色**（HSL 取色器 + 十六进制输入，还能**从背景图自动取主色**）、**界面字体、卡片圆角档位、界面动效总开关与速度**、窗口 / 卡片透明度与界面缩放、联机昵称（与 CnCNet 玩家名同步）、游戏 HUD 开关与透明度、天气城市、常用网站、背景与壁纸包（`.pkg` / `.mpkg`，可调模糊与暗化）、背景音乐、自定义布局编辑器（含主页各区块的自由定位与显隐）、**主页显示模式与附加小组件**、**窗口标题 / 窗口图标 / 启动与关闭音效**、扩展模块、开机自启、**重新运行首次运行向导**。
- **扩展模块**：一份 JSON 清单即可在主页加一张小组件卡片；纯声明式、不执行代码、数据源只做只读 GET。
- **在线更新**：启动时自动检查 GitHub / Gitee 的 Release（两线路互为备份），有新版本可下载、校验并交棒给替换脚本；替换只针对 `HMOL.exe` 本身，设置、缓存与游戏文件一概不动。更新确认框里可以**一键切换下载线路**（当前源下不动时换另一个再试，强制更新同样可以切）。**跨主 / 次版本的更新是强制的**（不更新就退出启动器），只有修订号变化才交给你选择。
- **发行与安全**：自包含单文件发行、**代码签名**（自建证书 `CN=mmm`，带 DigiCert 时间戳；发行包里不再附 `.cer` 散文件）、单实例运行、系统托盘常驻、开机自启只在托盘驻留、按需提权（默认 `asInvoker`，双击不弹 UAC）、启动安全自检（只记录日志告警，不拦截启动）。

### 本次修订（v1.5.8，2026-10-05）

这一版是**修复版**：

- **修复打开「设置」页时偶发闪退**：背景「轮播间隔」滑块在页面还在加载时就会被夹到最小值，提前触发了回写标签的代码，而那个标签此刻还没建好，于是抛出空引用异常。已改为等页面构造完成后再响应滑块事件。
- **崩溃提示框新增「修复」按钮**：启动器遇到界面未处理异常时，除了「知道了」还可以点「修复」——把启动器配置（`Settings.json` 与布局方案）**重置为默认并自动重启**；原配置会先备份到 `Data\Reset-<时间戳>\`，不会直接删除，实例、游戏与包一概不动。

### 上次修订（v1.5.7，2026-10-04）

这一版是**个性化大更新**：

- **主页自由排版**：欢迎横幅、当前实例卡、切换实例卡、底部提示、日历 / 天气 / 常用网站、扩展区等区块都能在「布局编辑器」里**拖动、缩放、隐藏**；拖动时显示对齐辅助线（只做提示，不做网格吸附）。布局方案的**坐标基准改为整页**，旧方案在首次应用时会按实测高度自动换算一次。
- **附加小组件**：设置 →「主页设置」里可打开**时钟**（24 / 12 小时制、显示日期）、**便签**（自定义标题与正文）、**音乐控制**（上一首 / 播放暂停 / 下一首），打开后都能在布局编辑器里自由摆放。
- **布局方案可分享**：布局编辑器新增「导出方案 / 导入方案」，存成 JSON 即可备份或发给朋友。
- **主题与配色**：强调色除四套预设外支持**任意自定义**——HSL 取色器 + 十六进制输入，还能**从当前背景图自动取主色**；任意颜色都会自动推导整套色阶（并做明度 / 饱和度归一化，保证按钮上的白字看得清）。
- **字体与动效**：可选**界面字体**（系统字体 + 实时预览）、**卡片圆角档位**（0.5×–1.6×）、**界面动效总开关与速度**（0.5×–2×）。
- **背景与壁纸**：支持**多张壁纸轮播**（间隔 10–600 秒、顺序 / 随机）、**填充方式**（铺满 / 适应 / 拉伸 / 平铺）、**鼠标视差**，以及**每页独立背景**（给某个页面单独指定一张）。
- **窗口与音效**：可自定义**窗口标题文字**与**窗口图标**，并设置**启动音效**与**关闭音效**（退出前留约 0.7 秒播完）。
- **设置页侧栏改为两级**：先选「个性化 / 更新与下载 / 联机 / 其他」四个大类，点进去再看该类下的具体项；切换分类时内容带淡入动效。
- **更新窗口可切换下载线路**：确认框里新增「换个线路」，当前源下不动时换另一个再试；**强制更新也允许切换**。

### 上次修订（v1.5.0，2026-10-04）

- **新增「下载」页**：侧栏「联机」下方多了一个「下载」，集中管理运行库与启动器补丁。运行库是 EasyTier / n2n / TAP / WinIPBroadcast 与 7-Zip，启动器补丁是 MO 联机补丁；页面顶部明确写着**只提供运行库和启动器补丁，不提供任何游戏资源**。没有游戏实例也能先把补丁下载下来，之后创建实例再安装。
- **运行库改为按需下载**：`runtime\` 不再随发行包分发，包里只剩 `HMOL.exe` 与许可文件，体积明显变小。第一次打开启动器、配置向导出现**之前**会提示下载 7-Zip 组件（约 1 MB，可跳过；跳过只是让 7z 压缩包退回较慢的解压实现）。联机连接前若缺当前方案的组件，也会提示并现场下载；EasyTier 组件较大，已拆成多卷下载后自动合并。
- **下载列表可远程更新**：下载页会读取仓库 `survive` 分支的 `download.json`，把里面的条目列成「打开链接 / 下载」。往这个文件里加 `{"name":"...","url":"..."}` 并提交，下载页刷新即生效，不用重新发版。
- **联机页结构调整**：原先内嵌在联机页的「联机补丁」分类移到顶层「下载」页；未安装补丁时，联机页的组网 / 大厅 / 对端 / 引擎日志会整体置灰，并提示到「下载」页安装。首次进联机页仍会引导一次。

### 上次修订（v1.4.0，2026-10-04）

- **新增第三种组网方案「樱花 Frp」**：前两种（EasyTier / n2n）走虚拟局域网，得先组好网才能联；这条走**端口映射直连**——房主在启动器里填一次樱花FRP 访问密钥，就能查账号 / 节点 / 隧道、一键新建 TCP 隧道（映射本机 1233，也就是 MO 加入游戏时的握手端口），启动后把「口令」（`IP:端口`）发给队友；队友在 MO 客户端「局域网大厅」底部的地址框里粘贴回车即可加入。不用装虚拟网卡、不分配虚拟 IP，人少、临时开一局很方便。访问密钥本地加密保存，隧道输出记进「引擎日志」，还可在设置里打开内嵌的樱花FRP 网页面板（需本机有 WebView2 运行时）。
  - 进游戏后的数据由客户端中继经这条隧道转发，**双方都需要使用带中继的客户端**；该模式属实验特性，网络抖动时可能卡顿，求稳请用 EasyTier / n2n。
- **强制更新**：更新不再都能「稍后」。**主版本或次版本变化**（例如 `1.3.0→1.4.0`、`1.3.0→2.3.0`）属于强制更新——确认框只有「现在更新」，打开发布页或直接关掉都会退出启动器，避免旧版本连到已经变了的服务端接口；只有**修订号变化**（`1.3.0→1.3.1`）才由你决定什么时候更新。强制更新不受「启动时自动检查更新」开关影响。
- **联机页布局与工具箱收敛**：樱花 Frp 方案下不再显示房间参数、「连接」与「分享给队友」卡片，网络工具箱只保留防火墙控制与延迟代码，避免放一堆用不上的按钮。

### 上次修订（v1.3.0，2026-10-03）

- **游戏内 HUD 看得清了**：HUD 底色以前跟着主题与「卡片透明度」一起变透明，叠在游戏画面上字就糊了；现在改成固定的深色不透明底，文字加大加亮，通透度只由「HUD 透明度」单独控制（最低 40%）。设置 → 联机设置里还加了 HUD 开关，不用连房间也能打开，方便先调好不好看。
- **联机昵称与 CnCNet 玩家名打通**：以前启动器一个名字、CnCNet 客户端一个名字（`RA2MO.ini` 的 `[MultiPlayer] Handle`）。现在两边读的是同一个值——进设置页自动同步，点「保存昵称」时一起写进游戏设置文件，并按客户端的长度上限限制，不用再进客户端改一次。
- **对端列表与 HUD 显示联机昵称**：之前显示的是对端电脑名（hostname），认不出谁是谁。
- **EasyTier 连接更快更稳**：连接前并行探测节点再排序，单个节点等待从 45 秒缩到 20 秒，连不上自动换下一个（最多试 3 个）。

### 上次修订（v1.2.3，2026-10-02）

- **装大包不再卡死在进度条上**：此前 1 GB 以上的资源包经常“进度条不动、最后装不完”。原因有三：解压走的是 .NET 托管实现；解压出来的内容还要再**跨盘复制**一遍进游戏目录；`.7z` 里的空文件（`Size = 0`）会被当成“条目没有可读的流”整批跳过，装出来的包是残缺的。现在 `.7z` 交给随包的原生 `7za.exe` 解压，产物与游戏目录同分区时逐文件**改名就位**（不再复制），空文件也照常建出来。实测 1.8 GB / 1038 个文件的包：**解压约 14 秒，铺入 0.3 秒，失败 0**。
- **进度窗多了「速度 · 预计剩余」**：安装、导出、备份这类耗时操作会显示实时速度与预计剩余时间。速度按最近几秒的实际推进量算，数字不会乱跳；整块解压长时间不回报进度时，预计时间会停住，而不是一路往上涨。
- **导出实例时可选压缩级别**：选完保存路径后会问一句「快速 / 最小」——快速用最低压缩、几乎不吃 CPU，最小换最小体积，按包的用途自己挑。

### v1.2.0（2026-10-01）

- **新增首次运行配置向导**：第一次打开程序时会出现一个四步向导（欢迎 → 选目录 → 检查环境 → 创建实例），做完即建成可用状态。向导只负责「问」和「记」，不安装任何东西、也不改动游戏文件；每一步都能跳过或后退，校验不通过会写明原因。老用户不受影响——只要已经有实例就不会弹；之后想重跑，可以到「设置 → 游戏路径 → 重新运行配置向导」。
- **移除自动查找游戏目录**：之前每次启动都会在后台扫描本机固定磁盘找游戏目录，既慢又打扰（扫描结果还只是建议）。现已整体移除，目录改为在向导或「游戏实例」页里手动指定；设置页里的「自动检测 / 立即检测 / 候选列表」一并去掉。目录校验与主程序查找能力保留，实例管理与包安装仍在依赖它们。

### v1.1.0（2026-10-01）

- **修复 EasyTier 联机拿不到虚拟 IP**：发行包里的 `runtime\easytier\easytier-cli.exe` 文件内容是损坏的（不是有效的 Windows 可执行文件），而启动器直接调用它来读取虚拟 IP 与对端列表，导致 EasyTier 连接一直卡在「获取地址」阶段，也看不到队友。已换成官方 EasyTier v2.6.4 的正确 cli，与 `easytier-core.exe` 版本一致。
- **修掉二级窗口内容外的一圈黑边**：打开设置、分享、聊天等二级窗口时，内容卡片外侧会露出一圈近黑的窗口底色（深色主题下尤其明显）。已改为与卡片同色，并去掉那圈没有用途的 12px 留白。
- **exe 加上代码签名**：`HMOL.exe` 现在带代码签名（自签证书 `CN=mmm`，含 DigiCert 时间戳）。把这张公钥证书装进本机「受信任的根证书颁发机构」与「受信任的发布者」后，运行本程序就不再出现「未知发布者」提示。
- **发行包瘦身**：`HMOL-v1.1.0-win-x64.zip` 内只保留 `HMOL.exe`、`runtime\` 与许可文件，不再附 `HMOL-mmm.cer` 散文件 —— 签名后的 exe 本身已经带着证书。
- **证书性质**：证书由发布方自建、并非公共 CA 签发，因此没把证书装进本机受信任存储的机器上，SmartScreen 仍可能拦一次，点「更多信息 → 仍要运行」即可。
