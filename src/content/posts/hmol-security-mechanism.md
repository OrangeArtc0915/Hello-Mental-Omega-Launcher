# HMOL标准版 安全机制介绍

HMOL 内置了多层安全机制，保护用户数据和游戏文件的完整性。

## 文件完整性校验

每次启动时，HMOL 会对关键组件进行 SHA256 校验：

- 主程序文件不被篡改
- 核心模块 DLL 未损坏
- 配置文件格式正确

校验失败时会弹出明确提示，阻止程序在异常状态下运行。

## 加密存储

- 用户令牌和登录凭据使用 AES-256 加密存储
- 熵池随机生成，不依赖固定密钥
- 每次程序更新自动轮换加密参数

## 防篡改保护

- 检测运行时内存注入
- 关键 API 调用具备完整性验证
- 异常环境（调试器附加、虚拟机逃逸等）自动预警

## 数据隔离

- 用户配置与游戏数据分离存储
- 备份文件独立签名
- 插件包运行在受限沙箱环境中

## 隐私保护

HMOL 承诺：

- 不上传任何游戏文件到服务器
- 不收集运行日志以外的任何用户数据
- 更新检查仅比对版本号，不传输用户标识

如有安全问题，请通过 Github Issues 或官方 QQ 群反馈。
