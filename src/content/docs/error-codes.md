## 启动与门锁

### `E12.01` 启动被拦

**代码位置**：`src/HMOL.Core/Security/SurviveGate.cs`

**会看到**：

- 标题「**启动已暂停**」；
- 情形一：**此版本 HMOL 暂停支持！请联系域管理员！**
- 情形二：**未能验证启动授权，已禁用启动**，并附「原因：GitHub、Gitee 都读不到配置（断网 / 被墙 / 超时）」。

**原因**：程序启动时会联网读取一个开关（GitHub 优先、Gitee 备用）。「读到暂停」与「联网都读不到」都会阻止启动——这是刻意的严格模式。

**处理**：恢复网络后重开；确认可访问 `raw.githubusercontent.com` 与 `gitee.com`；关闭代理 / VPN 后重试。若持续如此，请联系发布者。

### `Hello Mental Omega Launcher 已经在运行了。`

程序**单实例运行**。请用系统托盘菜单的「显示主窗口」唤起已有窗口，或先退出再重开。

### `缺少组网组件，请重新解压完整发行包`

`runtime\` 目录缺失（或缺少其中某个组件，会追加「（缺少 xxx）」）。发行包的组网组件不会被打进 `HMOL.exe`，请重新完整解压。

## 游戏实例

**代码位置**：`src/HMOL.Core/Instances/InstanceManager.cs`

| 提示                                   | 原因                         | 处理                         |
| -------------------------------------- | ---------------------------- | ---------------------------- |
| `实例名称和路径不能为空`               | 名称或路径未填               | 补全表单                     |
| `实例名称已存在`                       | 名称与现有实例重复           | 换名称                       |
| `指定路径不是有效的心灵终结游戏目录`   | 不满足游戏目录识别规则       | 选含特征文件的 MO 目录       |
| `该游戏路径已被其他实例使用`           | 同一路径被多个实例占用       | 换目录或复用已有实例         |
| `实例不存在`                           | 实例已被外部删除             | 刷新列表 / 重建              |
| `实例名称不能为空`                     | 重命名时留空                 | 输入非空名称                 |
| `删除实例时出错：<原因>`               | 删除目录时出错（占用 / 权限）| 关闭占用程序；检查权限       |

**成功类提示**（用于确认操作结果）：`实例「x」创建成功`、`实例信息已更新`、`实例重命名成功：「旧」→「新」`、`实例「x」已删除`。

### 启动游戏时的提示

**代码位置**：`src/HMOL.Core/Launch/GameLauncher.cs`

| 提示                                                         | 处理                                         |
| ------------------------------------------------------------ | -------------------------------------------- |
| `游戏目录不存在：<目录>`                                     | 在实例页更新路径                             |
| `未找到游戏主程序（Mental_Omega_client.exe / MentalOmegaClient.exe / Mental_Omega.exe）：<目录>` | 检查游戏文件是否完整       |
| `启动游戏失败：<原因>`                                       | 见 [故障排查](/docs/troubleshooting/#-启动游戏失败) |

> 主页状态提示：**就绪 / 运行中 / 目录不可用**；「目录有效但未找到游戏主程序，启动会失败，请检查游戏文件是否完整。」

## 实例导入与导出

**代码位置**：`src/HMOL.Core/Instances/InstanceArchive.cs`

### 导出

| 提示                                             | 原因                                           |
| ------------------------------------------------ | ---------------------------------------------- |
| `导出路径不能为空`                               | 未选保存位置                                   |
| `游戏路径不存在：<路径>`                         | 实例游戏目录已失效                             |
| `导出目录不存在：<目录>`                         | 目标目录被删                                   |
| `目标文件已存在，请先删除或更换名称：<文件>`     | 同名文件已存在（界面通常已先询问覆盖）         |
| `无法导出为 rar：RAR 是专有格式，没有可用的写入实现…` | 选了 `.rar`（只支持 `.zip` / `.7z` 导出）  |
| `不支持的导出格式，请使用 .zip / .7z`            | 扩展名不受支持                                 |
| `实例中没有文件可导出`                           | 游戏目录为空                                   |
| `无法为游戏目录建立目录联接（…）。目录联接需要 NTFS 分区，请改用 .zip 导出。` | 7z 导出在非 NTFS 盘上失败 |
| `导出失败：<原因>`                               | 见日志                                       |

### 导入

| 提示                                             | 处理                                           |
| ------------------------------------------------ | ---------------------------------------------- |
| `文件不存在`                                     | 确认实例包还在                                 |
| `只支持 .zip / .7z / .rar 格式的实例包…`         | 换用受支持的格式                               |
| `无效的实例文件：缺少配置文件`                   | 实例包缺少 `instance_info.json`，重新获取包    |
| `配置文件格式错误`                               | 包内配置损坏                                   |
| `无法找到游戏文件目录（game_files）`             | 包结构不完整                                   |
| `解压的文件不是有效的心灵终结游戏目录`           | 包内游戏文件不完整                             |
| `游戏文件为空，导入失败` / `复制游戏文件失败：所有 N 个文件均无法复制` | 磁盘 / 权限问题    |
| `导入已取消`                                     | 用户取消                                       |

> 导入同名实例时会**自动改名**为「原名 (n)」，导入成功后自动设为当前实例。

## 包管理与安装卸载

**代码位置**：`src/HMOL.Core/Packages/PackageInstaller.cs`、`PackageLibrary.cs`

### 安装

| 提示                                                 | 处理                                     |
| ---------------------------------------------------- | ---------------------------------------- |
| `未指定实例` / `包名为空`                            | 先选实例与包                             |
| `当前实例的游戏目录已不存在或被移动：<目录>…`        | 更新实例路径                             |
| `包文件不存在：<路径>`                               | 包已从管理器目录移除，重新导入           |
| `解压失败：<原因>`                                   | 压缩包损坏 / 加密，换包或重新下载        |
| `压缩包内容为空，未解压到任何文件`                   | 换包                                     |
| `目标目录已存在且无法替换：<目录>`                   | 关闭占用程序后重试                       |
| `安装源中没有可复制的文件`                           | 换包                                     |
| `安装失败：所有 N 个文件均无法复制`                  | 关闭游戏 / 杀软；以管理员身份运行        |
| `安装后目标目录为空，可能复制失败`                   | 见日志                                   |
| `安装已取消，已回滚本次改动`                         | 正常提示                                 |
| `⚠️ 文件已装到游戏目录，但安装记录写入失败…`          | 重启后「已安装」列表可能不显示该包，也无法精确卸载 |

### 卸载

| 提示                                                                   | 处理                               |
| ---------------------------------------------------------------------- | ---------------------------------- |
| `未找到原版游戏备份。请先执行「备份原版游戏」…`                        | 先备份原版                         |
| `未找到该包的精确安装记录，且当前不允许全量恢复原版。`                 | 改用「全量恢复原版」               |
| `原版备份为空，未恢复任何文件`                                         | 重新执行「备份原版游戏」           |
| `卸载失败：所有 N 个文件均无法复制`                                    | 关闭占用程序 / 提权后重试          |
| 地图卸载：`在 Maps\Custom 中未找到与「x」匹配的文件…仅清除了安装记录。` | 文件已被手动删除，属正常提示       |

### 导入 / 移除包

| 提示                                             | 处理                                 |
| ------------------------------------------------ | ------------------------------------ |
| `所选文件不存在：<路径>`                         | 重新选择文件                         |
| `目标目录已存在同名文件：<路径>`                 | 选择覆盖或改名                       |
| `导入失败：<原因>`                               | 见日志                               |
| `包文件不存在：<路径>`                           | 该包已不在管理器目录                 |
| `移除失败：<原因>\n文件可能被占用或权限不足…`    | 关闭占用程序后重试                   |

> **移除**只删包管理器目录里的源文件；**卸载**才动游戏目录。

## 备份与还原

**代码位置**：`src/HMOL.Core/Backup/BackupService.cs`

### 备份名称校验

| 提示                                                             | 处理                     |
| ---------------------------------------------------------------- | ------------------------ |
| `备份名称不能为空` / `备份名称不能仅包含空白字符`                | 输入名称                 |
| `备份名称「x」为系统保留名称，禁止使用。…`                       | 避开 `MO`/`原版` 等保留名 |
| `备份名称包含非法字符，请避免使用：< > : " / \ | ? * 以及控制字符` | 换名称                   |
| `备份名称过长（最大 100 字符）`                                  | 缩短名称                 |

### 备份

| 提示                                             | 处理                                   |
| ------------------------------------------------ | -------------------------------------- |
| `源目录无效，无法备份：<目录>`                   | 检查实例路径                           |
| `已存在同名备份：<目录>`                         | 选择覆盖或换名                         |
| `实例中没有可备份的文件`                         | 游戏目录为空                           |
| `备份失败：所有 N 个文件均无法复制`              | 关闭占用程序 / 检查磁盘                |
| `备份完整性校验失败：备份目录为空`               | 见日志                                 |
| `备份已取消`                                     | 正常提示                               |
| `原版游戏备份已存在：<目录>`                     | 选择覆盖                               |
| `所选目录不是有效的心灵终结游戏目录：<目录>…`    | 确认实例当前是原版且路径有效           |

### 还原

| 提示                                                     | 说明                                   |
| -------------------------------------------------------- | -------------------------------------- |
| `备份目录不存在：<目录>`                                 | 备份被删，刷新列表                     |
| `目标目录为空` / `目标目录无法解析`                      | 实例路径异常                           |
| `无法移走目标目录现有内容：<项>`                         | 关闭占用程序后重试                     |
| `备份内容为空，未恢复任何文件`                           | 备份不完整                             |
| `恢复失败：所有 N 个文件均无法复制`                      | 磁盘 / 权限问题                        |
| `恢复已取消，已回滚本次改动`                             | 正常提示                               |
| `⚠️ 恢复后未能识别为有效的心灵终结游戏目录，请手动检查…` | 恢复成功但目录不完整，请人工确认       |

> 还原是**不可撤销**的破坏性操作；程序会在复制失败或取消时自动回滚。

## 设置与外观

### 常用网站

**代码位置**：`src/HMOL.App/Pages/PageSettings.xaml.cs`

| 提示                                                     | 处理                       |
| -------------------------------------------------------- | -------------------------- |
| `名称与网址都要填。`                                     | 补全两项                   |
| `网址不合法：只支持 http / https 且要有完整主机名（现在是 …）。` | 填完整网址（不写协议按 https 补全） |
| `这个网址已经在列表里了。`                               | 去掉重复                   |

### 天气城市

| 提示                                     | 处理                                               |
| ---------------------------------------- | -------------------------------------------------- |
| 解析失败 / `找不到城市…`                 | 换个常见写法（如「北京」「Shanghai」）后点「验证城市」 |
| `天气数据暂时取不到，请稍后再试`         | 检查网络后点主页天气卡右上角刷新重试               |

### 主页背景 / 壁纸包

**代码位置**：`src/HMOL.Core/Appearance/BackgroundService.cs`、`WallpaperPackageService.cs`

| 提示                                                     | 处理                             |
| -------------------------------------------------------- | -------------------------------- |
| `文件不存在。`                                           | 重新选择文件                     |
| `不支持的文件类型（.xxx）。可用的有：…`                  | 换受支持的图片 / 动图 / 视频     |
| `导入背景失败：<原因>`                                   | 见日志                           |
| 壁纸包相关失败（解包失败 / 未找到可用素材）              | 确认是 Wallpaper Engine 导出的 `.pkg` / `.mpkg` |

### 扩展模块

**代码位置**：`src/HMOL.Core/Extensions/ExtensionStore.cs`、`ExtensionValidator.cs`

单个扩展出问题时**只影响它自己**，设置页列表里会以红字给出可读原因，例如：

- `文件读不出来（原因）` / `文件内容是空的`；
- `不是有效的清单 JSON（第 N 行第 M 列）：…`（直接定位写错的位置）；
- `解析清单失败：…`；
- `扩展名不合法：只能写在扩展目录里，不能包含路径分隔符或上跳片段`；
- `这个扩展的清单文件已经不在了（可能被手工删除），点「重新加载」刷新列表。`；
- `保存失败：…` / `删除失败：…`。

> 字段与校验规则见仓库 `docs/extensions.md`。

## 日志中的级别

日志文件里每行形如 `[时间] [级别] [模块] 正文`：

| 级别    | 含义                         |
| ------- | ---------------------------- |
| `DEBUG` | 细节信息（含自检信息）       |
| `INFO`  | 正常运行信息                 |
| `WARN`  | 可继续但需注意（如跳过文件） |
| `ERROR` | 操作失败                     |
| `FATAL` | 界面线程未处理异常           |

日志位置与保留策略见 [故障排查 → 日志查看方法](/docs/troubleshooting/#日志查看方法)。

## 附录：数据位置

| 内容                 | 位置                                                         |
| -------------------- | ------------------------------------------------------------ |
| 全局设置             | `Data\Settings.json`                                         |
| 联机配置             | `Data\multiplayer.json`                                      |
| 实例配置             | `Data\instances\<id>.json`                                   |
| 精确安装记录         | `Data\instances\<id>\install_records\<类型>\<包名>.json`     |
| 包管理器目录         | `Data\packages\{ini,map,mission,plugin}\`                    |
| 备份                 | `Data\backup\MO\`（原版）、`Data\backup\game\<名称>\`（用户） |
| 背景素材             | `Data\backgrounds\`                                          |
| 布局方案             | `Data\layouts\`                                              |
| 扩展清单             | `Data\extensions\`                                           |
| 日志                 | `Data\Log\`                                                  |
| 门锁缓存 / 壁纸解包工具 | `Data\Cache\`                                             |

> 数据目录可用环境变量 `HMOL_DATA` 重定向。
