> 本章介绍 HMOL 启动器（C# / .NET 8 版）的系统要求、下载方式、解压与首次启动。

***

## 1. 系统要求

### 最低配置

| 项目     | 要求                   |
| -------- | ---------------------- |
| 操作系统 | Windows 10 1809+（x64） |
| 架构     | x64                    |
| 磁盘空间 | 除游戏本体外预留数百 MB |

### 推荐配置

| 项目     | 要求                     |
| -------- | ------------------------ |
| 操作系统 | Windows 10 21H2+ / Windows 11（x64） |
| 磁盘     | SSD                      |

> ✅ **无需另装任何运行库**：不需要单独安装 .NET 运行时，也**不需要 VC++ 运行库**。
> 发行包是一个**自包含单文件 `HMOL.exe`**（`build.bat` 里以 `--self-contained true` + `PublishSingleFile` 打包，内含 .NET 8 运行时）。

### 发行包结构

发行包名为 **`HMOL-v<版本>-win-x64.zip`**（版本号取自 `AppInfo.cs`），解压后至少包含：

```
HMOL.exe          ← 自包含单文件程序（内置 .NET 8 运行时）
LICENSE           ← 许可声明（保留所有权利）
README.md / NOTICE
runtime\          ← 组网组件（联机功能所需）
  ├─ 7zip\        ← 7za.exe（实例导出 .7z 用）
  ├─ easytier\    ← EasyTier
  ├─ n2n\         ← n2n（edge.exe / supernode.exe）
  ├─ tap\         ← TAP 虚拟网卡驱动
  └─ winipbroadcast\
```

> ⚠️ **必须完整解压整个压缩包**（包含 `runtime\` 目录）。
> 程序运行时会就近调用 `runtime\` 下的组网组件；**只把 `HMOL.exe` 单独拷走会导致联机功能不可用**（联机页会提示「缺少组网组件，请重新解压完整发行包」）。

## 3. 解压与存放位置

- **建议解压到非系统盘**（如 `D:\HMOL\`）；放在 `C:\Program Files\` 会被 UAC 限制写操作，需要以管理员身份运行
- 程序的数据都在 exe 同级的 `Data\` 目录内，**复制整个目录即可备份 / 迁移**
- **不要用新版本覆盖式解压到正在使用的目录**，建议解压到新目录后再处理数据（见下文「升级与卸载」）

### 数据目录结构（运行时生成）

```
Data\
  ├─ Settings.json      ← 全局设置（主题、背景、BGM、昵称、常用网站…）
  ├─ multiplayer.json   ← 联机配置（方案、节点、房间、收藏队友…）
  ├─ instances\         ← 实例配置（<id>.json）与实例数据（<id>\install_records\）
  ├─ packages\          ← 包管理器目录：ini / map / mission / plugin 四类
  ├─ backup\            ← 备份：backup\MO（原版）、backup\game\<名称>（用户备份）
  ├─ backgrounds\       ← 主页背景素材
  ├─ layouts\           ← 界面布局方案
  ├─ Cache\             ← 缓存（含门锁缓存与壁纸解包工具）
  ├─ Log\               ← 日志
  └─ extensions\        ← 扩展模块清单（不存在时不会被创建）
```

> 💡 数据目录可用环境变量 **`HMOL_DATA`** 重定向到任意路径。

## 4. 首次启动

1. 双击 `HMOL.exe`。
2. 程序会先做一次**联网门锁校验**（见下），然后加载设置、实例与包目录，并显示主窗口。
3. 首次进入没有实例，主页会引导你创建第一个实例：

   1. 进入「**游戏实例**」→「**新建实例**」；
   2. 填写**实例名称**，用「浏览」选择**心灵终结安装根目录**；
   3. 目录需能被识别为有效的心灵终结目录（见 [FAQ - 什么算有效的游戏目录](/docs/faq/#q-什么算有效的心灵终结游戏目录)）；
   4. 创建后建议先执行「**备份原版游戏**」，把原版文件备份到 `backup\MO`（这是后续精确卸载与全量恢复的前提）。

### 关于启动门锁

程序启动时会联网读取 `survive` 分支上的开关（GitHub 优先、Gitee 备用）：

- 读到「暂停支持」或**联网也读不到配置**（断网 / 被墙 / 超时）都会**阻止启动**，并给出错误代码 **E12.01**；
- 断网环境请先恢复网络再启动；两次校验失败时可重试。

> 这是刻意设计的「严格模式」，不是安装问题。详见 [错误信息与解决](/docs/error-codes/)。

### 关于单实例与系统托盘

- **单实例运行**：程序已在运行时再次双击，只会提示「已经在运行了」并退出。
- **系统托盘**：主窗口点「关闭」默认只是**收起到系统托盘**；要真正退出请用托盘菜单的「退出程序」。托盘不可用时，关闭窗口即退出。

## 5. 升级与卸载

### 升级

1. 退出正在运行的 HMOL（托盘菜单 →「退出程序」）；
2. 下载新版本的 `HMOL-v<版本>-win-x64.zip` 并**解压到新目录**；
3. 把旧目录里的 **`Data\`** 整个复制到新目录；
4. 运行新目录的 `HMOL.exe` 验证功能正常后，再删除旧目录。

### 卸载

1. 退出程序；
2. 如果开过「开机自启」，先在**设置 → 开机自启**里关闭（它会删除 `HKCU\...\Run` 下名为 `HMOL` 的启动项）；也可以手动删除；
3. 删除启动器所在目录（含 `Data\`）即可，程序不写其它系统位置。

> 如果需要保留存档 / 备份，可只删 `HMOL.exe` 与 `runtime\`，保留 `Data\`。

## 6. 常见安装问题

### 双击没反应 / 一闪而过

- 确认已**完整解压**（不要直接在压缩软件里双击运行）；
- 查看 `Data\Log\` 下最新日志（首次启动若连日志都没有，多半被安全软件拦截）；
- 将启动器目录加入杀毒软件信任区。

### 提示「已经在运行了」

说明已有一个实例在运行：到任务栏托盘中找到 HMOL 图标，用托盘菜单的「显示主窗口」唤起，或先退出再重开。

### 提示「缺少组网组件，请重新解压完整发行包」

`runtime\` 目录缺失。请重新完整解压发行包；该目录**不会**被打进 `HMOL.exe`，属于必需的外部组件。

### 提示「未能验证启动授权 / 此版本 HMOL 暂停支持」（错误代码 E12.01）

属于[启动门锁](#关于启动门锁)拦截。恢复网络后重试；若持续如此，请联系发布者。
