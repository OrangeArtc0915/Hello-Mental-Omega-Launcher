## 安装与启动

### Q: 从哪里下载 HMOL？

从官方渠道：

| 渠道            | 链接                                                                     |
| --------------- | ------------------------------------------------------------------------ |
| GitHub Releases | <https://github.com/OrangeArtc0915/Hello-Mental-Omega-Launcher/releases> |
| Gitee Releases  | <https://gitee.com/orangearc655743/Hello-Mental-Omega-Launcher/releases> |
| QQ 群           | `1034243331`                                                             |

⚠️ 其它渠道的二进制可能已被修改，同时也违反本项目的许可。

### Q: HMOL 需要安装吗？需要装别的运行库吗？

**都不需要。** 下载 `HMOL-v<版本>-win-x64.zip`，**完整解压**后双击 `HMOL.exe` 即可。程序是**自包含单文件**，已内置 .NET 8 运行时，也不需要 VC++ 运行库。

### Q: 解压后只把 HMOL.exe 拷走可以吗？

**不可以。** 发行包里的 `runtime\` 目录是联机功能的组网组件，**不会**被打进 exe。只拷 exe 会导致联机不可用（会提示「缺少组网组件，请重新解压完整发行包」）。请保留完整目录。

### Q: 解压到 `C:\Program Files\` 后能写入数据吗？

程序把数据写在 exe 同级的 `Data\` 目录。放在 `C:\Program Files\` 会受 UAC 限制。**建议解压到非系统盘**（如 `D:\HMOL\`）；如必须放在受保护目录，请以管理员身份运行，或用环境变量 `HMOL_DATA` 把数据目录指向可写位置。

### Q: 支持 Windows 7 / 8.1 吗？

**不支持。** 仅支持 Windows 10 1809+ 与 Windows 11（x64）。

### Q: 启动时提示「未能验证启动授权」/「此版本 HMOL 暂停支持」，错误代码 E12.01？

这是**启动门锁**：程序启动时会联网读取一个开关。除了「被暂停」会拦，**联网也读不到配置（断网 / 被墙 / 超时）同样会拦**——这是刻意的严格模式。

处理：恢复网络后重试；确认能访问 GitHub / Gitee 后仍未通过，请联系发布者。详见 [错误信息与解决](/docs/error-codes/)。

### Q: 双击没反应 / 一闪而过？

1. 确认**完整解压**后再运行（不要直接在压缩软件里双击）；
2. 查看 `Data\Log\` 下是否有日志文件（连日志都没有，多半被安全软件拦截）；
3. 把启动器目录加入杀毒软件信任区。

### Q: 提示「已经在运行了」？

程序**单实例运行**。已有实例在跑时再次双击只会提示并退出。到系统托盘找到 HMOL 图标，用托盘菜单的「显示主窗口」唤起；或先退出再重开。

## 游戏实例

### Q: 什么算「有效的心灵终结游戏目录」？

目录满足**以下任一条**即有效（判定规则与代码一致）：

1. 目录下存在 `Mental_Omega` 子目录；
2. 路径本身就叫 `Mental_Omega`；
3. 目录下存在 `MentalOmegaClient.exe` 或 `Mental Omega.exe`；
4. 其**父目录**下存在上述特征可执行文件（允许选到安装根的子目录）。

> 注意：识别用的文件名（`MentalOmegaClient.exe` / `Mental Omega.exe`）与**启动时**查找的主程序名不完全一样——启动按顺序找 `Mental_Omega_client.exe` → `MentalOmegaClient.exe` → `Mental_Omega.exe`。

### Q: 一个游戏目录可以绑定到多个实例吗？

**不可以。** 同一路径不能被两个实例共用（会提示「该游戏路径已被其他实例使用」）。如需多版本共存，请把游戏安装到不同目录。

### Q: 删除实例会删除游戏本体吗？

**一般不会。** 删除实例只移除实例配置与实例数据目录 `Data\instances\<id>\`，**不会删除游戏目录**。

**例外**：通过「导入实例」创建的实例，其游戏目录就在实例数据目录内，删除实例会**一并删除其中的游戏文件**。确认框会明确提示。

### Q: 导出实例支持哪些格式？为什么不能导出 .rar？

支持 **`.zip`** 与 **`.7z`**。RAR 是专有格式，**没有任何可用的写入实现**（WinRAR 的商业组件不能随包分发），因此只支持**导入** `.rar`，不支持导出。

### Q: 导入实例时提示「解压的文件不是有效的心灵终结游戏目录」？

说明实例包里的 `game_files\` 没有通过游戏目录识别。请确认该实例包本身完整、且导出时指向的是有效游戏目录。

### Q: 怎么迁移到新电脑？

复制**整个启动器目录**即可（含 `Data\`）。HMOL 没有账号体系，也不存机器绑定的凭据，因此没有「换机后要重新登录」的问题。

## 包管理

### Q: 有哪些类型的包？

当前共 **四类**：**INI 包 / 地图包 / 任务包 / 插件包**，分别对应包管理器目录下的 `ini` / `map` / `mission` / `plugin`。

### Q: 支持哪些压缩格式？

导入 `.zip` / `.7z` / `.rar` 均可；导出（实例包）支持 `.zip` / `.7z`。

### Q: 安装时提示需要先创建实例？

安装 / 卸载都作用于**当前实例**。请先在「游戏实例」页创建并选择一个实例。

### Q: 安装时提示「目标目录已存在」，选「替换」会删除整个游戏目录吗？

**不会。** 程序采用**文件级合并**：只有「目录形式的包」且目标目录已存在时才会先移走该目标目录再铺新内容；压缩包一律解压合并到游戏根目录，不会清空游戏目录。安装过程可取消，失败或取消会回滚。

### Q: 卸载时的「选择性卸载」和「全量恢复原版」有什么区别？

| 维度       | 选择性卸载                     | 全量恢复原版                     |
| ---------- | ------------------------------ | -------------------------------- |
| 范围       | 只删该包装进游戏目录的文件     | 清空整个游戏目录后用原版覆盖     |
| 前置条件   | 存在该包的**精确安装记录**     | 必须存在 `backup\MO` 原版备份    |
| 还原被覆盖 | 从 `backup\MO` 还原原版文件    | N/A（整体用原版覆盖）            |
| 其它包     | 不受影响                       | ⚠️ **全部被移除**                |

### Q: 提示「未找到原版游戏备份，无法卸载」？

按包卸载（选择性卸载）与全量恢复都需要 `backup\MO`。请先在「游戏实例」页执行「**备份原版游戏**」。

### Q: 「移除」和「卸载」有什么区别？

- **移除**：删除 `packages\<类型>\` 里的**源文件**，不影响游戏目录；
- **卸载**：把某个包从**游戏目录**里撤掉（删文件 / 还原被覆盖的原版文件）。

## 备份与还原

### Q: 备份存在哪里？

| 类型         | 位置                       |
| ------------ | -------------------------- |
| 用户备份     | `Data\backup\game\<名称>\` |
| **原版备份** | `Data\backup\MO\`（固定）  |

### Q: 备份名称有什么限制？

- 不能为空，长度 ≤ 100 字符；
- 不能含 `< > : " / \ | ? *` 及控制字符；
- 不能是保留名 `MO` / `mo` / `Mo` / `mO` / `MO.mo.mO` / `原版` / `原版游戏` / `原版游戏备份`。

### Q: 还原会做什么？能撤销吗？

还原会用备份**替换目标实例游戏目录中的所有现有文件与子目录**，**不可撤销**。还原前目标内容会先搬进隔离区，若复制中途失败或取消会**自动回滚**。

### Q: 删除原版备份有什么影响？

删除 `backup\MO` 后，**按包卸载（选择性卸载）与全量恢复都不可用**，需要重新执行「备份原版游戏」。

## 联机

> 联机功能详见 **[联机](/docs/multiplayer/)** 章节，这里只列常见疑问。

### Q: 联机需要登录账号吗？

**不需要。** 当前实现没有账号体系。联机用的是**设置 → 联机昵称**里填的昵称；进入大厅前必须先填昵称。

### Q: 有哪些组网方案？

**EasyTier**（三层，免装驱动，推荐）与 **n2n**（二层，需先安装 TAP 虚拟网卡驱动）。

### Q: n2n 提示需要 TAP 驱动？

n2n 依赖 TAP 虚拟网卡。在联机页的 n2n 工具里点「安装 TAP 驱动」，会以管理员身份运行发行包 `runtime\tap\` 下的安装程序；驱动已就绪时会提示无需重复安装。

### Q: 提示「缺少组网组件，请重新解压完整发行包」？

发行包的 `runtime\` 目录缺失。请重新完整解压。

### Q: 大厅是什么？聊天内容安全吗？

大厅是基于公共 MQTT 信标实现的公共广场，与你的房间组网相互独立。**大厅聊天是公开的**（内容经传输混淆，但应视为公开），请勿发送敏感信息；房间聊天仅房间成员可见。

## 设置与外观

### Q: 支持哪些主题？

明暗模式：**浅色 / 深色 / 跟随系统**；强调色：**默认 / 湖蓝 / 青绿 / 紫罗兰**。

### Q: 主页背景支持什么格式？

图片：`.jpg` / `.jpeg` / `.png` / `.bmp` / `.webp`；动图：`.gif`；视频：`.mp4` / `.wmv` / `.avi`。还支持导入 Wallpaper Engine 的 `.pkg` / `.mpkg` 壁纸包。

### Q: 背景音乐支持什么格式？

`.mp3` / `.wav` / `.wma` / `.m4a` / `.aac` / `.flac` / `.ogg`（实际能否解码由系统 Media Foundation 决定，认不出的会在载入时跳过）。

### Q: 侧边栏能自定义吗？

可以。**设置 → 界面布局**打开布局编辑器，可调整左侧导航的**顺序 / 显隐 / 名称**，点「保存并应用」后立即生效。方案在 `Data\layouts\`。

### Q: 开机自启怎么关掉？

**设置 → 开机自启**里关一次开关即可（会删除注册表 `HKCU\...\Run` 下的 `HMOL` 项）。自启后程序只驻留系统托盘、不弹主窗口。

### Q: 扩展模块安全吗？能执行代码吗？

**不能执行代码，这是刻意设计。** 扩展只是一份 JSON 清单，启动器只把清单里的文字 / 图标 / 网址画成卡片，不加载程序集、不跑脚本、不改你的系统；数据源只做 `http`/`https` 的只读 GET，且可在设置里一键关闭联网。详见仓库 `docs/extensions.md`。

## 日志与反馈

### Q: 日志在哪里？

`Data\Log\` 下，文件名形如 `HMOL-2026-9-25-192828382.log`。也可在「运行日志」页直接查看、导出 TXT / CSV，或点「打开日志目录」。

### Q: 怎么彻底卸载？

退出程序 →（如开过）关闭开机自启 → 删除启动器所在目录（含 `Data\`）即可。程序不写其它系统位置。

### Q: 怎么报告 Bug？

在 [GitHub Issues](https://github.com/OrangeArtc0915/Hello-Mental-Omega-Launcher/issues) 提交，附上：

1. HMOL 版本号；
2. Windows 版本；
3. 复现步骤；
4. `Data\Log\` 下相关日志片段（「运行日志」页可导出）。

**注意**：本项目不接受代码修改类的 PR。

### Q: 在哪里查看当前版本号？

- 标题栏右侧（形如 `v1.0.0`）；
- 设置 → 「关于与存储」卡片；
- 关于窗口。

版本号唯一来源是 `src/HMOL.Core/App/AppInfo.cs`。
