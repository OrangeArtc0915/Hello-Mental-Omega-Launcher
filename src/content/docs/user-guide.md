> 本章介绍 HMOL 启动器（C# / .NET 8 版）的主界面、各页面功能与日常使用流程。
> 界面文案与按钮以当前实现为准。

***

## 1. 界面总览

### 1.1 侧边栏导航

左侧边栏固定六个页面，底部固定一个「关于」入口（点击打开独立窗口，不参与页面切换）：

| 入口             | 图标 | 功能                                                     |
| ---------------- | ---- | -------------------------------------------------------- |
| 🏠 **主页**       | 仪表盘 | 问候横幅、月历 / 天气 / 常用网站小组件、扩展卡片、当前实例、启动按钮 |
| 📚 **游戏实例**   | 层叠 | 实例增删改查、导出 / 导入、启动；备份 / 还原区块          |
| 📦 **包管理**     | 包裹 | 四类包的可用 / 已安装列表、导入、安装、卸载               |
| 🌐 **联机**       | 网络 | 组网（网络设置）、联机大厅、在线对端、工具箱              |
| 📜 **运行日志**   | 卷轴 | 应用日志 / 游戏日志 / 磁盘日志三视图、导出、清理          |
| ⚙️ **设置**       | 齿轮 | 主题、联机昵称、天气城市、常用网站、背景、背景音乐、布局、扩展、开机自启 |
| ℹ️ **关于**（底部） | 信息 | 版本、仓库、QQ 群（独立窗口）                            |

> 侧边栏的顺序、显隐与名称可在**设置 → 界面布局**里自定义（见下文「设置」）。

### 1.2 标题栏与托盘

- 标题栏显示程序名与版本号，右侧为最小化 / 最大化 / 关闭。
- 点「关闭」默认**收起到系统托盘**（不是退出）；用托盘图标右键菜单的「显示主窗口 / 连接联机 / 退出程序」操作。
- 左键单击托盘图标可恢复主窗口；托盘提示会显示联机状态。
- 若系统托盘不可用，关闭窗口即退出程序。

### 1.3 日常流程

```
启动 HMOL → 主页确认当前实例 → 点「启动游戏」→ 游玩 → 关闭游戏
（需要装包/备份时进「包管理」/「游戏实例」；需要联机时进「联机」）
```

## 2. 主页

主页由四部分构成：问候横幅、舞台（当前实例卡）、切换实例列表、三个内置小组件 + 扩展卡片。

### 2.1 问候横幅

按时段显示问候语，并用一句话说明当前状态：无实例时引导创建；有实例时显示实例名与「目录可用 / 目录不可用 / 正在运行中」。

### 2.2 当前实例与启动

- 「当前实例」卡显示：实例名、游戏目录、状态胶囊（**就绪 / 运行中 / 目录不可用**）、上次启动时间、备注。
- **启动按钮**：目录有效时可用，点击后启动游戏；游戏运行中时按钮变为「停止游戏」（会结束游戏进程）。
- 若目录有效但**找不到主程序**，会提示「目录有效但未找到游戏主程序，启动会失败」。

### 2.3 切换实例

主页右侧列出全部实例，点击某一行即把它设为当前实例（当前实例行以播放图标标识）。

### 2.4 小组件

| 小组件       | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 📅 **月历**   | 现实月历，今天用强调色高亮；可用左右箭头翻月，点标题回到本月 |
| 🌦️ **天气**   | 现实天气。需先在**设置 → 天气城市**填城市名；数据来自 Open-Meteo（免费、无需 Key），30 分钟内复用缓存，右上角可强制刷新 |
| 🔗 **常用网站** | 显示**设置 → 常用网站**里的站点，点击用系统默认浏览器打开     |
| 🧩 **扩展卡片** | 来自 `Data\extensions\` 下的 JSON 清单（见下文「设置 → 扩展模块」），每个扩展一张卡 |

> 天气与扩展需要联网时才发请求；失败只改文案、不弹窗，不影响其它小组件。

## 3. 游戏实例

实例 = 一个游戏安装目录 + 独立的已安装记录与安装记录目录。实例只记录「游戏装在哪」，**不会复制游戏本体**。

### 3.1 新建实例

**路径**：「游戏实例」→「新建实例」

| 字段     | 必填 | 说明                                                         |
| -------- | ---- | ------------------------------------------------------------ |
| 实例名称 | ✅   | 不能为空，不能与现有实例重名（忽略大小写）                   |
| 游戏路径 | ✅   | 需被识别为有效的心灵终结目录（见 [FAQ](/docs/faq/#q-什么算有效的心灵终结游戏目录)） |
| 备注     | ❌   | 仅展示用                                                     |

**校验失败时的提示**（与代码一致）：

| 提示                         | 原因           |
| ---------------------------- | -------------- |
| 实例名称和路径不能为空       | 表单未填完整   |
| 实例名称已存在               | 名称重复       |
| 指定路径不是有效的心灵终结游戏目录 | 路径不合法 |
| 该游戏路径已被其他实例使用   | 同一路径被多个实例占用 |

### 3.2 编辑 / 重命名 / 删除

- **编辑**：可改名称、路径、备注（三者可只改一部分）。
- **重命名**：走名称输入框，新名称不能为空、不能重名。
- **删除**：弹出二次确认。删除会移除实例配置与实例数据目录 `Data\instances\<id>\`；**游戏目录本身不会被删除**——但**导入的实例例外**（它的游戏目录就在实例数据目录内，会一并删除，确认框会明确提示）。

### 3.3 设为当前 / 启动 / 打开目录

- **设为当前**：把某个实例设为当前实例（主页与包管理都作用于当前实例）。
- **启动**：直接启动该实例的游戏；若已有游戏在运行会提示先关闭。
- **打开目录**：打开该实例的数据目录 `Data\instances\<id>\`。

### 3.4 导出实例

**路径**：「游戏实例」→ 实例卡片「导出」

- 导出格式：**`.zip`** 与 **`.7z`**（7z 会调用随包的 `runtime\7zip\7za.exe`）。
- **不支持导出 `.rar`**：RAR 是专有格式，没有可用的写入实现。
- 导出包结构：根下 `instance_info.json` + `game_files\`（游戏目录内容）。
- 目标文件已存在时会先询问是否覆盖。

### 3.5 导入实例

**路径**：「游戏实例」→「导入实例」

- 支持 `.zip` / `.7z` / `.rar`。
- 解压后校验 `game_files` 是有效的心灵终结目录，并把游戏文件复制到实例数据目录，建立新实例。
- **同名实例会自动改名**为「原名 (n)」；导入成功后自动设为当前实例。

### 3.6 备份与还原

见下文「备份与还原」一节。

## 4. 包管理

「包管理」页顶部分为四个页签：**INI 包 / 地图包 / 任务包 / 插件包**；每个页签下有「可用包」与「已安装」两个列表。

### 4.1 四类包

| 页签         | 目录         | 允许的扩展名                     | 安装落点                                        |
| ------------ | ------------ | -------------------------------- | ----------------------------------------------- |
| 📝 **INI 包** | `packages\ini\`     | `.zip` / `.7z` / `.rar` | 压缩包解压合并到游戏根目录                      |
| 🗺️ **地图包** | `packages\map\`     | `.map` 及压缩包         | 单个 `.map` 装到 `Maps\Custom`；压缩包合并到根目录 |
| 📋 **任务包** | `packages\mission\` | `.zip` / `.7z` / `.rar` | 压缩包解压合并到游戏根目录                      |
| 🧩 **插件包** | `packages\plugin\`  | `.zip` / `.7z` / `.rar` | 压缩包解压合并到游戏根目录                      |

包的形式：

- **压缩包**：安装时先解压到临时目录；若解压后只有一个顶层目录，则以其为内容根。
- **目录形式的包**：会整体落到 `游戏目录\包名`。
- **单个 `.map` 文件**：装到 `游戏目录\Maps\Custom`。

### 4.2 可用列表与已安装列表

- **可用包**：来自包管理器目录，显示类型（文件夹 / 压缩包 / 文件）与体积。已安装的包会标注。
- **已安装**：来自当前实例的已安装记录。若包目录里已找不到源文件，会提示「包目录里已找不到源文件，仍可按记录卸载」。

### 4.3 导入 / 移除包

- **导入**：把本地文件复制到对应类别的包管理器目录。同名文件会先询问是否覆盖。
- **移除**：只删除包管理器目录里的源文件，**不影响已装进游戏目录的内容**；若该包已被某些实例记为已安装，会一并提示。

### 4.4 安装

**路径**：在「可用包」列表点某个包的「安装」

安装前会先算出落点并给出确认；如果**目标目录已存在**：

- 无文件级冲突 → 询问「替换 / 取消」；
- 有文件级冲突 → 询问「覆盖全部 / 跳过已有 / 取消」（最多列出前 10 条冲突样例）。

安装过程会显示进度窗、可取消；**覆盖已有文件前会留下 `.bak-<时间戳>` 备份**，失败或取消会回滚本次已做的改动。

### 4.5 卸载

**路径**：在「已安装」列表点某个包的「卸载」

卸载选项**按实际情况给出**：

- **地图文件（单个 `.map`）**：直接从 `Maps\Custom` 删除，不需要原版备份。
- **选择性卸载**：只删该包装进游戏目录的文件，被它覆盖掉的原版文件从 `backup\MO` 还原。**前提是存在精确安装记录**。
- **全量恢复原版**：清空当前实例的游戏目录后，用 `backup\MO` 整体覆盖；**实例上安装的所有包都会被移除**（破坏性操作）。没有 `backup\MO` 时该选项不可用。

> 💡 **必须先在实例页执行过「备份原版游戏」**，否则既无法还原被覆盖的文件，也无法全量恢复。

## 5. 备份与还原

入口在「游戏实例」页底部的备份区块。

### 5.1 备份位置

| 类型         | 位置                              | 说明                       |
| ------------ | --------------------------------- | -------------------------- |
| 用户备份     | `Data\backup\game\<名称>\`        | 名称可自定义               |
| **原版备份** | `Data\backup\MO\`                 | **名称固定，不可改**       |

每个备份目录里有一份 `backup_info.json` 元数据（类型、来源实例、文件数、体积、创建时间等）。

### 5.2 备份名称规则

- 不能为空，长度 ≤ 100 字符；
- 不能包含 `< > : " / \ | ? *` 及控制字符；
- **禁用保留名**：`MO` / `mo` / `Mo` / `mO` / `MO.mo.mO` / `原版` / `原版游戏` / `原版游戏备份`。

### 5.3 创建备份 / 备份原版

- **备份游戏**：备份**当前实例**的游戏目录。默认名称形如 `<实例名>_yyyyMMdd_HHmmss`；同名备份存在时会询问是否覆盖。
- **备份原版游戏**：把当前实例的游戏目录备份为原版（固定放到 `backup\MO`）。请确认该实例当前是**原版状态**（未安装任何资源包）。

> 备份一律先写到临时目录、写完元数据后再整体搬到目标位置，避免半成品被当成可用备份。

### 5.4 还原

1. 在备份列表点选一个备份（原版备份与用户备份都列在这里）；
2. 点「还原」→ 二次确认；
3. 还原会**替换目标实例游戏目录中的所有现有文件与子目录**，**不可撤销**。

> ⚠️ 还原时目标目录现有内容会先搬进隔离区；复制失败或取消会**自动回滚**。还原完成后，若目录不再被识别为有效的游戏目录，会给出提醒。

### 5.5 删除备份

选中备份 →「删除」，二次确认后整个备份目录被删除。删除**原版备份**会使按包卸载与「恢复原版状态」不可用，需要重新执行「备份原版游戏」。

## 6. 联机

「联机」页包含四个页签：**网络设置 / 联机大厅 / 在线对端 / 工具箱**。

- **组网方案**：**EasyTier**（三层，免装驱动，推荐）与 **n2n**（二层，需先安装 TAP 虚拟网卡驱动）。
- **基本流程**：填房间名 → 选节点 → 点「连接」→ 成功后「分享给队友」把分享文本发给好友 → 对方「一键加入」。
- **大厅**：进入大厅后可看到在线玩家与公开房间，可收藏队友、邀请入房。
- **在线对端**：列出同房间的对端（IP / 延迟），房主可踢人 / 拉回，成员可开房间聊天。
- **工具箱**：连通性检测、防火墙、网卡优先级、TAP 安装、自建节点、文件传输、游戏 HUD 等。

> 联机功能完整说明见 **[联机](/docs/multiplayer/)** 章节。使用前请确认发行包里的 `runtime\` 目录完整。

## 7. 运行日志

「运行日志」页有三个页签：

| 页签           | 数据来源                                                     |
| -------------- | ------------------------------------------------------------ |
| 📄 **应用日志** | 内存环形缓冲（上限 500 行），实时刷新                        |
| 🎮 **游戏日志** | 游戏进程的输出（启动游戏时被捕获），同一内存缓冲             |
| 💾 **磁盘日志** | `Data\Log\` 下落盘的日志文件（单个文件最多渲染 2000 行）     |

- 顶部「刷新 / 清空 / 导出 TXT / 导出 CSV / 打开日志目录 / 清理旧日志」。
- **日志文件命名**：`HMOL-<年-月-日>-<时分秒毫秒>.log`，落在 `Data\Log\`。
- 落盘日志按**份数**保留最近 16 份、单文件上限 8 MB；「清理旧日志」按时间删除 **7 天前**的文件（正在写入的那份会跳过）。
- 导出 CSV 带 BOM，Excel 打开中文不乱码。

## 8. 设置

设置页的改动**立即生效并自动落盘**。共 9 张卡片：

### 8.1 外观

- **明暗模式**：浅色 / 深色 / 跟随系统；
- **强调色**：默认 / 湖蓝 / 青绿 / 紫罗兰，并给出色板预览。

### 8.2 联机昵称

联机时显示的本地昵称（用于大厅、聊天、收藏队友）。填好后点「保存昵称」；留空会提示未设置。

### 8.3 天气城市

主页天气小组件显示的城市，填城市名即可（如「北京」）。可点「验证城市」用 Open-Meteo 的地理编码服务确认能否解析出经纬度。

### 8.4 常用网站

主页「常用网站」小组件里的站点列表：

- 逐条添加（名称 + 网址），网址只允许 `http` / `https`（不写协议按 `https` 补全）；
- 每条可单独移除；
- 「恢复默认列表」会替换为项目自带的默认站点（本项目 GitHub / Gitee、心灵终结官网、官方 QQ 群）。

### 8.5 主页背景

- **选择图片 / 动图 / 视频**：支持 `.jpg` / `.jpeg` / `.png` / `.bmp` / `.webp` / `.gif`，以及 `.mp4` / `.wmv` / `.avi`；
- **导入壁纸包**：支持 Wallpaper Engine 导出的 `.pkg` / `.mpkg`，程序用内置工具解包并取其中的视频 / 图片；
- **清除背景**：恢复主题渐变；
- **模糊程度**（0–30）与**暗化程度**（0–80%）滑条。

> 素材会被复制进 `Data\backgrounds\`，所以原文件被删或被移走都不影响背景。视频背景只做暗化、不做模糊。

### 8.6 背景音乐

- **启用背景音乐**开关；开启后随程序启动自动播放；
- 播放列表：添加曲目（支持 `.mp3` / `.wav` / `.wma` / `.m4a` / `.aac` / `.flac` / `.ogg`）、移除当前曲目、逐条移除；
- 上一首 / 播放暂停 / 下一首、音量滑条；
- **循环**、**随机**开关；当前曲目高亮显示。

### 8.7 扩展模块

扩展是**一份 JSON 清单**，用来在主页加一张小组件卡片。

- **扩展目录**：`Data\extensions\`，一个 `.json` 文件 = 一个扩展，文件名（去掉 `.json`）就是它的 ID；
- **安全边界**：扩展**不会被「执行」**——启动器不加载程序集、不引入脚本引擎、不读写扩展以外的文件、不改注册表；
- **数据源**：清单里可选配一个数据源，只做 `http` / `https` 的**只读 GET**，有超时与内存缓存；**数据源联网总开关**可一键关闭；
- 支持：新建、编辑、启用 / 停用、删除、重新加载、打开扩展目录。

> 字段说明与示例见仓库 `docs/extensions.md` 与 `docs/extensions/示例.json`。

### 8.8 开机自启

- 开关一下即写入 / 删除注册表项 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下名为 `HMOL` 的值，命令行形如 `"<exe 全路径>" --autostart`；
- **自启后只驻留系统托盘、不弹出主窗口**，点托盘图标才打开界面；
- 程序被挪过目录时，注册表里的旧路径会在下次启动时自动改正；
- 状态以**注册表实际值**为准。

### 8.9 关于与存储

显示当前版本与**数据目录**（点击可打开）；数据目录可用 `HMOL_DATA` 重定向。

### 8.10 界面布局（布局编辑器）

「设置 → 界面布局」卡片可打开**布局编辑器**：调整左侧导航的**顺序 / 显隐 / 名称**。编辑过程不影响主界面，点「保存并应用」后立即生效；方案存在 `Data\layouts\` 下。另有「恢复默认布局」可清空「默认布局」的自定义。

> 列表底部还有一张「尚未实现的设置」卡片，明确列出当前尚未提供的选项（如窗口透明度、界面缩放）。

## 9. 关于窗口

**路径**：左侧导航底部「关于」

- 显示程序名、版本（取自 `AppInfo`）、作者；
- GitHub / Gitee 仓库与 Issues 链接；
- **QQ 群**：`1034243331`，可一键复制群号或一键加群。

***

## 10. 退出程序

- 主窗口点「关闭」→ **收起到系统托盘**（托盘可用时）；
- 要真正退出：右键托盘图标 →「退出程序」。

> 退出时会断开联机、停止文件接收、关闭游戏内 HUD、停播背景音乐并保存设置。
