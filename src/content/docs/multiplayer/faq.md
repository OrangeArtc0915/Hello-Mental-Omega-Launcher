## 1. 启动相关

### 在哪里打开联机功能？

联机功能**内置在 HMOL 主程序**里，左侧导航点「**联机**」即可。

### 提示「缺少组网组件，请重新解压完整发行包」？

发行包的 `runtime\` 目录缺失或不完整。请重新**完整解压**发行包（组网组件不会被打进 `HMOL.exe`）。

### 进大厅提示「请先在『设置 → 联机昵称』里填写昵称」？

到 **设置 → 联机昵称** 填好昵称并点「保存昵称」，再回联机页进入大厅。

### 提示需要管理员权限？

TAP 驱动安装、防火墙开关、网卡优先级修改都需要管理员权限，会弹 UAC 提权确认。**建议直接以管理员身份运行 HMOL**；若拒绝提权，这些操作不会执行（其余功能仍可用）。

## 2. 连接相关

### 连不上 / 一直显示连接中？

1. 用 **网络工具箱 → 连通性检测** 测 PING 节点与 NAT 类型；
2. 试 **防火墙控制 → 关闭防火墙**（需管理员），关闭后再连接；
3. 点 **节点测速** 换一个延迟低的节点，或到 **更多设置 → 自定义节点** 添加；
4. 查看「组网」页的「**引擎输出**」卡片，里面的报错最直接。

### 双方都能连，但互 ping 不通？

- 最常见原因是**防火墙拦截**，先关防火墙测试；
- 检查双方**房间名**与**加密密钥**是否一致；
- 检查虚拟 IP 是否在同一网段（n2n 手动模式请确认两人 IP **不相同**）；
- 注意：分享文本里的「房主: 否」是固定值，收到分享的一方一律按**成员**加入，属正常。

### 游戏里发现不到房间？

- 用 **网络工具箱 → 网卡优先级** 让广播优先走虚拟网卡；
- 或改用 **n2n** 方案（二层广播，见 [方案详解](/docs/multiplayer/engines/)）；
- 也可以直接填对方的**虚拟 IP** 进游戏。

### 房间名提示「最多 6 个字符」？

房间名（小组名）上限为 **6 个字符**。点「随机生成」可得到一个 6 位随机名。

### 手动虚拟 IP 填不进去？

手动 IP 必须是合法 IPv4，且**不能以 `.0` 或 `.255` 结尾**（网段 / 广播地址），否则会提示「手动虚拟 IP 格式不正确…」。

## 3. 方案相关

### 有哪些方案？

**EasyTier**（三层，默认推荐）与 **n2n**（二层，需 TAP 驱动）。

### n2n 提示需要 TAP 驱动？

到「组网方案」卡片 →「n2n 专属工具」→「**安装 TAP 驱动**」，装好后重连。已装过时会提示「系统里已经有 N 个 TAP 虚拟网卡，无需重复安装」。

### n2n 自动模式拿不到 IP？

公共 supernode 可能未开 DHCP 池。改为**手动 IP** 模式并让队友用不同 IP（如 `.66` 与 `.67`）；或者用有公网 IP 的机器自建 supernode（n2n 专属工具 →「服务端模式」）。

## 4. 大厅相关

### 进入大厅失败？

提示「所有大厅信标都不可用」时，说明公共 MQTT 信标都连不上。请稍后重试或检查网络。

### 大厅聊天安全吗？

**大厅是公开广场**，聊天内容对第三方可见（虽然做了传输混淆），**请勿发送敏感信息**。房间聊天仅房间成员可见。

### 发送大厅聊天被拒？

内容策略会拦截 **URL** 与违禁词；另外大厅聊天有**速率限制**，发得太快会被限流。

### 收藏队友存在哪？

存在本机 `Data\multiplayer.json` 的 `friends` 字段，**纯本地、不上传**。

### 怎么把房间公开给大厅？

先连接房间并进入大厅，再在「组网」页的「连接」卡片点「公开我的房间到大厅」。详见 [建房与加入](/docs/multiplayer/hosting/)。

## 5. 延迟 / 性能相关

### 延迟高？

- P2P 直连时延迟最低，走节点中转时偏高；
- 用「节点测速」选延迟低的节点；
- NAT 类型为「开放 / 锥形」时更易打洞成功（对称型 NAT 较差）。

### 游戏卡顿？

- 关闭无关下载 / 直播；
- HUD 浮窗可隐藏（点浮窗右上角 ×，或再点一次「游戏 HUD」按钮）。

## 6. 其他

### 文件传不出去？

确认双方都在同一房间且在线，单文件需 **≤ 500MB**，大文件先压缩再传。详见 [文件传输与 HUD](/docs/multiplayer/file-transfer-hud/)。

### 想自己搭节点？

n2n 方案可在「n2n 专属工具」→「服务端模式」用有公网 IP 的机器自建 supernode，然后把公网地址给队友填进节点栏。

### 出问题想反馈？

把「运行日志」页导出的日志，连同现象描述发到 [GitHub Issues](https://github.com/OrangeArtc0915/Hello-Mental-Omega-Launcher/issues) 或 QQ 群 `1034243331`。
