网络工具箱在「联机」页 →「**组网**」页签的「**网络工具箱**」卡片里，共 7 个按钮：

| 按钮 | 作用 |
| --- | --- |
| **连通性检测** | 聚合窗：PING / TCP 测速 / UDP 测速 / NAT 检测 |
| **防火墙控制** | 关闭 / 恢复 Windows 防火墙（需管理员） |
| **网卡优先级** | 把虚拟 IP 所在网卡的接口跃点数设为 1 |
| **文件传输** | 见 [文件传输与 HUD](/docs/multiplayer/file-transfer-hud/) |
| **更多设置** | 自定义节点、进程守护、开机自启 |
| **游戏 HUD** | 开关游戏内浮窗 |
| **大厅延迟代码** | 显示可复制的 `/framesendrate x` |

> 卡片说明原文：涉及系统改动的操作都会**先说明再执行**；装驱动、开关防火墙、改网卡跃点等需要管理员权限时会弹出系统提权确认。

---

## 1. 连通性检测

点「连通性检测」打开一个聚合窗，里面有四项：

- **PING 测试**：对目标主机发 4 次 `ping`（每次超时 2 秒），显示成功次数与平均延迟；
- **TCP 测速**：默认端口 `48771`（服务端 / 客户端成对使用）；
- **UDP 测速**：默认端口 `48772`；
- **NAT 检测**：用 STUN 服务器（`stun.qq.com` / `stun1.l.google.com` / `stun.miwifi.com`）判断 NAT 类型，结果为「开放(公网IP) / 锥形 NAT(受限锥形/全锥形) / 对称型 NAT / 检测失败」。

> 用途：判断「为什么连不上」——先 PING 节点，再看 NAT 类型，配合防火墙排查。对称型 NAT 打洞成功率较低。

---

## 2. 防火墙控制

点「防火墙控制」会先显示当前防火墙状态，然后让你选择：

- **关闭防火墙**（红）——让同一房间的机器互相发现（组网端口与游戏广播常被防火墙拦截）；
- **恢复开启**；
- **取消**。

修改防火墙**需要管理员权限**，会弹系统提权确认；不点确认不会执行任何改动。联机结束后建议恢复开启。

> 非管理员身份时，操作会直接返回「修改防火墙需要管理员权限（当前以普通权限运行）」。
> 另外，文件传输需要 TCP `17800` 入站放行，程序会尝试自动添加防火墙规则；权限不足时提示「需要管理员权限才能自动放行端口（可在 Windows 防火墙里手动放行）」。

---

## 3. 网卡优先级

连接后点「网卡优先级」，把**虚拟 IP 所在网卡**的接口跃点数设为 `1`，让游戏的局域网广播优先走虚拟网卡（避免被真实网卡抢走）。

- 原理：跃点数越小优先级越高；
- 该命令通常需要管理员权限；当前不是管理员时，即便执行成功也会提示「若游戏内仍发现不了房间，请以管理员身份重试」。

> 适用场景：游戏里局域网自动发现不到房间。

---

## 4. 节点测速

在「组网方案」卡片点「**节点测速**」，会打开一个窗口，**后台逐个测量当前方案的所有节点**（含自定义节点）：

- **EasyTier**：优先用 **TCP 建连耗时**（更接近真实连接体验），失败回退 PING；
- **n2n**：用 PING（3 次取平均）；
- 结果显示为 `N ms` 或「不可达」；**双击某行**或选中后点「应用」即切换为该节点。

---

## 5. 更多设置

点「更多设置」打开窗口，包含三项：

| 设置项 | 说明 |
| --- | --- |
| **自定义节点** | 添加 / 移除内置节点之外的自定义节点；添加重复项会提示「这个节点已经在列表里了。」 |
| **进程守护** | 守护组网引擎进程，异常退出自动重启（默认开启）；改动**立刻生效**，不用重连 |
| **开机自启** | 随系统登录自动运行（写 `HKCU\...\Run`，命令行带 `--autostart`，自启后只驻留托盘）；状态以**注册表实际值**为准 |

> 自定义节点会同时出现在「节点服务器」下拉框与节点测速窗里。

## 6. n2n 专属工具

选择 **n2n** 方案时，「组网方案」卡片下方会多出「n2n 专属工具」：

- **安装 TAP 驱动**：运行发行包 `runtime\tap\` 下的 `tapinstall.exe install OemVista.inf tap0901`，需要管理员权限。执行前会说明「做什么 / 为什么要管理员 / 会执行什么」；已存在 TAP 网卡时提示无需重复安装；
- **服务端模式**：本机自建 n2n **supernode**（需有公网 IP）。可填**监听端口**（1024–65535，默认 `9555`）与**自动分配 IP 池**（默认 `192.168.100.0/24`）；启动后显示「公网地址：`<ip:port>`（队友节点栏填这个）」。

> 自建节点在窗口关闭后仍会继续运行，直到手动「停止服务」或退出程序。

---

## 7. 配置与日志

- **联机配置**：`Data\multiplayer.json`（方案、节点、房间名、密钥、IP 模式、公开房间、自定义节点、收藏队友、进程守护、开机自启、自建节点端口 / IP 池）。改动会即时落盘。
- **组网引擎输出**：在「组网」页签的「引擎输出」卡片里实时显示（保留最新 300 行）。
- **运行日志**：程序级日志统一在「**运行日志**」页查看 / 导出（见 [使用说明 → 运行日志](/docs/user-guide/)）。

> 注意：修改 `multiplayer.json` 请先退出程序，否则改动可能被程序覆盖。

---

## 8. 其他说明

- 若发行包缺少 `runtime\`，联机页会提示「缺少组网组件，请重新解压完整发行包」；
- `runtime\winipbroadcast\` 里随包分发了 **WinIPBroadcast**（局域网广播转发服务）。源码里有安装该服务的内部能力，但**当前没有接到界面按钮上**——如需要，请手动运行该安装程序。

> 关于各个菜单项的定位与来源，见仓库 `docs/third-party.md`（随包组件清单）。
