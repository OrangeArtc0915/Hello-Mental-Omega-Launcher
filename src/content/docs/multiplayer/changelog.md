## v1.0.0

联机功能随启动器 **v1.0.0** 一并发布。

### 结构

- 联机功能是启动器的**内置页面**（左侧导航「🌐 联机」）；
- 配置保存在数据目录下的 **`Data\multiplayer.json`**；
- 组网二进制放在发行包的 **`runtime\`** 目录（EasyTier / n2n / TAP / WinIPBroadcast），不内嵌进 exe。

### 方案

- 内置 **EasyTier**（三层）与 **n2n**（二层，需 TAP 驱动）两种方案。

### 昵称

- 联机昵称取自**设置 → 联机昵称**；
- 进入大厅前必须已填昵称。

### 功能面

- 「组网 / 大厅 / 对端」三个页签：组网方案与连接、分享与一键加入、引擎输出、网络工具箱；大厅（在线玩家 / 公开房间 / 收藏队友）；在线对端（房间聊天、房主踢人 / 拉回）；
- 网络工具箱：连通性检测（PING / TCP·UDP 测速 / NAT）、防火墙控制、网卡优先级、文件传输、更多设置（自定义节点 / 进程守护 / 开机自启）、游戏 HUD、大厅延迟代码；
- n2n 专属工具：安装 TAP 驱动、自建 supernode（服务端模式）；
- 分享文本首行为 `HMOL联机模块 组网分享`，带版本号，**版本不一致拒绝联机**。

### 其它

- 游戏 HUD 为状态卡片；
- `runtime\winipbroadcast\` 里随包分发的 WinIPBroadcast，源码有安装能力但**未接到界面按钮**。
