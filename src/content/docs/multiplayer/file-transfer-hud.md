## 1. 文件传输

> 需要先连接联机房间，且对方在线。

### 入口

「联机」页 →「组网」页签 → 网络工具箱卡片 →「**文件传输**」。

### 使用

1. 在列表里**选择接收方**（在线对端，按虚拟 IP 直连）；
2. 点「选择文件」挑一个要发送的文件（**单文件上限 500MB**）；
3. 点「发送」，确认提示后开始传输；窗口内有进度条与日志，可「取消」。

对方会收到「某某想发送文件」的确认框，同意后再选保存位置。

### 说明

- 采用**直连对端虚拟 IP** 的 TCP 传输（默认端口 `17800`），不经公网中转，速度快；
- **重名文件自动改名**为「文件名 (1).扩展名」「文件名 (2).扩展名」…，**不会覆盖**已有文件；
- 空文件、超过 500MB 的文件会被拦下。

> 提示：大文件先压缩（zip / rar）再发，可显著缩短传输时间并减少出错。

## 2. 游戏 HUD 浮窗

在「网络工具箱」卡片点「**游戏 HUD**」开关，开启 / 关闭游戏内浮窗。

- 置顶、无边框、半透明的深色小浮窗，**实时显示联机状态与对端列表**（昵称 / 虚拟 IP / 延迟），并在有对端时显示「在线 N」；
- 可**按住卡片拖动**调整位置（拖动时会自动夹回屏幕内）；
- 右上角有 **×** 按钮可隐藏浮窗，隐藏后再次点「游戏 HUD」可重新显示。

> 当前 HUD 是纯状态卡片，窗口位置**不会跨会话保存**（每次回到默认落点：屏幕左上偏下）。

---

## 3. 系统托盘

关闭主窗口时，程序会**最小化到系统托盘**（托盘可用时）。

- 右键托盘图标：**显示主窗口 / 连接联机 / 退出程序**；
- 左键单击托盘图标：恢复主窗口；
- 托盘提示会显示联机状态（如「已连接 10.0.0.5」）。

> 托盘由主程序统一实现，详见 [使用说明 → 标题栏与托盘](/docs/user-guide/)。

## 4. 大厅延迟代码

在「网络工具箱」卡片点「**大厅延迟代码**」，打开一个小窗显示心灵终结 CNC 大厅可用的延迟指令 **`/framesendrate x`**，可一键复制。
