**联机大厅**是一个公共广场，基于公共 MQTT 信标实现，与你的联机房间**完全解耦**——大厅异常不影响房间组网。

> ⚠️ 大厅为公开广场，**聊天内容对第三方可见**，请勿发送敏感信息。

---

## 1. 进入大厅

在「联机」页切到「**大厅**」页签，点「**进入大厅**」。状态变为「已进入大厅 · 公网 IP：…」。

- 进入前必须先在 **设置 → 联机昵称** 填好昵称；
- 昵称取自该设置；未设置时会提示「还没有联机昵称：请到『设置 → 联机昵称』填写后再进入大厅」。

> 大厅是公共信标：进入失败会提示「进入大厅失败：所有大厅信标都不可用（请检查网络或稍后重试）」。

---

## 2. 在线玩家

列表显示大厅里的在线玩家（**名称 / IP / 延迟**）。选中一名玩家后可：

| 按钮 | 说明 |
| --- | --- |
| **大厅聊天** | 打开大厅聊天窗口，所有在线玩家可见 |
| **收藏选中玩家** | 把该玩家加入你的收藏（本地保存，不上传） |
| **邀请入房（房主）** | 仅**房主**可用，邀请对方加入当前房间 |
| **刷新** | 手动刷新在线列表 |

> 在线玩家列表在进入大厅后**每 3 秒自动刷新**一次，也可以手动刷新。

---

## 3. 收藏队友

收藏数据保存在**本机**配置 `Data\multiplayer.json` 的 `friends` 字段里，**纯本地、不上传**。同一 IP 视为同一队友，会记录**联机次数**与**最近时间**。

| 按钮 | 说明 |
| --- | --- |
| **一键加入** | 若该队友有房间记录，则把房间名填入表单并跳到「组网」页（节点需自行确认后点「连接」）；若没有房间记录，则把其**虚拟 IP 复制到剪贴板** |
| **取消收藏** | 从收藏中移除 |
| **刷新** | 刷新列表 |

> 与好友联机后会自动记录，下次开黑可从收藏快速填入，省去再要一次分享文本。

---

## 4. 公开房间

「公开房间」列表显示大厅里所有被公开的房间（**房主昵称 / 房间名 / 延迟**）。

- **一键加入公开房间**：把选中房间的房间名与节点填入表单，并跳到「组网」页，确认后点「连接」；
- **刷新**：手动刷新房间列表。

> 如何公开自己的房间：见 [建房与加入](/docs/multiplayer/hosting/) 中的「公开我的房间」一节。

---

## 5. 大厅聊天

大厅聊天通过公共 MQTT 服务中转，所有大厅在线玩家共享。聊天内容经内置共享密钥做**传输混淆**，但**内容仍应视为公开**。

- 大厅聊天有**速率限制**（窗口内最多若干条/秒），发送过快会被限流；
- 内容策略会拦截 **URL** 与违禁词；

> 房间聊天（仅房间成员可见）见 [建房与加入](/docs/multiplayer/hosting/) 中的「房间聊天与踢人」一节。
