HMOL 的联机功能是一个**跨公网 · 模拟局域网**的联机工具，作为启动器的**内置页面**（左侧导航「🌐 联机」）提供，帮助你和好友在任意网络环境下像在同一局域网中一样游玩红警 2 / 心灵终结。

- 组网方案：**EasyTier**（三层 · 推荐）、**n2n**（二层 · 需 TAP 驱动）
- 额外能力：联机大厅、房间聊天、收藏队友、文件传输、游戏内 HUD、网络工具箱
- 配置落盘：`Data\multiplayer.json`
- 依赖发行包里的 `runtime\` 目录（组网组件随包分发，不内嵌进 exe）

## 一分钟上手

1. 确认发行包**完整解压**（`runtime\` 目录在），否则联机页会提示「缺少组网组件，请重新解压完整发行包」。
2. 到 **设置 → 联机昵称** 填好昵称（进入大厅前必须填）。
3. 打开左侧「**联机**」页 →「**组网**」页签；默认方案 **EasyTier** 即可。
4. **房主**：填房间名（最多 6 字符）→ 点「**连 接**」→ 成功后点「**复制分享文本**」发给队友。
5. **队友**：复制分享文本 → 点「**粘贴分享文本一键加入**」，自动填入并连接。
6. 双方在游戏里通过**局域网 / 虚拟网卡**互相发现即可开黑。

> 详细步骤见 [快速开始](/docs/multiplayer/quick-start/)。

## 界面总览

「联机」页上方有页签「**组网 / 大厅 / 对端**」，「组网」页签下是各功能卡片：

| 卡片 | 作用 |
| --- | --- |
| **组网方案** | 选方案（EasyTier / n2n）、节点服务器（含节点测速 / 自定义节点）、房间名称、加密密钥、虚拟 IP 模式；n2n 下额外有「安装 TAP 驱动 / 服务端模式」 |
| **连接** | 连接状态、虚拟 IP、节点信息（NAT / PeerID / 公网 IP）、公开我的房间到大厅、连接 / 断开按钮 |
| **分享给队友** | 复制分享文本 / 分享文本窗口 / 粘贴分享文本一键加入，以及分享文本预览 |
| **引擎输出** | 组网引擎的运行输出（最新 300 行） |
| **网络工具箱** | 连通性检测、防火墙控制、网卡优先级、文件传输、更多设置、游戏 HUD、大厅延迟代码 |

「大厅」与「对端」页签见 [大厅与好友](/docs/multiplayer/hall/) 与 [建房与加入](/docs/multiplayer/hosting/)。
