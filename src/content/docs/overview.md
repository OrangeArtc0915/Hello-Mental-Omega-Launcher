## 📖 项目简介

**HMOL** 是一款专为 **心灵终结（Mental Omega）** 玩家打造的第三方桌面启动器，使用 **C# / .NET 8（WPF）** 编写，提供游戏启动、游戏实例管理、资源包管理、备份还原、联机组网等一体化能力。

> ⚠️ **本项目与 EA、红色警戒 2 开发团队、心灵终结开发团队不存在任何关联。**

## 🌟 核心特性

- 🎮 **一键启动** — 按固定顺序在实例目录中查找游戏主程序并启动，同时捕获游戏输出到「运行日志」
- 📦 **多实例管理** — 同时管理多个游戏实例，每个实例独立记录已安装的包与备份
- 🧩 **四类资源包** — INI / 地图 / 任务 / 插件，支持 `.zip` / `.7z` / `.rar` 导入与精确卸载
- 💾 **备份与还原** — 用户备份 + 固定位置的「原版游戏」备份，支持精确卸载与全量恢复
- 🌐 **联机组网** — 内置 **EasyTier**（三层，推荐）与 **n2n**（二层，需 TAP 驱动）两种方案，含联机大厅、房间聊天、文件传输、游戏内 HUD
- 🎨 **主题与外观** — 浅色 / 深色 / 跟随系统，4 套强调色；可自定义主页背景（图片 / 动图 / 视频，含壁纸包导入）与背景音乐
- 🧱 **界面布局自定义** — 可在布局编辑器里调整左侧导航的顺序、显隐与名称
- 🧩 **声明式扩展** — 用一份 JSON 清单在主页加一张小组件卡片；不执行代码、不读写你的文件
- ⏰ **开机自启与系统托盘** — 登录后自动驻留托盘，随时唤起
- 🛡️ **启动门锁与安全自检** — 启动前联网校验开关，并做调试器 / 完整性自检（只记日志告警，不阻断使用）

## 🧭 界面一览

左侧导航共六个页面，外加底部的「关于」独立窗口：

| 入口         | 说明                                                     |
| ------------ | -------------------------------------------------------- |
| 🏠 **主页**     | 问候横幅、月历 / 天气 / 常用网站小组件、扩展卡片、当前实例与启动按钮 |
| 📚 **游戏实例** | 实例的增删改查、导出 / 导入、启动，以及备份 / 还原区块     |
| 📦 **包管理**   | 四类包的可用列表 / 已安装列表、导入、安装与卸载           |
| 🌐 **联机**     | 组网（网络设置）、联机大厅、在线对端、工具箱              |
| 📜 **运行日志** | 应用日志 / 游戏日志 / 磁盘日志三视图，导出与清理          |
| ⚙️ **设置**     | 主题、联机昵称、天气城市、常用网站、背景、背景音乐、布局、扩展、开机自启 |
| ℹ️ **关于**     | 版本、仓库、QQ 群（独立窗口，不占页面）                   |
