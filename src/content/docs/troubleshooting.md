## 日志查看方法

### 日志位置

```
<启动器目录>/
└── Data/
    └── Log/
        ├── HMOL-2026-9-24-183045123.log
        └── HMOL-2026-9-25-091233456.log  ← 最新
```

也可在程序里点「**运行日志 → 磁盘日志**」查看，或点操作栏的「打开日志目录」。

### 日志格式

```
[18:30:45.123] [INFO] [PagePackages.cs] 安装完成：xxx
[18:30:46.201] [WARN] [DirectoryCopier.cs] 跳过无法读取的文件：…
[18:30:47.884] [ERROR] [BackupService.cs] 备份失败：…
```

一行形如 `[时间] [级别] [模块] 正文`；级别有 `DEBUG / INFO / WARN / ERROR / FATAL`。

### 查找关键错误

```powershell
# 只看今天的 ERROR / WARN
Get-ChildItem "$env:USERPROFILE\..\HMOL\Data\Log\HMOL-*.log" | Sort-Object LastWriteTime -Descending | Select-Object -First 1 |
  Select-String -Pattern "ERROR|WARN|FATAL"

# 或在程序内：运行日志 → 磁盘日志 → 导出 TXT/CSV
```

### 日志保留策略

- 落盘日志按**份数**保留最近 **16 份**，单文件上限 **8 MB**（超出自动新开一份）；
- 「清理旧日志」按时间删除 **7 天前**的文件；正在写入的那份会跳过。

## 启动类问题

### ❌ 双击 `HMOL.exe` 没有任何反应

**排查**：

1. **确认已完整解压**（不要直接在压缩软件里双击运行）。
2. **确认 `Data\Log\` 里有没有新日志**：
   - 有日志 → 打开看 `ERROR` / `FATAL` 行；
   - 完全没有日志 → 大概率被安全软件拦截，把启动器目录加入信任区后重试。
3. **确认系统版本**：仅支持 Windows 10 1809+ / Windows 11（x64）。
4. 从命令行启动，观察是否有输出：

   ```powershell
   cd "D:\HMOL"
   .\HMOL.exe
   ```

### ❌ 提示「已经在运行了」

程序单实例运行。请到系统托盘找到 HMOL 图标用托盘菜单唤起，或先退出再重开。

### ❌ 启动被拦：错误代码 E12.01（「未能验证启动授权」/「此版本 HMOL 暂停支持」）

启动门锁的严格模式。**联网也读不到配置同样会被拦。**

**排查**：

1. 确认网络可用，且能访问 GitHub 与 Gitee：

   ```powershell
   Test-NetConnection raw.githubusercontent.com -Port 443
   Test-NetConnection gitee.com -Port 443
   ```

2. 关闭代理 / VPN 后重试；
3. 重开程序（会再做两轮校验），仍不行请联系发布者。

### ❌ 提示「缺少组网组件，请重新解压完整发行包」

发行包的 `runtime\` 目录缺失。请重新完整解压；该目录不会被打进 `HMOL.exe`。

### ❌ 界面打不开 / 窗口空白

- 若托盘可用，先用托盘菜单「显示主窗口」把窗口叫回来；
- 若任务栏 / 托盘都找不到，请在任务管理器结束 `HMOL.exe` 后重启；
- 检查是否装过会强制修改窗口 / 主题的第三方工具，并更新显卡驱动。

## 实例相关问题

| 提示                                 | 原因                     | 处理                                   |
| ------------------------------------ | ------------------------ | -------------------------------------- |
| 实例名称和路径不能为空               | 表单未填完整             | 补全名称与路径                         |
| 实例名称已存在                       | 名称重复                 | 更换名称                               |
| 指定路径不是有效的心灵终结游戏目录   | 路径不合法               | 选择含特征文件的 MO 目录               |
| 该游戏路径已被其他实例使用           | 同一路径被多个实例占用   | 换目录，或复用已有实例                 |
| 实例不存在                           | 实例已被外部删除         | 刷新列表 / 重新创建                    |
| 游戏目录不存在：`<路径>`             | 实例路径失效             | 在实例页「编辑」中更新路径             |

### ❌ 实例显示「游戏目录不可用」

说明该目录已不满足游戏目录识别规则（目录被移动 / 重命名 / 删除，或缺少特征文件）。请在「游戏实例」页用「编辑」更新路径。

### ❌ 主页按钮提示「目录有效但未找到游戏主程序」

识别规则与启动查找规则不同：识别看 `MentalOmegaClient.exe` / `Mental Omega.exe`，启动按顺序找 `Mental_Omega_client.exe` → `MentalOmegaClient.exe` → `Mental_Omega.exe`。请确认游戏文件完整。

### ❌ 启动游戏失败

- 确认游戏目录有效且主程序存在；
- 关闭可能占用主程序的程序；
- 查看「运行日志 → 游戏日志 / 应用日志」中的原因。

## 包安装与卸载问题

### ❌ 提示「压缩包/解压失败」

1. 用 7-Zip / WinRAR 单独打开测试压缩包是否损坏；
2. 确认文件已下载完整；
3. 联系资源提供者换一个包。

### ❌ 提示「所有 N 个文件均无法复制」

1. 关闭游戏与可能占用文件的程序（杀毒软件、同步盘）；
2. 以管理员身份运行启动器；
3. 检查磁盘空间；
4. 注意 Windows 路径长度限制（约 260 字符）。

### ❌ 提示「未找到原版游戏备份」

按包卸载（选择性卸载）与全量恢复都需要 `backup\MO`。请先在实例页执行「**备份原版游戏**」。

### ❌ 提示「包文件不存在：…」

该包已从 `packages\<类型>\` 移除，但实例的已安装记录还在。可选择「全量恢复原版」清理，或重新导入包源文件后再卸载。

### ❌ 卸载后游戏无法启动

1. 若「选择性卸载」后异常 → 可用「全量恢复原版」回退；
2. 若「全量恢复」后异常 → 用用户备份还原，或检查 `backup\MO` 是否完整；
3. 查看 `Data\Log\` 里的详细原因。

## 备份与还原问题

### ❌ 备份名称为系统保留名 / 含非法字符

禁止的保留名：`MO` / `mo` / `Mo` / `mO` / `MO.mo.mO` / `原版` / `原版游戏` / `原版游戏备份`；
禁止的字符：`< > : " / \ | ? *` 及控制字符。换一个名称即可。

### ❌ 备份失败

**排查**：

```powershell
# 磁盘空间
Get-PSDrive
# 目标目录权限
icacls "Data\backup"
```

然后查看 `Data\Log\` 中 `BackupService` 相关记录。

### ❌ 还原中途失败

程序会在还原前把目标目录现有内容搬进隔离区，**复制失败或取消会自动回滚**。请查看日志中的具体原因，并确认目标磁盘空间充足、无程序占用游戏目录。

> ⚠️ 还原会替换游戏目录中的所有内容，**不可撤销**，请谨慎操作。

## 联机相关问题

> 完整的联机排障请看 **[联机 → 常见问题](/docs/multiplayer/faq/)**，这里只列与主程序相关的问题。

### ❌ 联机页一进来就提示「缺少组网组件」

`runtime\` 目录不完整。请重新完整解压发行包。

### ❌ 修改虚拟网卡 / 关闭防火墙时提示失败

这些操作需要**管理员权限**，并且程序会在需要时弹出 UAC 提权确认。若拒绝提权或当前账户无权限，操作不会执行。

### ❌ 游戏里发现不到房间

- 用「工具箱 → 网卡优先级」把虚拟网卡跃点数调低，让游戏广播优先走虚拟网卡；
- 或直接填对方的虚拟 IP 进游戏；
- 必要时改用 **n2n** 方案（二层广播）。

### ❌ 大厅进入失败

大厅是公共 MQTT 信标，多个信标都不可用时会提示失败。请稍后重试或检查网络。

## 界面与外观问题

### ❌ 背景没生效 / 素材丢失

背景素材会被复制到 `Data\backgrounds\`。若提示「原先的素材已丢失，请重新选择」，说明该文件被删除或损坏，重新导入即可。

### ❌ 背景音乐不出声

1. 确认「启用背景音乐」为**已启用**，且播放列表非空；
2. 检查音量与系统音量；
3. 文件不存在时列表会标注「（文件不存在）」，重新添加；
4. 部分精简版 Windows 缺少媒体组件，个别格式无法解码，换一个常见格式（`.mp3`）试试。

### ❌ 侧边栏被我改乱了 / 想恢复

设置 → 界面布局 →「**恢复默认布局**」。注意：这只会清空「默认布局」方案里的自定义，其它自存方案不受影响。

### ❌ 扩展卡片不显示 / 显示加载失败

- 打开「设置 → 扩展模块」看列表里的**红色失败原因**（会写清是第几行第几列的问题）；
- 修改清单后点「**重新加载**」；
- 若不需要联网数据，确认「数据源联网总开关」状态；
- 主页每次进入都会重读扩展目录。

## 性能问题

### ❌ 启动较慢

- 首次启动（尤其是压缩包刚解压、被安全软件扫描）会慢一些，之后会快；
- 将启动器目录加入杀毒软件白名单；
- 包管理器目录里有大量文件时，「包管理」页列举可用包会较慢（体积统计需要遍历）；
- 实例体积统计在后台进行，不会阻塞界面。

### ❌ 界面卡顿 / 占用偏高

- 关闭自定义背景（尤其是视频背景）或降低模糊 / 暗化；
- 关闭背景音乐；
- 关闭不需要的扩展（数据源按 `refreshSeconds` 定时请求）；
- 重启程序。

### ❌ 备份时界面无响应

备份在后台线程进行，界面会显示进度窗。若进度窗长时间不动：

1. 查看 `Data\Log\` 是否有新的错误；
2. 检查是否被安全软件拦截文件读写；
3. 若进程已无响应，请在任务管理器中结束并重试。

## 通用排查步骤

1. **看日志**：`Data\Log\` 最新一份，从最后往前找 `ERROR` / `WARN`；
2. **查错误信息**：[错误信息与解决](/docs/error-codes/) 对号入座；
3. **查 FAQ**：[常见问题](/docs/faq/)；
4. **最小化复现**：确认是否与某个包 / 备份 / 联机相关；
5. **检查环境**：磁盘空间、权限、安全软件、系统版本；
6. **反馈**：把日志与现象发到 [GitHub Issues](https://github.com/OrangeArtc0915/Hello-Mental-Omega-Launcher/issues) 或 QQ 群 `1034243331`。
