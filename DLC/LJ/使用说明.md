# HMOL联机模块 使用说明

红警2 / 心灵终结 等支持局域网的旧游戏，跨异地（跨公网）零成本联机工具。

---

## 快速开始（3 步）

1. 打开 **HMOL**，使用**微软账号登录**（未登录时本模块会拒绝启动）
2. 在 HMOL 左侧导航点 **程序DLC** → 找到 **HMOL联机模块** → 点击 **🚀 启动**
3. 选择方案（**EasyTier 推荐**）→ 选择节点服务器 → 填写或随机生成小组名 → 点击 **连接**，看到"本机虚拟 IP"出现即成功

> 队友做同样操作，并填入**相同的小组名**，即可在"在线对端"中互相看到。
>
> **注意**：本模块是 HMOL 的 DLC 插件包，**不能独立运行**，必须从 HMOL 的「程序DLC」页面启动。

---

## 拉人联机（分享功能）

- 点右上角 **分享给队友** → 复制文本发给队友，或让队友**扫二维码**
- 队友拿到文本复制后，两种一键加入方式：
  - **刚打开程序**：自动检测到剪贴板里的分享 → 弹窗问是否一键加入 → 点"是"直接连接
  - **程序已打开**：点右上角绿色 **一键加入** 按钮 → 自动填入并直接连接
- 全程无需手动配置，一键入伙

### 分享文本格式

```
HMOL联机模块 组网分享
方案: EasyTier        ← EasyTier 或 n2n
节点: tcp://xxx:11010 ← 节点服务器地址
小组: RA2TEST         ← 小组名（双方必须一致）
密钥: (无)            ← 加密密钥
IP: 自动              ← 自动 或 手动:192.168.100.66
```

---

## 双方案选择

| 方案 | 说明 | 适用 |
| ---- | ---- | ---- |
| **EasyTier**（推荐） | 三层组网，免装驱动，内置公共节点即可用 | 大多数情况 |
| **n2n** | 二层组网，首次需在工具箱点 **TAP 安装** | 依赖 MAC 地址的老游戏，兼容性最好 |

---

## 服务端模式

公共节点都不通时使用：

1. 点工具箱 **服务端模式** → 本机自建节点服务器
2. 把界面显示的公网地址发给队友，填入节点栏
3. 注意：需在路由器上开放对应的 UDP 端口（可设置端口转发）

## 测试工具

| 工具 | 用途 |
| ---- | ---- |
| 连通性检测 | 汇总 PING / TCP·UDP 测速 / NAT 检测 |
| 防火墙 | 一键关闭/恢复（需管理员） |
| TAP 安装 | n2n 方案首次使用前安装虚拟网卡驱动 |
| 网卡优先级 | 连接后让游戏广播优先走虚拟网卡 |

## 常见问题

**Q: 连不上或找不到队友？**
A: 确认双方小组名、节点完全一致；用 PING 测试对方虚拟 IP；必要时在工具箱一键关闭防火墙后重试。

**Q: 手动 IP 模式连不上？**
A: 两台机器的 IP 不能相同（如 .66 / .67）。

**Q: 必须管理员运行吗？**
A: 修改防火墙、安装 TAP、创建虚拟网卡需要管理员权限，启动脚本会自动请求提权。

**Q: 二维码显示不出来？**
A: 不影响使用，直接复制文本发给队友即可。
