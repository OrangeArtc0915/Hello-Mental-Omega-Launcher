# HMOL 启动器 Wiki

欢迎来到 **Hello Mental Omega Launcher (HMOL)** 官方 Wiki。

请选择你使用的版本：

***

## 版本选择 / Select Version

| 版本              | 说明                                       | 入口                               |
| --------------- | ---------------------------------------- | -------------------------------- |
| **HMOL 标准版**    | HMOL 启动器 ，基于 **Python + PySide6 (Qt 6)** | [进入标准版 Wiki](HMOL-Home)          |
| **HMOL Wine 版** | HMOL 启动器 ，基于 **Python + tkinter**        | [进入 Wine 版 Wiki](HMOL-Wine-Home) |

***

## 两个版本的区别 / Differences

| <br /> | HMOL 标准版                | HMOL Wine 版         |
| ------ | ----------------------- | ------------------- |
| GUI 框架 | PySide6 (Qt 6.6 \~ 6.9) | tkinter (Python 内置) |
