## E1 实例管理错误

### E1.01 实例名称和路径不能为空

- **提示**：`实例名称和路径不能为空`
- **可能原因**：新建实例时未填写名称或未选择游戏路径
- **解决**：填写实例名称并点击「浏览」选择含 `Mental_Omega_client.exe` 的游戏根目录

### E1.02 实例名称已存在

- **提示**：`实例名称已存在`
- **可能原因**：新名称与已有实例重复
- **解决**：更换为其他名称；或先删除/重命名旧实例

### E1.03 指定路径不是有效的心灵终结游戏目录

- **提示**：`指定路径不是有效的心灵终结游戏目录`
- **可能原因**：所选路径下找不到 `Mental_Omega_client.exe` 或关键资源
- **解决**：选择包含 `Mental_Omega_client.exe` 而非快捷方式所在目录；若已移动游戏需重新指定

### E1.04 该游戏路径已被其他实例使用

- **提示**：`该游戏路径已被其他实例使用`
- **可能原因**：一个游戏目录被绑定到多个实例
- **解决**：为新实例选择不同游戏目录，或复用现有实例

### E1.05 实例不存在

- **提示**：`实例不存在`
- **可能原因**：对不存在的实例进行操作
- **解决**：刷新实例列表，确认实例名称；若被外部删除需先新建

### E1.06 实例名称不能为空 / 备份名称不能为空

- **提示**：`实例名称不能为空 / 备份名称不能为空`
- **可能原因**：重命名、备份等操作未填写名称
- **解决**：在弹窗中输入合法名称（非空、不含 `< > : " / \ | ? *` 等特殊字符）

### E1.07 删除实例时出错

- **提示**：`删除实例时出错: <异常>`
- **可能原因**：删除时抛出异常（权限/文件占用/磁盘错误）
- **解决**：关闭游戏或可能占用目录的程序（EAC、杀软）；以管理员身份运行；检查磁盘空间

### E1.08 无法创建实例目录

- **提示**：`无法创建实例目录 <路径>: <异常>`
- **可能原因**：实例目录创建失败
- **解决**：确认磁盘可写、防火/杀软未拦截；尝试以管理员身份运行；更换 base\_path

### E1.09 无法写入实例配置

- **提示**：`无法写入实例配置 <路径>: <异常>`
- **可能原因**：实例的 `config.json` 无法写入（权限/磁盘/只读）
- **解决**：检查目录权限，关闭可能占用文件的程序；或迁移到本地可写目录

### E1.10 游戏路径不存在

- **提示**：`游戏路径不存在: <path>`
- **可能原因**：当前实例指向的游戏目录已被移动或删除
- **解决**：在【实例管理】中重新指定游戏根目录；或删除该实例

### E1.11 无法切换到实例

- **提示**：`无法切换到实例: <name>`
- **可能原因**：切换实例时失败（目标实例路径异常）
- **解决**：确认目标实例的目录与游戏路径有效；必要时删除并重建

### E1.12 切换实例失败

- **提示**：`切换实例失败: <异常>`
- **可能原因**：底层异常（IO/JSON 解析失败）
- **解决**：查看 logs/ 当日日志获取 Traceback；修复后重启

### E1.13 加载实例失败

- **提示**：`加载实例失败: <instance_dir>`
- **可能原因**：实例配置文件损坏或目录权限受限
- **解决**：删除 `instances/<id>` 目录后重新添加实例

### E1.14 请输入实例名称 / 请选择游戏路径

- **提示**：`请输入实例名称 / 请选择游戏路径`
- **可能原因**：在添加实例对话框中必填项缺失
- **解决**：填入名称并点击「浏览」选择游戏目录

## E2 导入/导出错误

### E2.01 导出路径不能为空

- **提示**：`导出路径不能为空 / 导出目录不存在: <路径>`
- **可能原因**：导出时未选择目标目录，或目录已被删除
- **解决**：在保存对话框中选择已存在的目录后重试

### E2.02 目标文件已存在

- **提示**：`目标文件已存在: <path>`
- **可能原因**：导出目标已存在同名文件
- **解决**：删除同名文件，或在保存对话框中更换文件名

### E2.03 实例中没有文件可导出

- **提示**：`实例中没有文件可导出`
- **可能原因**：实例目录为空或被清空
- **解决**：确认游戏目录完整；必要时重新安装游戏

### E2.04 导出过程中发生错误

- **提示**：`导出过程中发生错误: 输出文件未生成 / 输出文件为空`
- **可能原因**：导出过程被中断（取消、磁盘满、杀软拦截）
- **解决**：关闭杀软，确保磁盘空间充足

### E2.05 导出失败: 权限不足

- **提示**：`导出失败: 权限不足 (<e>)`
- **可能原因**：目标目录权限不足（系统盘/U 盘/网盘目录）
- **解决**：以管理员身份运行，或更换到用户主目录

### E2.06 导出失败: 磁盘/系统错误

- **提示**：`导出失败: 磁盘/系统错误 (<e>)`
- **可能原因**：磁盘空间不足或文件系统错误
- **解决**：清理磁盘；运行 chkdsk 修复

### E2.07 7z 支持不可用

- **提示**：`7z 支持不可用,请先安装 py7zr 库`
- **可能原因**：Python 环境未安装 `py7zr`
- **解决**：`pip install py7zr`；或在导出对话框中选择 ZIP 格式

### E2.08 ZIP 导出失败

- **提示**：`ZIP 导出失败: <错误类型>: <e>`
- **可能原因**：压缩过程中底层 IO 异常
- **解决**：检查目标目录权限与磁盘空间；关闭杀软

### E2.09 7z 导出失败

- **提示**：`7z 导出失败: <错误类型>: <e>`
- **可能原因**：`py7zr` 调用异常或磁盘写入失败
- **解决**：升级 `py7zr`；确保磁盘可写

### E2.10 未检测到 WinRAR CLI

- **提示**：`未检测到 WinRAR CLI,且同名 .zip 已存在: <路径>`
- **可能原因**：选择 RAR 格式但未安装 WinRAR/unrar
- **解决**：安装 WinRAR；或删除同名 `.zip`；或选择 ZIP 格式

### E2.11 不支持的文件格式

- **提示**：`不支持的文件格式 / 无效的实例文件:缺少配置文件`
- **可能原因**：导入文件不是 zip/7z/rar，或压缩包内缺少 `instance.json`
- **解决**：使用本启动器导出的实例包导入

### E2.12 无法找到游戏文件目录

- **提示**：`无法找到游戏文件目录 (game_files) / 解压的文件不是有效的心灵终结游戏目录`
- **可能原因**：压缩包结构异常或导出时中断
- **解决**：重新从原版目录导出实例

### E2.13 复制游戏文件失败

- **提示**：`复制游戏文件失败: 所有 <N> 个文件均无法复制`
- **可能原因**：目标目录完全无写权限或磁盘已满
- **解决**：更换为非系统盘目录；检查目录权限；清理磁盘

### E2.14 导入已取消

- **提示**：`操作已取消 / 导入已取消`
- **可能原因**：用户在进度对话框中点击了「取消」
- **解决**：需要导入时，请等待进度条走完

### E2.15 配置文件格式错误

- **提示**：`配置文件格式错误`
- **可能原因**：压缩包内 `instance.json` 不是合法 JSON
- **解决**：重新下载或导出实例

### E2.16 导出已取消

- **提示**：`操作已取消 / 导出已取消`
- **可能原因**：用户在进度对话框中点击了「取消」
- **解决**：需要导出时，请耐心等待

### E2.17 导入失败 / 导出失败

- **提示**：`导入失败: <e> / 导出失败: <e>`
- **可能原因**：综合异常（压缩包损坏/解压库缺失/IO 失败）
- **解决**：查看 logs/；安装缺失的 py7zr/rarfile；重新下载

### E2.18 无法删除已存在文件

- **提示**：`无法删除已存在文件: <e> / 清理旧目标失败: <e>`
- **可能原因**：目标文件被外部程序占用，或权限不足
- **解决**：关闭可能占用文件的程序；以管理员身份运行

### E2.19 读取目录失败

- **提示**：`读取目录失败: <e> / 打开失败: <e>`
- **可能原因**：文件系统异常或目录被外部删除
- **解决**：刷新目录树；若仍失败，重启电脑

### E2.21 打开浏览器失败

- **提示**：`打开浏览器时发生错误: <e>`
- **可能原因**：系统无默认浏览器或被外部拦截
- **解决**：在 Windows 设置中将浏览器设为默认应用

### E2.22 请先选择要操作的项目

- **提示**：`请先选择要重命名的项目 / 请先选择要删除的项目 / 请先选择要打开的项目`
- **可能原因**：列表中未选中目标
- **解决**：先点击选中条目，再点对应操作按钮

### E2.23 重命名/删除失败

- **提示**：`重命名失败: <e> / 删除失败: <e>`
- **可能原因**：权限/占用/只读
- **解决**：关闭占用程序；去掉只读属性；以管理员身份运行

### E2.24 项目不存在

- **提示**：`项目不存在: <path>`
- **可能原因**：文件/文件夹被外部删除或移动
- **解决**：刷新文件树，重新定位目标

## E3 插件包安装错误

### E3.01 请先选择游戏实例

- **提示**：`请先选择一个游戏实例`
- **可能原因**：安装前未选择目标实例
- **解决**：在「实例管理」中先选择/创建游戏实例

### E3.03 包文件不存在

- **提示**：`包文件不存在: <src>`
- **可能原因**：列表显示但源文件被外部删除
- **解决**：点击「刷新」重新扫描本地包

### E3.04 ZIP 文件已损坏

- **提示**：`ZIP 文件已损坏或格式错误: <src>`
- **可能原因**：压缩包本身损坏或下载不完整
- **解决**：重新下载资源包

### E3.05 7z 支持不可用

- **提示**：`7z 支持不可用,请先安装 py7zr 库: pip install py7zr`
- **可能原因**：未安装 py7zr
- **解决**：`pip install py7zr`，然后重启启动器

### E3.06 RAR 支持不可用

- **提示**：`RAR 支持不可用,请先安装 rarfile 库: pip install rarfile`
- **可能原因**：未安装 rarfile
- **解决**：`pip install rarfile`，并确保系统已安装 unrar

### E3.07 RAR 解压需要 unrar/WinRAR

- **提示**：`RAR 解压需要系统已安装 unrar/WinRAR`
- **可能原因**：`rarfile` 库依赖 unrar CLI，系统未找到
- **解决**：安装 WinRAR 或将 `unrar.exe` 放入 PATH

### E3.08 RAR 解压失败

- **提示**：`RAR 解压失败: <e>`
- **可能原因**：压缩包损坏或 RAR 格式不被支持
- **解决**：升级 unrar；或重新压缩为 ZIP/7Z

### E3.10 解压失败

- **提示**：`解压失败: <e>`
- **可能原因**：压缩包损坏或磁盘写入失败
- **解决**：确认磁盘空间；重新下载

### E3.11 读取解压结果失败

- **提示**：`读取解压结果失败: <e>`
- **可能原因**：解压后目录 IO 异常
- **解决**：查看 logs/；确认 `temp/` 目录可写

### E3.12 压缩包内容为空

- **提示**：`压缩包内容为空,未解压到任何文件`
- **可能原因**：压缩包内没有任何文件
- **解决**：重新下载或要求作者重新打包

### E3.13 安装源中没有可复制的文件

- **提示**：`安装源中没有可复制的文件`
- **可能原因**：解压后目录为空
- **解决**：用 7-Zip 手动解压确认包内容

### E3.14 安装失败: 所有文件无法复制

- **提示**：`安装失败: 所有 <N> 个文件均无法复制`
- **可能原因**：目标目录权限严重不足或被杀软拦截
- **解决**：关闭杀软；以管理员身份运行

### E3.15 安装后目标目录为空

- **提示**：`安装后目标目录为空,可能复制失败`
- **可能原因**：复制步骤被异常打断
- **解决**：查看 logs/；清理磁盘后重试

### E3.16 清理旧目标失败

- **提示**：`清理旧目标失败: <e>`
- **可能原因**：删除旧文件失败（占用/权限）
- **解决**：关闭占用程序；以管理员身份运行

### E3.17 已取消

- **提示**：`已取消覆盖 / 已取消安装 / 安装已取消`
- **可能原因**：用户在冲突/安装确认对话框中点「否」
- **解决**：若确实要覆盖，请点「是」

### E3.18 安装过程发生异常

- **提示**：`安装过程发生异常: <e> (安装错误)`
- **可能原因**：顶层异常
- **解决**：查看 logs/；重新下载；重启启动器

### E3.20 包文件不存在

- **提示**：`包文件未找到 / 包文件不存在: <path>`
- **可能原因**：列表项的源文件被外部删除
- **解决**：点击「刷新」重新扫描本地包

### E3.21 已安装但保存安装记录失败

- **提示**：`已安装到游戏目录,但保存安装记录失败`
- **可能原因**：`install_record.json` 写入失败
- **解决**：确认 `instances/<id>` 目录可写

### E3.22 目标已存在 - 检测到冲突

- **提示**：`检测到 <N> 个文件冲突`
- **可能原因**：新包与已安装内容存在冲突
- **解决**：在「文件冲突」对话框中选「是」覆盖

### E3.23 请先选择游戏实例 (卸载/启动)

- **提示**：`请先选择一个游戏实例`
- **可能原因**：卸载/启动前未选择实例
- **解决**：先在「实例管理」中选择一个有效实例

### E3.24 未找到游戏主程序

- **提示**：`未找到游戏主程序 (Mental_Omega_client.exe)`
- **可能原因**：实例目录中找不到主程序
- **解决**：确认游戏目录完整；或重新指定游戏根目录

### E3.25 启动失败

- **提示**：`启动失败: <e>`
- **可能原因**：`subprocess` 启动主程序失败
- **解决**：以管理员身份运行；关闭杀软；清空「启动参数」

### E3.26 缺少 py7zr / 缺少 rarfile

- **提示**：（状态栏提示）
- **可能原因**：Python 依赖未安装
- **解决**：`pip install py7zr rarfile`

### E3.27 备份名称为系统保留

- **提示**：`备份名称 '<name>' 为系统保留名称`
- **可能原因**：使用 CON / PRN / AUX / NUL 等保留名
- **解决**：改用其他名称

### E3.28 备份名称包含非法字符

- **提示**：`备份名称包含非法字符: < > : " / \ | ? *`
- **可能原因**：名称含 Windows 非法字符
- **解决**：只使用中文/英文/数字/下划线/点/空格

### E3.29 备份名称过长

- **提示**：`备份名称过长(最大 100 字符)`
- **可能原因**：名称超过 100 字符
- **解决**：将名称精简到 100 字符以内

## E4 插件包卸载错误

### E4.01 卸载完成(有警告)

- **提示**：`卸载完成 - <msg>(部分文件无法删除)`
- **可能原因**：部分文件被占用或权限不足
- **解决**：关闭游戏后再次卸载，或手动删除残留文件

### E4.02 卸载完成

- **提示**：`卸载完成 - <msg>`
- **可能原因**：成功卸载（无残留）
- **解决**：无需处理

### E4.03 卸载失败

- **提示**：`卸载失败: <e>`
- **可能原因**：删除/恢复文件时抛出异常
- **解决**：查看 logs/；关闭游戏；以管理员身份运行

### E4.04 ⚠️ 全量恢复确认

- **提示**：`⚠️ 全量恢复确认 - 是否继续?`
- **可能原因**：还原时会覆盖游戏目录全部内容

## 附录 A: 通用排查步骤

1. 查看启动器同目录下的 `logs/HMOL_<日期>.log`，搜索 `ERROR` / `Traceback` 关键字
2. 关闭游戏主程序、EAC、Steam、杀毒软件后再操作
3. 右键启动器 → 以管理员身份运行
4. 检查磁盘剩余空间（建议 > 5 GB）
5. 确认 Windows 已更新到最新版本，安装了最新的 VC++ 运行库
6. 重新安装缺失的 Python 依赖：`pip install -r requirements.txt`
7. 备份并删除启动器目录下的 `HMOL_config.json`、`instances/`、`cache/` 后重试
8. 若仍无法解决，在 GitHub Issues 附上 log 文件和复现步骤
