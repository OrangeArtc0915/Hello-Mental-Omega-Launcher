## E1 实例管理错误

### E1.01 实例名称和路径不能为空

> 实例名称和路径不能为空

- **可能原因: 新建实例时未填写名称或未选择游戏路径。**
- **解决: 在【实例管理】对话框中,填写实例名称(例:MO\_主版本),并点击"浏览"选择心灵终结根目录(含 Mental\_Omega\_client.exe)。**

### E1.02 实例名称已存在

> 实例名称已存在

- **可能原因: 尝试创建或重命名时,新名称与已有实例重复。**
- **解决: 更换为其他名称;或先删除/重命名旧实例。**

### E1.03 指定路径不是有效的心灵终结游戏目录

> 指定路径不是有效的心灵终结游戏目录

- **可能原因: 所选路径下找不到 Mental\_Omega\_client.exe 或关键资源文件。**
- **解决: 确认选择了正确的 MO 安装目录(包含 Mental\_Omega\_client.exe 而非快捷方式所在目录);若已移动游戏,需重新指定。**

### E1.04 该游戏路径已被其他实例使用

> 该游戏路径已被其他实例使用

- **可能原因: 一个游戏目录被绑定到多个实例,可能造成文件冲突。**
- **解决: 为新实例选择不同的游戏目录,或复用现有实例而非新建。**

### E1.05 实例不存在

> 实例不存在

- **可能原因: 对不存在的实例进行操作(重命名/删除/导出/卸载)。**
- **解决: 刷新【实例管理】列表,确认要操作的实例名称;若被外部删除,需先新建。**

### E1.06 实例名称不能为空 / 备份名称不能为空

> 实例名称不能为空 / 备份名称不能为空

- **可能原因: 重命名、备份等操作未填写名称。**
- **解决: 在弹窗中输入合法的名称(非空、不含 < > : " / \ | ? \* 等特殊字符)。**

### E1.07 删除实例时出错: <异常>

> 删除实例时出错: <异常>

- **可能原因: 删除实例时抛出异常(权限/文件占用/磁盘错误)。**
- **解决: 关闭游戏或可能占用该目录的程序(EAC、杀毒软件);以管理员身份运行启动器;检查磁盘空间。**

### E1.08 无法创建实例目录 <路径>: <异常>

> 无法创建实例目录 <路径>: <异常>

- **可能原因: Program 内部抛出 RuntimeError,实例目录创建失败。**
- **解决: 确认启动器所在磁盘可写、防火/杀毒未拦截;尝试以管理员身份运行;更换 base\_path。**

### E1.09 无法写入实例配置 <路径>: <异常>

> 无法写入实例配置 <路径>: <异常>

- **可能原因: 实例的 config.json 无法写入(权限/磁盘/只读)。**
- **解决: 检查目录权限,关闭可能占用文件的程序;或迁移到本地可写目录。**

### E1.10 游戏路径不存在: <path>

> 游戏路径不存在: <path>

- **可能原因: 当前实例指向的游戏目录已被移动或删除。**
- **解决: 在【实例管理】中点击"更新路径"重新指定游戏根目录;或删除该实例。**

### E1.11 无法切换到实例: <name>

> 无法切换到实例: <name>

- **可能原因: 切换实例时校验失败。**
- **解决: 在【实例管理】中检查该实例状态(游戏目录是否存在、配置是否完整),必要时重新创建。**

### E1.12 切换实例失败: <异常>

> 切换实例失败: <异常>

- **可能原因: 切换过程中抛出未捕获异常。**
- **解决: 查看 logs/HMOL\_\*.log 中的 traceback,联系开发者反馈 bug。**

### E1.13 加载实例失败: \<instance\_dir>, 错误: <e>

> 加载实例失败: \<instance\_dir>, 错误: <e>

- **可能原因: 启动时加载某个实例配置失败。**
- **解决: 进入启动器所在目录,检查 instances/<id>/config.json 是否存在且 JSON 格式正确;损坏可删除后重建。**

### E1.14 请输入实例名称 / 请选择游戏路径

> 请输入实例名称 / 请选择游戏路径

- **可能原因: 新建/重命名时表单校验不通过。**
- **解决: 按提示补全对应字段后再提交。**

#### E1.15  实例目录无效

当前实例的游戏目录已不存在或被移动

> 实例目录无效
> 当前实例的游戏目录已不存在或被移动

- **可能原因: 安装/启动前再次校验实例路径,发现已失效。**
- **解决: 在【实例管理】中更新路径,或新建一个指向正确游戏目录的实例。**

## E2 导入/导出错误

### E2.01 导出路径不能为空 / 导出目录不存在

> 导出路径不能为空 / 导出目录不存在

- **可能原因: 导出实例时未选择目标目录,或目录已被删除。**
- **解决: 在导出对话框中点击"浏览"选择有效的本地目录(不要选桌面/下载以外受保护的路径)。**

### E2.02 目标文件已存在,请先删除或更换名称: <path>

> 目标文件已存在,请先删除或更换名称: <path>

- **可能原因: 导出文件已存在于目标位置。**
- **解决: 删除同名文件后重试,或更换导出文件名;也可勾选"覆盖"。**

### E2.03 实例中没有文件可导出

> 实例中没有文件可导出

- **可能原因: 当前实例目录为空,无法打包。**
- **解决: 确认实例路径指向已安装的游戏目录;若游戏未安装,请先安装原版 MO。**

### E2.04 导出过程中发生错误: 输出文件未生成 / 输出文件为空

> 导出过程中发生错误: 输出文件未生成 / 输出文件为空

- **可能原因: 打包过程中文件读取/写入失败,生成的文件大小为 0。**
- **解决: 检查磁盘空间;关闭可能占用目标文件的程序(杀毒);以管理员身份运行。**

### E2.05 导出失败: 权限不足 (<e>)。请尝试以管理员身份运行,或更换导出目录。

> 导出失败: 权限不足 (<e>)。请尝试以管理员身份运行,或更换导出目录。

- **可能原因: 目标目录需要管理员权限(如 C:\Program Files)。**
- **解决: 右键启动器 → 以管理员身份运行;或将导出目标改为本地用户目录(桌面/文档)。**

### E2.06 导出失败: 磁盘/系统错误 (<e>)。请检查磁盘空间和路径权限。

> 导出失败: 磁盘/系统错误 (<e>)。请检查磁盘空间和路径权限。

- **可能原因: 磁盘满、文件系统错误或路径过长。**
- **解决: 清理磁盘空间;检查目标磁盘格式(NTFS);缩短路径层级。**

### E2.07 7z 支持不可用,请先安装 py7zr 库 (pip install py7zr)

> 7z 支持不可用,请先安装 py7zr 库 (pip install py7zr)

- **可能原因: 选择 .7z 格式但运行时缺少 py7zr 依赖。**
- **解决: 在终端执行: pip install py7zr;或在启动器设置中改用 .zip 导出。**

### E2.08 ZIP 导出失败: <错误类型>: <e>

> ZIP 导出失败: <错误类型>: <e>

- **可能原因: 写入 zip 时权限/磁盘/系统错误。**
- **解决: 参见 E2.05 / E2.06 解决方案。**

### E2.09 7z 导出失败: <错误类型>: <e>

> 7z 导出失败: <错误类型>: <e>

- **可能原因: 写入 7z 时权限/磁盘/系统错误。**
- **解决: 参见 E2.05 / E2.06 解决方案,或改用 .zip 格式。**

### E2.10 未检测到 WinRAR CLI,且同名 .zip 已存在: <path>

> 未检测到 WinRAR CLI,且同名 .zip 已存在: <path>

- **可能原因: 使用 WinRAR 打包但未找到 rar.exe,且 .zip 已存在。**
- **解决: 安装 WinRAR 并加入 PATH;或删除同名 .zip 后重试;或改用 .zip 格式。**

### E2.11 不支持的文件格式 / 无效的实例文件:缺少配置文件

> 不支持的文件格式 / 无效的实例文件:缺少配置文件

- **可能原因: 导入的压缩包不是有效的实例包,或缺少 config.json。**
- **解决: 确认压缩包来源正确;在资源管理器中打开查看是否含 config.json。**

### E2.12 无法找到游戏文件目录 (game\_files) / 解压的文件不是有效的心灵终结游戏目录

> 无法找到游戏文件目录 (game\_files) / 解压的文件不是有效的心灵终结游戏目录

- **可能原因: 导入的实例包中缺少游戏文件,或目录结构不正确。**
- **解决: 从可信来源重新下载实例包;或自行打包时确保包含完整的 game\_files 子目录。**

### E2.13 复制游戏文件失败: 所有 <N> 个文件均无法复制

> 复制游戏文件失败: 所有 <N> 个文件均无法复制

- **可能原因: 导入过程中全部文件都复制失败(权限/磁盘/路径)。**
- **解决: 关闭游戏进程;以管理员身份运行;检查目标磁盘剩余空间;检查路径是否过长。**

### E2.14 导入已取消

> 导入已取消

- **可能原因: 用户在导入对话框点击了"取消"。**
- **解决: 无需处理,若需继续请重新发起导入。**

### E2.15 配置文件格式错误

> 配置文件格式错误

- **可能原因: 实例包中的 config.json 不是合法 JSON。**
- **解决: 用文本编辑器打开校验 JSON 格式;或重新下载实例包。**

### E2.16 导出已取消

> 导出已取消

- **可能原因: 用户在导出对话框点击了"取消"。**
- **解决: 无需处理,若需继续请重新发起导出。**

### E2.17 导入失败: \<str(e)> / 导出失败: <e>

> 导入失败: \<str(e)> / 导出失败: <e>

- **可能原因: 未分类的通用异常。**
- **解决: 查看 logs/HMOL\_\*.log 中的 traceback,联系开发者并附上日志。**

### E2.18 无法删除已存在文件: <e> / 清理旧目标失败: <e>

> 无法删除已存在文件: <e> / 清理旧目标失败: <e>

- **可能原因: 覆盖/替换目标时,文件被占用或权限不足。**
- **解决: 关闭可能占用目标文件的程序(游戏/杀毒);以管理员身份运行。**

### E2.19 读取目录失败: <e> / 打开失败: <e>

> 读取目录失败: <e> / 打开失败: <e>

- **可能原因: 目录读取异常(权限/IO 错误)。**
- **解决: 检查目录权限;以管理员身份运行;更换目标目录。**

#### E2.20  无法打开浏览器。

建议: 请检查默认浏览器设置,或手动复制链接打开。

> 无法打开浏览器。
> 建议: 请检查默认浏览器设置,或手动复制链接打开。

### E2.21 打开浏览器时发生错误: <e>

> 打开浏览器时发生错误: <e>

- **可能原因: webbrowser.open 抛出异常。**

### E2.22 请先选择要重命名的项目 / 请先选择要删除的项目 / 请先选择要打开的项目

> 请先选择要重命名的项目 / 请先选择要删除的项目 / 请先选择要打开的项目

- **可能原因: 在文件/插件列表中未选中目标项。**
- **解决: 先在列表中点击选中目标项,再执行对应操作。**

### E2.23 重命名失败: <e> / 删除失败: <e>

> 重命名失败: <e> / 删除失败: <e>

- **可能原因: 文件被占用、权限不足或路径冲突。**

### E2.24 项目不存在: <path>

> 项目不存在: <path>

- **可能原因: 选中的文件/目录已不存在。**
- **解决: 刷新列表;或重新选择其他目标。**

## E3 插件包安装错误

### E3.01 请先选择一个游戏实例 / 请先选择游戏实例

> 请先选择一个游戏实例 / 请先选择游戏实例

- **可能原因: 未选中任何实例就触发安装/启动。**
- **解决: 在【实例管理】中先选中一个有效的实例,或新建一个。**

#### E3.02  实例目录无效

当前实例的游戏目录已不存在或被移动

> 实例目录无效
> 当前实例的游戏目录已不存在或被移动

- **可能原因: 安装前二次校验,发现实例目录已失效。**
- **解决: 在【实例管理】中更新路径。**

### E3.03 包文件不存在: <src>

> 包文件不存在: <src>

- **可能原因: 选中的插件包文件已被移动/删除。**
- **解决: 在插件列表中点击"刷新"重新扫描;或重新下载/导入该包。**

### E3.04 ZIP 文件已损坏或格式错误: <src> / 读取 ZIP 文件失败: <e>

> ZIP 文件已损坏或格式错误: <src> / 读取 ZIP 文件失败: <e>

- **可能原因: 压缩包不是合法 zip,或下载未完成。**
- **解决: 重新下载该压缩包;校验 MD5/SHA1;用 7-Zip/WinRAR 单独打开测试。**

### E3.05 7z 支持不可用,请先安装 py7zr 库: pip install py7zr

> 7z 支持不可用,请先安装 py7zr 库: pip install py7zr

- **可能原因: 选择 .7z 包但缺少 py7zr。**
- **解决: pip install py7zr 后重启启动器。**

### E3.06 RAR 支持不可用,请先安装 rarfile 库: pip install rarfile

> RAR 支持不可用,请先安装 rarfile 库: pip install rarfile

- **可能原因: 选择 .rar 包但缺少 rarfile。**
- **解决: pip install rarfile 后重启启动器;Windows 还需要安装 unrar.exe 并加入 PATH。**

### E3.07 RAR 解压需要系统已安装 unrar/WinRAR

> RAR 解压需要系统已安装 unrar/WinRAR

- **可能原因: rarfile 依赖系统 unrar 命令行。**
- **解决: 从 win-rar.com 下载并安装 WinRAR,或单独下载 unrar.exe 到 PATH。**

### E3.08 RAR 解压失败: <e>

> RAR 解压失败: <e>

- **可能原因: rar 格式异常或密码错误。**
- **解决: 重新下载;检查包是否加密;更换解压工具。**

#### E3.09  压缩包已损坏或格式错误: <类型>: <e>

请重新下载该压缩包后重试。

> 压缩包已损坏或格式错误: <类型>: <e>
> 请重新下载该压缩包后重试。

- **可能原因: 解压过程中抛出 BadZipFile/Bad7zFile/BadRarFile/LZMAError/ReadError 等。**
- **解决: 重新下载;校验文件哈希;不要在下载途中断电/退出。**

### E3.10 解压失败: <e>

> 解压失败: <e>

- **可能原因: 通用解压异常。**
- **解决: 检查磁盘空间;关闭杀毒软件对临时目录的扫描;重新下载。**

### E3.11 读取解压结果失败: <e>

> 读取解压结果失败: <e>

- **可能原因: 解压后无法 listdir 临时目录。**
- **解决: 检查临时目录权限;清理 %TEMP%;重启电脑。**

### E3.12 压缩包内容为空,未解压到任何文件

> 压缩包内容为空,未解压到任何文件

- **可能原因: 压缩包是空包(zip 内 0 文件)。**
- **解决: 重新下载;或联系作者确认该包是否完整。**

### E3.13 安装源中没有可复制的文件

> 安装源中没有可复制的文件

- **可能原因: 解压后目录为空。**
- **解决: 重新下载;确认压缩包非空。**

### E3.14 安装失败: 所有 <N> 个文件均无法复制

> 安装失败: 所有 <N> 个文件均无法复制

- **可能原因: 复制过程全部失败(权限/磁盘/路径)。**
- **解决: 关闭游戏/杀毒/Steam;以管理员身份运行;检查磁盘空间。**

### E3.15 安装后目标目录为空,可能复制失败

## 附录 A: 通用排查步骤

1. 查看启动器同目录下的 logs/HMOL\_<日期>.log,搜索 ERROR / Traceback 关键字。
2. 关闭游戏主程序、EAC、Steam、杀毒软件后再操作。
3. 右键启动器 → 以管理员身份运行。
4. 检查磁盘剩余空间(建议 > 5 GB)。
5. 确认 Windows 已更新到最新版本,安装了最新的 VC++ 运行库。
6. 重新安装缺失的 Python 依赖: pip install -r requirements.txt
7. 备份并删除启动器目录下的 HMOL\_config.json、instances/、cache/ 后重试。
8. 若仍无法解决,在 GitHub Issues 附上 log 文件和复现步骤。
