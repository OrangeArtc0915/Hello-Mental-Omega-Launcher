## 2. 下载 HMOL

> ⚠️ **请仅从官方渠道下载,任何其他渠道提供的二进制均可能已被修改,可能包含恶意代码。**

### 2.1 官方下载渠道

| 渠道              | 链接                                                                       |
| --------------- | ------------------------------------------------------------------------ |
| GitHub Releases | <https://github.com/OrangeArtc0915/Hello-Mental-Omega-Launcher/releases> |

### 2.2 版本命名

示例:

- `HMOL_v2.4_release_20260720.zip` — 正式发布版
- `HMOL_v2.4_secure_20260720.zip` — 字节码加密版

### 2.3 验证下载完整性

每个 Release 都附带 SHA-256 校验和:

```powershell
# Windows PowerShell
Get-FileHash .\HMOL_v2.4_release_20260720.zip -Algorithm SHA256
```

将输出与 GitHub Release 页面公布的哈希值对比,**必须完全一致**才可使用。

## 3. 安装方式

<br />

1. 运行 `HMOL_v2.4_release_setup.exe`
2. 按向导选择安装路径(默认 `C:\Program Files\HMOL\`)
3. 选择「桌面快捷方式」「开始菜单快捷方式」
4. 点击「安装」
5. 安装完成后双击桌面图标启动

**注意**: 安装到 `Program Files` 需要管理员权限,且后续备份可能受 UAC 限制,**推荐安装到非系统盘**。

***

## 4. 首次启动

### 4.1 EULA 协议

首次启动会弹出 **最终用户许可协议** 对话框,包含 14 个章节,核心条款:

- ⛔ **§3 二次修改禁令** — 严禁任何形式的二次修改
- ✅ §4 仅限个人非商业使用
- ⚠️ §7 按"现状"提供,无担保
- 🚫 §9 禁止违法、作弊、刷屏、商业滥用

请仔细阅读后:

- 点击「✅ 同意」继续(可使用全部功能)
- 点击「❌ 不同意,退出」将**立即清理所有临时数据**后退出

### 4.2 实例创建向导

同意 EULA 后,启动器会引导您创建第一个游戏实例:

1. 点击「🎮 实例管理」→「新建实例」
2. 填写 **实例名称**(例:`MO_主版本`、`MO_测试版`)
3. 点击「浏览」选择 **心灵终结安装根目录**
   - 必须包含 `Mental_Omega_client.exe`
   - 必须包含 `Maps/`、`Resources/` 等标准 MO 目录
4. 点击「创建」后。点击 \[备份原版文件].

### 4.3 主题与背景

- **设置 → 主题**: 6 套主题可选(深空蓝、暮光紫、森林绿、烈焰红、海洋蓝、经典深色)
- **设置 → 背景**: 支持自定义 JPG/PNG/WEBP 图片
- **设置 → 字体**: 跟随系统或自定义

## 5. 升级与降级

### 5.1 升级到新版本

1. 备份当前数据(可选):
   ```
   复制整个启动器目录即可(配置在 HMOL_config.json)
   ```
2. 下载新版本 安装程序
3. 解压到 **新目录**(不要直接覆盖)
4. 首次启动新版本会提示「导入旧配置」,选择「是」
5. 验证功能正常后,删除旧目录

### 5.2 降级到旧版本

仅在当前版本存在严重 Bug 时降级:

1. 卸载当前版本(参见[卸载指南](HMOL-User-Guide#卸载))
2. 从 GitHub Releases 下载旧版本 ZIP
3. 按绿色版流程安装

**注意**: 降级后**已加密的令牌缓存可能无法读取**(因机器码派生密钥一致则可读)。

***

## 6. 卸载

<br />

- **Windows 设置 → 应用 → 搜索「HMOL」 → 卸载**
- 或运行安装目录下的 `unins000.exe`

卸载后,以下本地数据 **不会被自动删除**:

- `%APPDATA%\HMOL\` — 用户配置(若启用)
- `%LOCALAPPDATA%\HMOL\logs\` — 运行日志
- 启动器目录下的 `instances/`、`backups/`、`cache/`、`temp/`

如需彻底清理,手动删除上述目录。
