## 📌 首页（Home） / Home Page

启动器默认进入首页，显示：

- **背景图**：可自定义（设置 → 主题）
- **当前实例名称**
- **快速启动按钮**（点击启动游戏）
- **实例切换器**
- **最近活动**（最近 3 次操作）

### 切换主页背景

1. 点击"设置" → "主题与外观"
2. 选择"自定义背景图"
3. 选择本地 PNG/JPG 文件（≤ 10 MB）
4. 立即生效

### 返回首页

任何页面下点击左侧"首页"按钮即可。

## 📂 实例管理 / Instance Management

> 实例 = 一个游戏安装目录 + 独立的配置/插件/备份。

### 添加实例

1. 左侧"实例管理" → 点击 **"添加实例"**
2. 填写**实例名称**（1-64 字符，不与现有实例重名）
3. 点击 **"浏览"** 选择游戏根目录
4. 系统自动验证：必须包含 `Mental_Omega_client.exe`
5. 点击 **"确定"** 完成

> 💡 **提示**：一个游戏目录只能绑定到一个实例。如需多版本共存，请将游戏安装到不同目录。

### 切换实例

在实例列表中**单击**目标实例，状态栏立即更新。

### 重命名实例

1. 选中实例 → 点击 **"重命名"**
2. 输入新名称（避免 `< > : " / \ | ? *` 等特殊字符）
3. 确定

### 删除实例

1. 选中实例 → 点击 **"删除"**
2. 二次确认对话框出现
3. 选择「仅删除配置（保留游戏文件）」或「同时删除游戏文件」
4. 确认删除

> ⚠️ **删除游戏文件不可恢复**！建议先 [备份](HMOL-Wine-Features#备份与还原) 再删除。

### 导出实例

将整个实例打包为压缩包（用于备份或迁移）：

1. 选中实例 → 点击 **"导出"**
2. 选择格式：**ZIP / 7Z**（需要 `py7zr`）/ **RAR**（需要 WinRAR）
3. 选择保存位置
4. 等待进度条完成

> 详见 [Features › 实例导出](HMOL-Wine-Features#实例导出导入)

### 导入实例

从 `.zip` / `.7z` 压缩包导入实例：

1. 点击 **"导入"**
2. 选择压缩包文件
3. 程序自动解压、验证、注册到实例列表

## 📦 包管理 / Package Management

> 插件包 = 第三方资源（任务包、地图、模组）的标准压缩包。

### 安装插件包

1. 左侧"包" → 确认已选择目标实例
2. **方式 A**：从 `导入包`点击"刷新"
3. **方式 B**：从 OneDrive（笨蛋广场）下载
4. 选中包 → 点击 **"安装选中"**
5. 若有文件冲突，弹出确认对话框（覆盖/取消）
6. 等待进度条完成

### 卸载插件包

1. 切换到"已安装"标签
2. 选中要卸载的包 → 点击 **"卸载选中"**
3. 程序按 `install_record.json` 精确删除
4. 二次确认

### 导入本地包

将外部 `.zip` / `.7z` / `.rar` 文件导入到 `packages/` 目录：

1. 点击 **"导入包"**
2. 选择文件
3. 复制到 `packages/` 目录并加入列表

### 查看安装记录

- 启动器使用 `instances/<id>/install_record.json` 精确记录每个包安装的每个文件
- 卸载时**只删除**记录中的文件，不会误删其他包的内容

## 💾 备份与还原 / Backup & Restore

### 创建备份

1. 左侧"备份" → 选中实例
2. 点击 **"创建备份"**
3. 输入备份名称（1-100 字符，避免保留名 `CON/PRN/AUX/NUL`）
4. 等待进度条完成
5. 备份保存到 `backups/<实例ID>/<备份名>/`

### 还原备份

1. 左侧"备份" → 选中实例
2. 在备份列表中选择目标备份
3. 点击 **"还原"**
4. ⚠️ **全量覆盖确认**：会覆盖当前游戏目录所有内容
5. 确认后等待进度条完成

> 💡 **建议**：每次安装大型插件包前先备份原版。

### 删除备份

1. 选中备份 → 点击 **"删除"**
2. 二次确认

## ☁️ 笨蛋广场（OneDrive 共享） / SharePoint

> HMOL 内置 OneDrive 资源浏览，原名 "OneDrive"，重命名为「笨蛋广场」。

### 登录微软账号

1. 左侧"账号" → 点击 **"登录"**
2. 浏览器自动打开 `https://microsoft.com/devicelogin`
3. 输入 8 位设备码
4. 完成授权
5. 关闭浏览器，程序自动继续

### 浏览共享资源

1. 左侧"笨蛋广场" → 等待列表加载
2. 文件夹标 `[文件夹]`，可双击进入
3. 文件标 `[文件]`，可右键下载

### 下载资源

1. 选中文件 → 点击 **"下载"**
2. 选择保存目录
3. 等待下载完成
4. 程序自动询问是否安装到游戏目录

### 退出登录

左侧"账号" → **"退出登录"** → 确认 → 令牌从本地清除（加密文件被覆盖）

## 🛒 DLC 启动器 / DLC Launcher

> 启动第三方附加组件（如原版红警 2、对战平台等）。

### 安装 DLC

将 DLC 文件夹放入 `DLC/` 目录（必须包含 `DLC.json`），启动器自动识别。

`DLC.json` 示例：

```json
{
  "name": "示例 DLC",
  "version": "1.0",
  "main_path": "Game.exe",
  "description": "示例说明"
}
```

### 启动 DLC

1. 左侧"DLC" → 选中目标 DLC
2. 点击 **"启动"**
3. 主程序文件执行

### 打开 DLC 目录

点击 **"打开目录"** 在资源管理器中查看。

## 👤 账号管理 / Account

### 微软账号

- **登录**：触发设备代码流
- **查看信息**：显示用户名、Xbox Gamertag（如有）
- **退出登录**：清除本地加密令牌
- **Xbox 玩家代号**：可手动设置或读取

### QQ Bot 凭据

- 在设置中配置：
  - `AppID` / `AppSecret`（QQ 开放平台申请）
  - 群 ID（默认 ）
- 程序运行时从加密 seal 读取，绝不明文保存

## ⚙️ 设置 / Settings

### 主题与外观

- **6 套主题**：Mocha、Latte、Dracula、Nord、Solarized、Light
- **自定义背景图**：选择本地图片
- **字体大小**：10 / 11 / 12 / 14 pt

### 启动参数

- 启动游戏时附带的命令行参数（默认空）
- 例：`-speedcontrol -win`

### QQ 喊话

- 启用/禁用喊话功能
- 配置 群 ID
- 测试发送（仅本机测试）

### OneDrive 缓存

- 清除本地缓存
- 重置 share\_url

### 法律与协议

- 查看 EULA 全文
- 同意/撤销 EULA（撤销后下次启动需重新接受）
- 显示当前接受的 EULA 版本

### 日志

- **打开日志目录**
- **导出日志**：将所有日志打包为 ZIP
- **清理 30 天前的日志**

## 🖱️ 侧边栏编辑（高级） / Sidebar Editor

> HMOL 内置拖拽式侧边栏编辑（v2.4 起开放给用户）。

### 进入编辑模式

左侧"设置" → "侧边栏布局" → **"编辑"**

### 拖拽重排

- 按住**任一按钮**拖动到新位置
- 6 px 移动阈值后视为拖拽
- 释放后自动吸附

### 重命名

- 右键 → "重命名" → 输入新名称

### 隐藏/显示

- 右键 → "隐藏"
- 在"已隐藏"区域可恢复

### 调整宽度

- 拖动侧边栏右边缘的 **<img>** **双箭头光标** 调整宽度
- 几何以**分数**存储，自动适配窗口大小

### 保存/取消

- "保存"：写入 `sidebar_layout.yaml`
- "取消"：回滚本次会话所有修改

### 导入/导出方案

- "导出"：保存为 `.yaml` 文件
- "导入"：从 `.yaml` 恢复布局

> 详见 [Features › 侧边栏布局编辑器](HMOL-Wine-Features#侧边栏布局编辑器)
