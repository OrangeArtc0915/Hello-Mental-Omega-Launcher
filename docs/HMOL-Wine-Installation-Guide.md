## 🔧 安装步骤 / Installation Steps

1. 打开 [GitHub Releases](https://github.com/OrangeArtc0915/Hello-Mental-Omega-Launcher/releases)
2. 下载最新版本的 `HMOL-Setup-x.x.x.exe`
3. **右键 → 以管理员身份运行**安装程序
4. 按向导选择安装路径（**避免** **`C:\Program Files`** **等受保护目录**）
5. 勾选「创建桌面快捷方式」
6. 完成安装
7. **首次启动前**：将启动器目录加入杀毒软件白名单
8. 双击桌面图标启动

> 💡 **路径建议**：`D:\HMOL\`、`E:\Programs\HMOL\`（非系统盘、纯英文/数字路径）

## 🛡️ 首次启动前的安全准备 / Pre-launch Security

### 1. 杀毒软件白名单

启动器包含加密模块、PyInstaller 字节码和 `subprocess` 调用，部分杀软可能误报。**请将以下加入信任区：**

| 杀软               | 操作                              |
| ---------------- | ------------------------------- |
| Windows Defender | 设置 → 病毒防护 → 排除项 → 添加 `D:\HMOL\` |
| 360 安全卫士         | 信任区 → 添加文件夹                     |
| 火绒               | 信任区 → 添加文件夹                     |
| 卡巴斯基             | 设置 → 排除项 → 添加                   |
| McAfee           | 配置 → 排除项 → 添加                   |

### 2. 防火墙放行

首次启动如弹出"是否允许网络访问"对话框，**点击「允许」**。启动器仅在以下情况访问网络：

- 微软设备代码流登录
- OneDrive 资源浏览
- QQ 喊话
- 安全审计/版本检查

> 🚫 **启动器不会主动上传任何用户数据**（无中央服务器）。

### 3. Windows 运行库

若提示 `MSVCP140.dll` / `VCRUNTIME140.dll` 缺失：

- 下载安装 [Microsoft Visual C++ 2015-2022 Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe)
- 重启电脑后再次启动

## 🚀 首次启动 / First Launch

### EULA 接受流程

启动后立即弹出 EULA 对话框（不可关闭主窗口）：

```
┌─────────────────────────────────────┐
│   HMOL 启动器 最终用户许可协议       │
├─────────────────────────────────────┤
│  [EULA 全文 - 可滚动查看]           │
│                                     │
│  ☑ 我已阅读并同意上述协议           │
│                                     │
│  ⚠️ 不允许二次修改程序（红字高亮）  │
│                                     │
│  [同意并继续]    [不同意并退出]     │
└─────────────────────────────────────┘
```

- **同意**：进入主界面，程序自动生成 `HMOL_crypto_entropy.bin`（机器绑定）
- **不同意**：清理临时数据后立即 `os._exit(0)` 退出

### 初始配置生成

首次同意 EULA 后，程序会创建：

| 文件                        | 用途              |
| ------------------------- | --------------- |
| `HMOL_config.json`        | 主配置（主题、背景、凭据占位） |
| `HMOL_crypto_entropy.bin` | 加密熵文件（机器绑定）     |
| `instances/`              | 空目录，待添加实例       |
| `packages/`               | 空目录，待放置本地插件包    |
| `backups/`                | 空目录             |
| `logs/`                   | 日志目录            |
| `temp/`                   | 临时目录            |

> 💡 这些文件**全部位于启动器目录**，不会写入 C 盘系统目录。

## ✅ 验证安装成功 / Verify Installation

### 1. 启动器能正常打开

- 双击 `HMOL.exe` 或桌面图标
- 主界面在 3 秒内显示
- 标题栏显示 "Hello Mental Omega Launcher v2.4"

### 2. 实例管理可用

1. 点击左侧"实例管理"
2. 点击"添加实例"
3. 选择心灵终结游戏根目录（含 `Mental_Omega_client.exe`）
4. 列表显示实例名称

### 3. 启动游戏

1. 在实例列表中选择实例
2. 点击主页面"启动游戏"按钮
3. 游戏客户端弹出

### 4. 错误码手册可访问

启动器同目录下的 `docs/HMOL_错误代码与解决方法.docx` 可正常打开。

## 🔄 升级与降级 / Upgrade & Downgrade

### 升级到最新版本

1. 备份 `HMOL_config.json` 和 `instances/` 目录
2. 下载新版本 EXE
3. 解压/安装到**任意目录**（不要覆盖旧文件）
4. 重启程序 → 首次会检测 EULA 版本变更并要求重新接受
5. 验证实例和插件包仍存在

### 降级到旧版本

- 卸载新版本
- 安装旧版本 EXE 到同一目录
- **注意**：旧版本可能无法识别新版本的配置格式，建议先删除 `HMOL_config.json` 让程序重建

### 干净卸载

1. 关闭启动器
2. 删除启动器所在目录
3. 删除桌面快捷方式
4. 从杀毒软件白名单移除

## 🐛 安装失败排查 / Installation Troubleshooting

| 症状                | 原因                     | 解决方法                         |
| ----------------- | ---------------------- | ---------------------------- |
| 双击无反应             | 杀软拦截 / VC++ 缺失 / 路径权限  | 加入白名单 / 安装运行库 / 移到非系统盘       |
| `MSVCP140.dll` 缺失 | VC++ 未安装               | 安装 2015-2022 Redistributable |
| EULA 不弹出          | 残留进程占用                 | 任务管理器结束 HMOL.exe 后重启         |
| `PermissionError` | 目录在 `C:\Program Files` | 移到 D:\HMOL\ 等可写目录            |
| EXE 被杀软删除         | 静态启发式误报                | 信任区白名单后重新下载                  |
