title: 快速开始
---

本插件包作为 **HMOL 的 DLC** 运行，**不能独立启动**。请始终从 HMOL 程序内打开。

---

## 1. 启动前准备

| 要求 | 说明 |
| --- | --- |
| HMOL 程序 | 本插件包位于 HMOL 的 DLC 目录，需通过 HMOL 启动 |
| 微软账号登录 | 未登录会被拒绝启动（本地检测登录缓存，不联网） |
| 管理员权限 | 建议以管理员运行，便于安装虚拟网卡驱动、修改网卡优先级等操作 |

首次启动时请阅读并**同意最终用户协议**（EULA），否则程序会退出。

## 2. 启动方式

1. 打开 HMOL 程序并登录微软账号。
2. 在 HMOL 中找到 DLC 列表，启动 **HMOL联机模块**。
3. 窗口打开后，顶部标题显示当前版本号，侧边栏显示当前是否为管理员。

> 昵称默认取 HMOL 的 **Xbox 玩家代号**，用于大厅、聊天、收藏队友中展示。若未设置，请在 HMOL 账号页填写玩家代号。

## 3. 最简开黑流程（EasyTier 方案）

> 新手直接选默认方案 EasyTier 即可，无需任何额外配置。

### 房主

1. 在 **网络设置** 页确认方案为 **EasyTier**。
2. 填写 **房间名称**（小组名，可点「随机生成」）。
3. 点 **连接**，等待侧边栏「连接状态」变为已连接、出现虚拟 IP。
4. 点顶部 **分享给队友**，复制分享文本发给好友。

### 队友

1. 复制房主发来的分享文本。
2. 点顶部 **一键加入**。
3. 程序自动识别并填入方案、节点、房间、密钥等配置，并自动连接。

> 如果程序启动时剪贴板里已有分享文本，会自动询问是否一键加入。

## 4. 游戏内联机

连接成功后，双方在游戏里通过**局域网 / 虚拟网卡**互相发现：

- 若游戏支持局域网广播，虚拟网卡会自动广播，房间互相可见；
- 若无法自动发现，可在 [工具箱 → 网卡优先级](/multiplayer/toolbox#_3-网卡优先级) 中让广播优先走虚拟网卡；
- 也可以在游戏内直接填入对方的**虚拟 IP** 联机。

## 5. 分享文本长什么样

```
方案: EasyTier
节点: udp://39.108.52.138:11010
小组: ABC123
密钥: 
IP: 自动
```

- **方案**：EasyTier / n2n / ZeroTier / Anywherelan。
- **小组**：房间名称，双方必须一致才能互相发现。
- **密钥**：可选的组网加密密钥，留空不加密。
- **IP**：自动或手动 IP。
- ZeroTier 方案会携带**网络 ID**，Anywherelan 方案会携带房主 **Peer ID**。
- 分享文本带版本号，**版本不一致会拒绝联机**。

## 6. 首次使用 n2n 方案（如需要）

n2n 是二层方案，需要 **TAP 虚拟网卡驱动**：

1. 在 网络设置 选择 **n2n** 方案。
2. 在 n2n 专属工具中点击 **TAP 安装**。
3. 驱动就绪后，再点 **连接**。
