## 1. 启动相关

### 双击没有反应 / 无法启动？
本插件包是 HMOL 的 **DLC**，不能独立启动。请从 **HMOL 程序 → DLC** 启动。

### 提示未登录微软账号？
请在 HMOL 中登录微软账号后重新启动。登录状态为本地检测，不需要联网验证。

### 提示需要管理员权限？
虚拟网卡驱动安装、防火墙关闭、网卡优先级修改都需要管理员权限。请以管理员方式运行 HMOL。

## 2. 连接相关

### 连不上 / 一直显示连接中？
1. 用 **工具箱 → 连通性检测** 测 PING 节点与 NAT 类型。
2. 尝试 **防火墙 → 一键关闭**（需管理员），关闭后再连接。
3. 点 **节点测速** 换一个节点，或到 更多设置 添加自定义节点。

### 双方都能连，但互 ping 不通？
- 最常见原因是防火墙拦截，先关防火墙测试。
- 检查双方**房间名称（小组名）**与**密钥**是否一致。
- 检查虚拟 IP 是否在同一网段（n2n 手动模式请确认两人 IP 不同）。

### 游戏里发现不到房间？
- 运行 **工具箱 → 网卡优先级**，让广播优先走虚拟网卡。
- 或改用 **n2n / Anywherelan** 方案（二层广播 / 广播自动发现，见 [四方案详解](/multiplayer/engines)）。
- 也可以直接填对方的**虚拟 IP** 进游戏。

## 3. 方案相关

### n2n 提示需要 TAP 驱动？
先到 网络设置 → n2n 专属工具 → **TAP 安装**，装好虚拟网卡驱动再连接。驱动已就绪时会提示无需重复安装。

### n2n 自动模式拿不到 IP？
公共 supernode 可能未开 DHCP 地址池。程序会自动回退为手动 IP 重试；手动模式下让队友改用不同 IP（如 .66 与 .67）。

### ZeroTier 提示需要 API 令牌？
令牌仅**房主**需要：`my.zerotier.com → Account → API Access Tokens` 获取，在 网络设置 填写。成员只需网络 ID。

### Anywherelan 手动 IP 用不了？
Anywherelan 方案自动分配虚拟 IP，**手动 IP 模式不适用**，属正常现象。

## 4. 延迟 / 性能相关

### 延迟高？
- P2P 打洞成功直连时延迟最低；中转时偏高。可查看 在线对端 的「隧道」列判断直连或中转。
- 选离你最近的节点；NAT 检测中 FullCone 更易打洞成功。

### 游戏卡顿？
- 关闭无关下载/直播。
- HUD 浮窗可拖动到角落或关闭（顶部 HUD 按钮）。

## 5. 其他

### 文件传不出去？
确认双方都在同一房间且在线，单文件需 ≤ 500MB，大文件先压缩再传。

### 收藏队友在哪里？
大厅 → **收藏队友** 页签，本地保存，不会上传。

### 聊天内容安全吗？
**大厅聊天是公开广场**，内容明文公开可见，请勿发送敏感信息。房间聊天仅房间成员可见。

### 想自己搭节点？
n2n 方案可在 网络设置 → n2n 专属工具 → **服务端模式** 在有公网 IP 的机器上自建 supernode。

把 **运行日志 → 导出** 的日志连同现象描述发到 QQ 群（1 群 1034243331 / 2 群 1092671790）。
