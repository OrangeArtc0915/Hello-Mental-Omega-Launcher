## 1. 文件传输

> 需要先连接联机房间，且对方在线。

### 入口

- 工具箱 → **文件传输**。
- 或在线对端 / 聊天窗口中的传文件入口。

### 使用

1. 选择在线队友（通过其虚拟 IP 直连）。
2. 选择要发送的文件（**单文件上限 500MB**，建议发送前先压缩）。
3. 对方收到接收提示后确认，文件保存到本地。

### 说明

- 采用**直连对端虚拟 IP** 的 TCP 传输，不经公网中转，速度快。
- 重名文件自动保存为「文件名 (1).扩展名」，不会覆盖。
- 传输进度、完成/失败均有日志与提示。

> 提示：大文件先压缩（zip / rar）再发，可显著缩短传输时间并减少出错。

## 2. 游戏 HUD 浮窗

顶部 **HUD** 按钮开启/关闭游戏内浮窗。

- 深色卡片式浮窗，**实时显示队友在线状态与延迟**，方便游戏中随时掌握队友情况。
- 可**按住拖动**调整位置，位置自动记忆到配置。
- 角落有可拖动的**控制球**，用于开关 HUD / 退出。

> 适合窗口化游戏，可放在游戏画面角落不遮挡视线。

---

## 3. 系统托盘

关闭主窗口时程序可最小化到**系统托盘**（需在配置中开启托盘/最小化行为）。

- 右键托盘图标：**显示主窗口** / **退出程序**。
- 左键单击托盘图标：恢复主窗口。
- 托盘实现为纯系统 API（ctypes），无第三方依赖。
