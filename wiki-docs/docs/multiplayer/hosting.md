## 1. 建房（房主）

1. 在 **网络设置** 页选择组网方案（见 [四方案详解](/multiplayer/engines)）。
2. 填写 **房间名称**（小组名）：可手动输入，或点「随机生成」生成 6 位随机名。此名称会展示在大厅，玩家据此识别。
3. **加密密钥**（可选）：留空表示不加密；若填写，成员必须使用相同密钥才能入房。
4. 选择**虚拟 IP 模式**（默认自动；n2n 也可选手动并填 IP）。
5. 点 **连接**，等待侧边栏「连接状态」变为已连接、出现虚拟 IP。

> ZeroTier 方案房主需先填 API 令牌；Anywherelan 方案建房后自动生成 Peer ID。

## 2. 分享给队友

连接成功后，点顶部 **分享给队友**，复制弹出的分享文本发给好友（QQ / 微信均可）。

分享文本包含：方案、节点、小组（房间名）、密钥、IP，以及对应方案所需的网络 ID / Peer ID 与版本号。

## 3. 成员加入

### 方式 A：一键加入（推荐）

1. 复制房主发来的**分享文本**。
2. 点顶部 **一键加入**。
3. 程序自动解析并填入全部配置，未连接时自动开始连接。

> 程序启动时若剪贴板里已有分享文本，会自动询问是否一键加入。已连接时不会重复弹窗。

### 方式 B：手动填写

按分享文本内容，在 网络设置 页手动选择方案、节点、房间名称、密钥、IP 模式，然后点 **连接**。

### 方式 C：从收藏/公开房间加入

见 [大厅与好友](/multiplayer/hall)。

## 4. 公开我的房间（拉路人）

1. 先**连接联机房间**，并**进入大厅**（联机大厅页 → 进入大厅）。
2. 回到 网络设置，勾选 **公开我的房间到大厅**。
3. 大厅「公开房间」列表即可看到你的房间（房主 + 房间名 + 延迟），其他玩家可一键加入。

> 房间名 = 「房间名称」字段。取消勾选即停止公开。

## 5. 邀请入房（房主）

在大厅 **在线玩家** 列表选中某个玩家，点 **邀请入房（房主）** 发送邀请。对方同意后即可加入当前房间。

## 6. 房间聊天与踢人

### 房间聊天

在 **在线对端** 页点 **房间聊天** 打开聊天窗口。聊天消息在房间内所有成员间传播。

### 踢人 / 拉回（仅房主）

- **踢出选中**：在 在线对端 列表选中某玩家后点击，将其移出房间。
- **拉回被踢玩家**：踢错人后，可把被踢玩家拉回房间。

> 只有房主有踢人/拉回权限，聊天与踢人指令均校验房主身份。

## 7. 断开与退出

- 主界面 **连接/断开** 按钮切换连接状态。
- 关闭窗口时程序进入系统托盘（如已开启托盘功能），右键托盘图标可「显示主窗口 / 退出程序」。
