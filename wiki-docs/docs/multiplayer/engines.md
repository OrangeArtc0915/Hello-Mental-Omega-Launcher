---
title: 四方案详解
---

本插件包内置 **四种组网方案**，在「网络设置」页选择。区别主要在**组网层**和**是否依赖服务器**：

| 方案 | 层 | 服务器依赖 | 需要额外安装 | 适合场景 |
| --- | --- | --- | --- | --- |
| **EasyTier**（推荐） | 三层 | 公共节点 | 无 | 绝大多数玩家，开箱即用 |
| **n2n** | 二层 | 公共/自建 supernode | TAP 驱动 | 需要二层广播、老游戏联机 |
| **ZeroTier** | 三层 | ZeroTier 官方网络 | 无界面核心服务 | 想用官方服务建固定网络 |
| **Anywherelan** | 三层 | 无（完全去中心化） | 无 | 不信任服务器、零配置 |

---

## EasyTier（三层 · 推荐）

- 通过公共节点打洞并转发，DHCP 自动分配虚拟 IP（10.x 网段）。
- **零配置**：默认节点 `udp://39.108.52.138:11010`，直接点连接即可。
- 适合：绝大多数玩家，作为默认方案。
- 节点不通时可点击「节点测速」换节点，或到 [更多设置](/multiplayer/toolbox#_5-更多设置) 添加自定义节点。

> 历史默认节点为 TCP 协议，因被防火墙拦截已自动迁移为同主机 UDP 协议，无需手动处理。

## n2n（二层 · 需 TAP 驱动）

- 二层方案，虚拟局域网内可以**直接广播发现**，对老游戏的局域网联机最友好。
- 需要 **TAP 虚拟网卡驱动**（n2n 专属工具 → TAP 安装）。
- 默认节点 `n2n.aobacore.com:9555`，默认网段 `192.168.100.0/24`。
- **虚拟 IP 模式**：
  - **自动**：由 supernode 的地址池分配 IP；
  - **手动**：手动填写 IP（如 `192.168.100.66`），队友填 `192.168.100.67` 等不同 IP，避免冲突。
- 公共节点不通时，可由有公网机器的人自建 supernode（n2n 专属工具 → **服务端模式**）。
- 适合：游戏需要二层广播、对发现机制有要求的玩家。

## ZeroTier（三层 · API 建网）

- 使用 ZeroTier 官方服务自动建网，**房主全程零网页操作**：
  - 房主填写 **API 令牌**（`my.zerotier.com → Account → API Access Tokens` 获取，仅房主需要）；
  - 连接时自动创建或复用网络、自动授权自己，并**后台轮询自动授权新成员**；
  - 成员**无需令牌**，拿到分享文本中的**网络 ID** 即可加入，等待房主授权后自动获取虚拟 IP。
- 内置无界面 zerotier-one 核心服务（官方 MSI 静默安装，不含 GUI 客户端；无本地安装包时自动在线下载）。
- 默认虚拟网段 `172.24.1.0/24`，避开 EasyTier（10.x）与 n2n（192.168.100.x）。
- 该方案下「节点」栏变为「ZeroTier 网络 ID（16 位 hex）」，支持手动编辑。
- 适合：想用 ZeroTier 官方服务、需要固定网络的玩家。

## Anywherelan（三层 · 无服务器）

- **完全去中心化 P2P 组网**：基于 libp2p 公共 DHT 发现设备，**无服务器、无账号、无令牌，零成本零配置**。
- 房主建房后自动生成 **Peer ID**，连接成功写回节点栏；把分享文本发给队友即可自动加入，房主后台自动接受加入请求。
- 内置 headless 服务端（`awl.exe` + `wintun.dll` 随插件包分发），**离线可用、无在线下载依赖**。
- 默认虚拟网段 `10.66.0.0/16`，游戏房间通过虚拟网卡**广播自动发现**，无需手动填 IP。
- 该方案下「节点」栏变为「Anywherelan Peer ID」，**手动 IP 模式不适用**（自动分配虚拟 IP）。
- 适合：不信任任何服务器、追求完全去中心化的玩家。

---

## 怎么选？

1. **不知道选什么** → EasyTier，默认方案，最省心。
2. **游戏局域网发现不到房间** → 试 n2n（二层广播）或 Anywherelan（广播自动发现）。
3. **想用官方网络服务、方便管理成员** → ZeroTier。
4. **完全不想依赖任何服务器** → Anywherelan。

> 切换方案后，分享给队友的文本会自动带上对应方案，队友一键加入即可，无需手动同步配置。
