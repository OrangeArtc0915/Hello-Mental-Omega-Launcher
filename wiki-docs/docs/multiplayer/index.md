HMOL联机模块是一个**跨公网 · 模拟局域网联机工具**，作为 HMOL 程序的 DLC 运行，帮助你和好友在任意网络环境下像在同一局域网一样联机玩红警2 / 心灵终结。

- 当前版本：**v3.2.0**
- 组网方案：EasyTier（三层 · 推荐）、n2n（二层 · 需 TAP 驱动）、ZeroTier（三层 · API 建网）、Anywherelan（三层 · 无服务器）
- 内核：n2n + EasyTier 2.6.4 + ZeroTier + Anywherelan
- 额外功能：联机大厅、房间聊天、收藏队友、文件传输、游戏 HUD、系统托盘、工具箱

## 一分钟上手

1. 从 **HMOL 程序 → DLC** 启动本插件包（不能独立启动）。
2. 确保已在 HMOL 登录**微软账号**（未登录会被拒绝启动）。
3. 主界面选择组网方案，默认 **EasyTier** 即可。
4. 房主：点 **连接**，成功后点顶部 **分享给队友**，把分享文本发给好友。
5. 队友：复制分享文本 → 点顶部 **一键加入**（或直接点连接），自动入房。
6. 双方在游戏里选择对应的虚拟网卡 / 局域网联机即可开黑。

> 详细步骤见 [快速开始](/multiplayer/quick-start)。

## 界面总览

主窗口左侧为侧边栏（管理员状态、连接状态、虚拟 IP、在线对端、引擎信息、延迟代码、当前配置），上方为操作按钮（分享给队友、一键加入、HUD、使用说明），中间为六个页签：

| 页签 | 作用 |
| --- | --- |
| **网络设置** | 选择组网方案、节点服务器、房间名称、加密密钥、虚拟 IP 模式、公开房间、连接/断开 |
| **联机大厅** | 进入公共大厅，浏览在线玩家 / 收藏队友 / 公开房间 |
| **在线对端** | 查看已连队友（IP / 延迟 / 隧道），房间聊天，房主踢人/拉回 |
| **工具箱** | 连通性检测、防火墙、网卡优先级、文件传输、更多设置 |
| **运行日志** | 查看 / 刷新 / 清空 / 导出运行日志 |
| **关于** | 作者、官网、QQ 群、免责声明 |
