---
title: 大厅与好友
---

**联机大厅**是一个公共广场，基于公共 MQTT 信标实现，与你的联机房间**完全解耦**——大厅异常不影响房间组网。

> ⚠️ 大厅为公开广场，**聊天内容明文且公开可见**，请勿发送敏感信息。

---

## 1. 进入大厅

在 **联机大厅** 页点 **进入大厅**，状态变为已进入。昵称默认取 HMOL 的 Xbox 玩家代号。

> 若显示「未设置，请在 HMOL 账号页填写玩家代号」，说明未能获取玩家代号。

## 2. 在线玩家

大厅所有在线玩家列表（昵称 / 公网 IP / 在线时长）。选中玩家后可：

| 操作 | 说明 |
| --- | --- |
| **大厅聊天** | 打开大厅聊天窗口，所有在线玩家可见 |
| **收藏选中玩家** | 把该玩家加入你的收藏（本地保存，不上传） |
| **邀请入房（房主）** | 仅房主可用，邀请对方加入当前房间 |
| **刷新** | 手动刷新在线列表 |

## 3. 收藏队友

收藏数据保存在本地配置（`hmol-LJ-DLC_config.json` 的 friends 字段），**纯本地不上传**。同一 IP 或同一昵称视为同一队友，自动记录**联机次数**与**最近时间**，按最近时间倒序展示。

| 操作 | 说明 |
| --- | --- |
| **一键加入** | 直接按收藏中的 IP / 房间信息尝试加入对方 |
| **删除** | 移除收藏 |
| **刷新** | 刷新列表 |

> 与好友联机后会自动记录，下次开黑可从收藏直接一键加入，无需再要分享文本。

## 4. 公开房间

大厅里所有公开的房间列表（房主 / 房间名 / 延迟）。

- **一键加入公开房间**：直接加入选中的公开房间。
- **刷新**：刷新房间列表。

> 如何公开自己的房间：见 [建房与加入 → 公开我的房间](/multiplayer/hosting#_4-公开我的房间-拉路人)。

## 5. 大厅聊天

大厅聊天通过公共 MQTT 服务中转，所有大厅在线玩家共享。聊天内容经内置共享密钥做传输混淆，但**内容仍应视为公开**。

- 房间聊天（仅房间成员可见）见 [建房与加入 → 房间聊天与踢人](/multiplayer/hosting#_6-房间聊天与踢人)。
