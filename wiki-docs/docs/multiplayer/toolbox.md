工具箱页提供网络诊断与维护工具。在 **工具箱** 页点击对应卡片进入。

---

## 1. 连通性检测

汇总诊断，一键定位网络问题：

- **PING 测试**：检测基本连通性。
- **TCP / UDP 测速**：检测到节点/队友的带宽与时延。
- **NAT 检测**：判断你的 NAT 类型（FullCone / RestrictedCone 等），影响 P2P 打洞成功率。

> 用于判断「为什么连不上」：先 PING 节点，再看 NAT 类型，配合防火墙排查。

## 2. 防火墙

- **一键关闭**：临时关闭 Windows 防火墙（**需管理员权限**）。
- **一键恢复**：重新开启防火墙。

> 防火墙拦截是「双方互 ping 不通」的常见原因，关闭后往往立刻解决。联机结束后建议恢复防火墙。

## 3. 网卡优先级

连接后运行，让**游戏广播优先走虚拟网卡**。

- 适用场景：游戏局域网自动发现不到房间时使用。
- 原理：调整虚拟网卡的接口跃点（metric），使广播流量优先经虚拟网卡转发。

## 5. 更多设置

| 设置项 | 说明 |
| --- | --- |
| **自定义节点** | 添加/管理自定义节点（EasyTier / n2n / supernode 等），公共节点不通时使用 |
| **进程守护** | 守护引擎进程，异常退出自动重启（默认开启） |
| **开机自启** | 随系统开机自动运行（注册表项） |

## 网络设置页细节

| 控件 | 说明 |
| --- | --- |
| 组网方案 | EasyTier / n2n / ZeroTier / Anywherelan，见 [四方案详解](/multiplayer/engines) |
| 节点服务器 | 下拉选择节点，可「节点测速」或添加自定义节点 |
| 房间名称 | 小组名，大厅展示此名，可随机生成 |
| 加密密钥 | 可选，留空不加密；成员需一致 |
| 虚拟 IP 模式 | 自动 / 手动（手动需填 IP，n2n 场景队友应填不同 IP） |
| 公开我的房间 | 需先连接房间并进入大厅，勾选后大厅可见 |
| 连接 / 断开 | 主按钮 |

## 配置与日志

- 配置文件：程序目录下 `hmol-LJ-DLC_config.json`（崩溃/退出不丢失）。
- 运行日志：**运行日志** 页可查看、刷新、清空、导出，排障时导出给开发者。
- 侧边栏实时显示：管理员状态、连接状态、虚拟 IP、在线对端数、引擎信息、**心灵终结 CNC 大厅延迟代码**、当前配置。

> 注意：修改配置文件请先退出程序，否则改动可能被程序覆盖。
