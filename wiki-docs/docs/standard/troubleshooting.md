## 日志查看方法

### 日志位置

```
启动器目录/
└── logs/
    ├── HMOL_2026-07-20.log
    ├── HMOL_2026-07-21.log
    └── HMOL_2026-07-22.log  ← 最新
```

### 日志格式

```
2026-07-22 18:30:45 | INFO  | Install    | 解压完成,共 128 个文件
2026-07-22 18:30:46 | WARN  | Install    | 跳过 Maps/old.map: 权限不足
2026-07-22 18:30:47 | ERROR | Backup     | 备份失败: PermissionError
```

### 查找关键错误

```powershell
# PowerShell: 查找今天的 ERROR
Select-String -Path "logs\HMOL_$(Get-Date -Format 'yyyy-MM-dd').log" -Pattern "ERROR|CRITICAL|Traceback"

# 仅查看最近 50 行
Get-Content "logs\HMOL_$(Get-Date -Format 'yyyy-MM-dd').log" -Tail 50
```

## 启动类错误

### ❌ 启动时无任何反应

**症状**: 双击 `HMOL.exe` 无反应

**排查**:

1. **检查 VC++ 运行库**
   ```powershell
   # 查看是否安装
   Get-ChildItem "C:\Windows\System32\msvcp140.dll"
   ```
   若不存在,下载安装 [VC++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)
2. **检查系统版本**
   - 必须是 Windows 10 1809+ 或 Windows 11
   - 不支持 Windows 7/8.1
3. **尝试以管理员身份运行**
   - 右键 `HMOL.exe` →「以管理员身份运行」
4. **从命令行启动查看输出**
   ```powershell
   cd "D:\HMOL"
   .\HMOL.exe
   ```
   控制台会显示错误信息

***

### ❌ `ImportError: DLL load failed while importing QtCore`

**原因**: VC++ 运行库缺失或损坏

**解决**: 重新安装 [VC++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe)

## 实例管理错误

| 错误提示              | 原因      | 解决方案                              |
| ----------------- | ------- | --------------------------------- |
| 实例名称和路径不能为空       | 表单未填写   | 填写完整                              |
| 实例名称已存在           | 名称重复    | 更换名称                              |
| 指定路径不是有效的心灵终结游戏目录 | 路径错误    | 选择含 `Mental_Omega_client.exe` 的目录 |
| 该游戏路径已被其他实例使用     | 路径冲突    | 更换路径或删除旧实例                        |
| 实例不存在             | 实例被外部删除 | 刷新列表或新建                           |
| 游戏路径不存在: `<path>` | 实例路径失效  | 在【实例管理】中更新路径                      |
| 无法创建实例目录 `<path>` | 权限/磁盘错误 | 检查权限,更换 base\_path                |
| 切换实例失败: `<e>`     | 未捕获异常   | 查看日志,反馈 bug                       |

## 插件包安装错误

<br />

***

### ❌ 压缩包已损坏或格式错误

**原因**: 压缩包下载未完成 / 加密 / 格式异常

**解决**:

1. 重新下载并校验 SHA-256
2. 用 7-Zip/WinRAR 单独打开测试
3. 联系插件包作者获取未压缩版本

***

### ❌ 安装失败:所有 N 个文件均无法复制

**原因**: 全部文件复制失败(权限/磁盘/路径)

**解决**:

1. **关闭游戏/杀毒**: Mental\_Omega\_client.exe、Steam、杀毒软件
2. **以管理员身份运行**: 右键启动器 →「以管理员身份运行」
3. **检查磁盘空间**: `Get-PSDrive C | Select-Object Used,Free`
4. **检查路径长度**: Windows 路径限制 260 字符

***

### ❌ 安装后目标目录为空

**原因**: 复制失败但未抛出异常(罕见)

**解决**:

1. 查看 `logs/HMOL_<日期>.log`
2. 手动复制解压后的文件到游戏目录
3. 重新下载插件包

***

## 插件包卸载错误

### ❌ 未找到该包的精确安装记录,执行全量恢复

**说明**: 触发「全量恢复」流程。**不可撤销**!

**适用场景**:

- 旧版本安装,无安装记录
- 跨版本升级后记录失效
- 安装记录被外部删除

**操作前请确认**:

- ✅ MO 原版备份存在
- ✅ 重要存档已备份
- ✅ 已关闭游戏

***

### ❌ 卸载失败: `<e>`

**排查**:

1. 关闭游戏(EAC/Steam)
2. 以管理员身份运行
3. 查看日志获取详细异常

***

## 备份与恢复错误

### ❌ 备份名称为系统保留名称

**禁止使用**:

- `CON`、`PRN`、`AUX`、`NUL`
- `COM1` \~ `COM9`
- `LPT1` \~ `LPT9`

**解决**: 更换备份名称。

***

### ❌ 备份名称包含非法字符

**禁止字符**: `< > : " / \ | ? *` 和控制字符

**解决**: 使用中文/英文/数字/下划线。

***

### ❌ 备份过程发生异常

**排查**:

```powershell
# 1. 检查磁盘空间
Get-PSDrive

# 2. 检查目标目录权限
icacls "backups"

# 3. 查看日志
Get-Content "logs\HMOL_$(Get-Date -Format 'yyyy-MM-dd').log" -Tail 100
```

## OneDrive 联机错误

### ❌ MSAL 初始化失败 (无网络?)

**排查**:

1. **测试网络可达**:
   ```powershell
   Test-NetConnection login.microsoftonline.com -Port 443
   ```
2. **检查代理设置**: 启动器会读取系统代理
3. **暂时禁用杀毒**: 某些杀软会拦截 MSAL

***

### ❌ 请求超时,请检查网络

**解决**:

1. 切换网络(WiFi ↔ 有线)
2. 关闭 VPN/代理
3. 重试 3-5 次

***

### ❌ 无法连接到微软服务器

**排查**:

```powershell
# 1. DNS 解析
Resolve-DnsName graph.microsoft.com

# 2. 网络连通性
Test-NetConnection graph.microsoft.com -Port 443

# 3. 代理设置
netsh winhttp show proxy
```

***

### ❌ Token cache save failed

**排查**:

1. 检查启动器目录权限
2. 确认 `cryptography` 库已安装:
   ```powershell
   pip show cryptography
   ```

***

## 下载错误

### ❌ 下载速度很慢

**排查**:

1. HMOL 内置 16 连接多线程分片下载与 `download.aspx` 高速通道,若仍慢:
2. 检查代理/VPN 是否拦截 SharePoint(`*.sharepoint.com`)
3. 切换网络(WiFi ↔ 有线)
4. 资源有多个网盘镜像时,用「在浏览器中查看」选择其他线路(123云盘 / 百度网盘 / 移动云盘)

***

### ❌ 下载中断 / 断点续传

**说明**: 下载取消/失败/退出后,`.part` 与 `.meta` 文件保留在下载目录。

**续传**: 再次点击下载同一文件,弹窗询问是否从断点继续(显示已下载百分比),选择「继续」即可。

> 若提示"该文件正在下载",说明该文件已有进行中的任务,等其完成或先取消。

***

### ❌ 下载失败

**排查**:

1. 弹窗询问是否重试时,选择「重试」会自动续传(保持原前台/后台方式)
2. 检查网络连通性:
   ```powershell
   Test-NetConnection sharepoint.com -Port 443
   ```
3. 查看日志:
   ```powershell
   Get-Content "logs\HMOL_$(Get-Date -Format 'yyyy-MM-dd').log" -Tail 50
   ```

***

### ❌ 提示磁盘空间不足

**说明**: 下载前启动器自动检查目标盘剩余空间。

**解决**: 核对下载确认窗中的保存位置与文件大小,清理磁盘空间后重新下载。

***

### ❌ 后台下载悬浮窗不显示

**排查**:

1. 确认点击的是确认窗中的「⬇️ 后台下载」按钮(前台模式是模态进度窗)
2. 检查任务栏/屏幕右下角,悬浮窗为无边框置顶窗口,可能被其他窗口遮挡
3. 悬浮窗有独立关闭按钮;关闭启动器会自动停止下载
4. 若仍异常,查看日志确认是否进入后台模式

***

## QQ 喊话错误

### ❌ 消息中不能包含网址

**触发**: 检测到 URL(http/https/[www./baidu.com](http://www./baidu.com) 等及混淆形式)

**解决**: 移除消息中所有 URL。

***

### ❌ 消息中包含不文明词汇

**解决**: 修改用词,避免敏感词。

***

### ❌ 操作过于频繁, 请等待 N 秒

**原因**: 触发速率限制(5 次/分钟)

**解决**: 等待 N 秒后重试。

***

### ❌ 消息超过 500 字限制

**解决**: 精简消息。

***

### ❌ QQ Bot Token 获取失败

**排查**:

1. 检查网络可达 `api.sgroup.qq.com`
2. 等待几分钟后重试(临时封禁)
3. 若持续失败,可能是机器人被封禁

***

### ❌ 频道:err(401) / 群:err(401)

**原因**: 机器人 Token 失效或未授权

**解决**:

1. 重新登录微软账号
2. 联系管理员确认机器人授权状态

***

## DLC 启动错误

### ❌ 主程序文件不存在

**原因**: `DLC/DLC.json` 中 `main` 字段指向的文件不存在

**解决**:

1. 检查 DLC 文件夹结构
2. 修改 `DLC.json` 中 `main` 字段

***

### ❌ 主程序文件没有执行权限

**解决** (Windows):

1. 右键文件 →「属性」
2. 取消「只读」勾选
3. 应用 → 确定

***

### ❌ 权限错误 - 无法启动 DLC 程序

**解决**: 以管理员身份运行启动器。

***

## 更新错误

### ❌ 检查更新失败 / 无法连接更新服务器

**排查**:

1. 检查网络可达 GitHub:
   ```powershell
   Test-NetConnection github.com -Port 443
   ```
2. 国内网络可切换更新线路:更新弹窗中选择「下载线路」切换 GitHub 镜像后重新检查
3. 更新检查默认在启动 3 秒后静默进行(24 小时节流),也可在「设置」或「关于」页手动「🔄 检查更新」

***

### ❌ 更新下载失败

**排查**:

1. 在更新弹窗中重试下载(支持断点续传)
2. 确认磁盘剩余空间充足
3. 查看 `logs/HMOL_<日期>.log` 中的 updater 相关记录

***

### ❌ 更新后启动器无法启动

**排查**:

1. 更新通过 `.bat` 脚本替换 exe 后自动重启;若失败:
2. 从 [GitHub Releases](https://github.com/OrangeArtc0915/Hello-Mental-Omega-Launcher/releases) 手动下载最新版 zip 解压
3. 将旧目录的 `instances/`、`backups/`、`HMOL_config.json` 复制到新目录保留数据
4. 查看日志确认更新中断原因,反馈到 GitHub Issues

***

## 性能问题

### ❌ 启动器启动很慢

**排查**:

| 原因          | 排查方法        |
| ----------- | ----------- |
| 首次解压依赖      | 首次启动较慢,后续会快 |
| OneDrive 资源 | 关闭【联机】页减少扫描 |
| 大量插件包       | 几百个本地包会拖慢   |
| 杀毒扫描        | 将启动器加入白名单   |

***

### ❌ 备份时启动器卡住/无响应

**说明**: HMOL 2.6 已修复该问题。仍出现则:

1. 确认是 v3.x
2. 查看 `logs/HMOL_<日期>.log` 中是否有 `_bg_progress` 信号记录
3. 若完全没有,可能是杀毒软件拦截

***

### ❌ 启动器内存占用过高

**解决**:

1. 关闭未使用的实例
2. 关闭 OneDrive 资源列表
3. 关闭自定义背景
4. 重启启动器(Qt 6 长期运行可能内存增长)
