## 2. 下载 HMOL

> ⚠️ **请仅从官方渠道下载,任何其他渠道提供的二进制均可能已被修改,可能包含恶意代码。**

### 2.1 官方下载渠道

| 渠道              | 链接                                                                       |
| --------------- | ------------------------------------------------------------------------ |
| GitHub Releases | <https://github.com/OrangeArtc0915/Hello-Mental-Omega-Launcher/releases> |

### 2.2 验证下载完整性

每个 Release 都附带 SHA-256 校验和:

```powershell
# Windows PowerShell
Get-FileHash .\HMOL_v3.2.0_release_20260821.zip -Algorithm SHA256
```

将输出与 GitHub Release 页面公布的哈希值对比,**必须完全一致**才可使用。

## 3 注意事项

- **强烈建议解压到非系统盘**(如 `D:\HMOL\`);若放在 `C:\Program Files\`,写操作受 UAC 限制,需以管理员身份运行
- 所有数据都保存在启动器目录内,**复制整个目录即可备份/迁移**
- 不要直接覆盖式解压新版本到正在使用的目录,请使用新目录(见[升级](#5-升级与降级))

## 4. 首次启动

### 4.1 EULA 协议

首次启动会弹出 **最终用户许可协议** 对话框,包含 14 个章节,核心条款:

- ⛔ **§3 二次修改禁令** — 严禁任何形式的二次修改
- ✅ §4 仅限个人非商业使用
- ⚠️ §7 按"现状"提供,无担保
- 🚫 §9 禁止违法、作弊、刷屏、商业滥用

请仔细阅读后:

- 点击「✅ 同意」继续(可使用全部功能)
- 点击「❌ 不同意,退出」将**立即清理所有临时数据**后退出

### 4.2 实例创建向导

同意 EULA 后,启动器会引导您创建第一个游戏实例:

1. 点击「🎮 实例管理」→「新建实例」
2. 填写 **实例名称**(例:`MO_主版本`、`MO_测试版`)
3. 点击「浏览」选择 **心灵终结安装根目录**
   - 必须包含 `Mental_Omega_client.exe`
   - 必须包含 `Maps/`、`Resources/` 等标准 MO 目录
4. 点击「创建」后。点击 \[备份原版文件].

### 4.3 主题与背景

- **设置 → 主题**: 6 套渐变主题(蓝紫渐变(默认)、蓝青渐变、橘红渐变、森林绿渐变、玫瑰粉渐变、暮光紫渐变)+ 3 套雾感弥散光色板,支持浅色/深色/跟随系统
- **设置 → 背景**: 支持自定义 JPG/PNG/GIF/WEBP 图片、MP4/WebM 视频,以及 **Wallpaper 壁纸包(.mpkg)** 自动解包
- **设置 → 字体**: 跟随系统或自定义

## 5. 升级与降级

### 5.1 在线更新(推荐)

- 启动 3 秒后静默检查更新(24 小时节流),或在「ℹ️ 关于」→「🔄 检查更新」手动检查
- 更新弹窗中可选择下载线路,下载完成后自动生成 `.bat` 替换 exe 并重启
- 详细流程见 [使用说明 → 在线更新](/standard/user-guide#_11-在线更新)

### 5.2 手动升级

1. 备份当前数据:复制启动器目录下的 `instances/`、`backups/`、`HMOL_config.json`、`DLC/`
2. 下载新版本 zip 解压到**新目录**(不要直接覆盖旧目录)
3. 将备份的数据复制到新目录对应位置
4. 双击 `HMOL.exe` 启动新版本,验证功能正常后删除旧目录

### 5.3 降级到旧版本

仅在当前版本存在严重 Bug 时降级:

1. 从 GitHub Releases 下载旧版本 ZIP
2. 按[手动升级](#52-手动升级)流程执行

**注意**: 降级后已加密的令牌缓存可能无法读取(密钥与机器指纹相关),需重新登录微软账号。
