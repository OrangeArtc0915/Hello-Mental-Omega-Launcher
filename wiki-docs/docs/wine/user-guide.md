## 📌 首页（Home） / Home Page

启动器默认进入首页，显示：

- **品牌封面**：蓝紫渐变背景（可自定义本地图片，首页"选择背景图"按钮）
- **当前实例选择器**：下拉框切换实例
- **启动方式下拉框**：「vbs 脚本」或「MentalOmegaClient.exe」直接启动
- **🚀 启动游戏按钮**：一键启动当前实例

### 启动方式

| 方式 | 说明 |
| --- | --- |
| **vbs 脚本**（默认） | 通过 `wscript.exe` 执行 VBS 启动脚本，兼容性最好；缺失时自动回退 exe |
| **exe 直接启动** | 直接运行 `Mental_Omega_client.exe` / `MentalOmegaClient.exe`，可附加启动参数 |

### 切换主页背景

1. 首页点击 **"选择背景图"**
2. 选择本地 PNG/JPG 图片
3. 立即生效；点击"重置"恢复默认蓝紫渐变

### 返回首页

任何页面下点击左侧"主页"按钮即可。

## 📂 实例管理 / Instance Management

> 实例 = 一个游戏安装目录 + 独立的配置/插件/备份。

### 添加实例

1. 左侧"实例管理" → 点击 **"添加实例"**
2. 填写**实例名称**（1-64 字符，不与现有实例重名）
3. 点击 **"浏览"** 选择游戏根目录
4. 系统自动验证：必须包含 `Mental_Omega_client.exe`
5. 点击 **"确定"** 完成

> 💡 **提示**：一个游戏目录只能绑定到一个实例。如需多版本共存，请将游戏安装到不同目录。

### 切换实例

在实例列表中**单击**目标实例，状态栏立即更新。

### 重命名实例

1. 选中实例 → 点击 **"重命名"**
2. 输入新名称（避免 `< > : " / \ | ? *` 等特殊字符）
3. 确定

### 删除实例

1. 选中实例 → 点击 **"删除"**
2. 二次确认对话框出现
3. 选择「仅删除配置（保留游戏文件）」或「同时删除游戏文件」
4. 确认删除

> ⚠️ **删除游戏文件不可恢复**！建议先备份再删除。

### 导出实例

将整个实例打包为压缩包（用于备份或迁移）：

1. 选中实例 → 点击 **"导出"**
2. 选择格式：**ZIP / 7Z**（需要 `py7zr`）/ **RAR**（需要 WinRAR）
3. 选择保存位置
4. 等待进度条完成

> 详见 [Features › 实例导出

### 导入实例

从 `.zip` / `.7z` 压缩包导入实例：

1. 点击 **"导入"**
2. 选择压缩包文件
3. 程序自动解压、验证、注册到实例列表

## 📦 包管理 / Package Management

> 插件包 = 第三方资源（任务包、地图、模组）的标准压缩包。

### 安装插件包

1. 左侧"包" → 确认已选择目标实例
2. **方式 A**：从 `导入包`点击"刷新"
3. **方式 B**：从 OneDrive（笨蛋广场）下载
4. 选中包 → 点击 **"安装选中"**
5. 若有文件冲突，弹出确认对话框（覆盖/取消）
6. 等待进度条完成

### 卸载插件包

1. 切换到"已安装"标签
2. 选中要卸载的包 → 点击 **"卸载选中"**
3. 程序按 `install_record.json` 精确删除
4. 二次确认

### 导入本地包

将外部 `.zip` / `.7z` / `.rar` 文件导入到 `packages/` 目录：

1. 点击 **"导入包"**
2. 选择文件
3. 复制到 `packages/` 目录并加入列表

### 查看安装记录

- 启动器使用 `instances/<id>/install_record.json` 精确记录每个包安装的每个文件
- 卸载时**只删除**记录中的文件，不会误删其他包的内容

## 💾 备份与还原 / Backup & Restore

> 入口：**实例管理**页面底部按钮区（💾 备份 / 📀 备份原版 / 📂 还原 / 📁 打开目录）。

### 创建备份

1. 左侧"MO 设置" → "实例管理" → 选中实例
2. 点击 **"💾 备份"**
3. 输入备份名称（1-100 字符，避免保留名 `CON/PRN/AUX/NUL`）
4. 等待进度条完成
5. 备份保存到 `backups/<实例ID>/<备份名>/`

### 备份原版游戏

- 点击 **"📀 备份原版"**：将纯净版游戏文件备份为"原版备份"（唯一，重复备份会覆盖确认）
- 用于测试插件包前保留干净环境，随时可一键还原

### 还原备份

1. 左侧"MO 设置" → "实例管理" → 选中实例
2. 点击 **"📂 还原"**，在备份列表中选择目标备份
3. ⚠️ **全量覆盖确认**：会覆盖当前游戏目录所有内容
4. 确认后等待进度条完成

> 💡 **建议**：每次安装大型插件包前先备份原版。

### 删除备份

1. 在还原对话框的备份列表中选择 → 点击 **"删除"**
2. 二次确认

## ☁️ 笨蛋广场（OneDrive 共享） / SharePoint

> HMOL 内置 OneDrive 资源浏览，原名 "OneDrive"，重命名为「笨蛋广场」。侧边栏分组下共 **3 个入口**：
>
> | 入口 | 内容 |
> | --- | --- |
> | 🎮 **游戏资源** | 游戏资源包（任务包 / 地图 / 语音 / 音乐等） |
> | ⚙️ **运行环境** | 运行库 / 环境组件 |
> | 🧩 **程序DLC** | 启动器附加组件 |

### 登录微软账号

启动程序时会弹出登录窗口，支持 **设备代码流**：

1. 点击 **"登录"**，浏览器自动打开 `https://microsoft.com/devicelogin`
2. 输入屏幕上的 8 位设备码，完成授权
3. 关闭浏览器，程序自动继续

> 也可选择 **"跳过登录"** 进入离线模式：主页可正常使用，但笨蛋广场与账号页面不可用。

### 浏览共享资源

1. 左侧"笨蛋广场" → 选择入口 → 等待列表加载
2. 顶部**搜索框**可快速过滤当前目录文件
3. 文件夹标 `[文件夹]`，**双击进入**（可递归）
4. 文件标 `[文件]`，**双击 = 下载**
5. **"🌐 用浏览器打开"**：可选择直接线路（OneDrive）或镜像线路（123云盘 / 百度网盘 / 移动云盘）在浏览器中打开

### 下载资源

1. 选中文件 → 点击 **「⬇️ 下载选中」**（默认前台下载，进度在页面内实时显示）
2. 想边下载边干别的？点击 **「🌐 后台下载」**，右下角弹出下载中心悬浮窗，可切换到其他页面继续操作
3. 下载完成后自动弹窗提示结果，文件保存到 `packages/` 目录
4. 程序自动刷新"包管理"页面，可安装到游戏目录

> - 支持多文件并行 + 多线程分片下载、断点续传与自动重试；下载速度较旧版提升约 3 倍
> - **磁盘空间预检查**：下载前对比期望大小与磁盘剩余空间，空间不足会提前提醒
> - **高速模式**：设置 → 下载设置，开启后可进一步提高并发与分片数（默认关闭）

### 退出登录

左侧"账号" → **"退出登录"** → 确认 → 令牌从本地清除（加密文件被覆盖）

## 🧩 DLC 启动器 / DLC Launcher

> 启动第三方附加组件（如原版红警 2、对战平台等）。入口：侧边栏"🧩 本地DLC"。

### 安装 DLC

将 DLC 文件夹放入 `DLC/` 目录（必须包含 `DLC.json`），启动器自动扫描识别；放入的压缩包会在启动时自动解压。

`DLC.json` 示例：

```json
{
  "name": "示例 DLC",
  "version": "1.0",
  "main_path": "Game.exe",
  "description": "示例说明"
}
```

### 启动 DLC

1. 左侧"本地DLC" → 左侧列表选中目标 DLC（显示状态：正常 / 缺配置 / 解析失败）
2. 右侧卡片点击 **"启动"**
3. 主程序文件执行，并自动附加启动参数：
   - `--hmol-root`：启动器根目录
   - `--hmol-instance`：当前实例路径
   - `--hmol-gamertag`：当前 Xbox 玩家代号

### 打开 DLC 目录

右侧卡片点击 **"打开目录"** 在资源管理器中查看。

### 查看 DLC.json 规范

点击 **"查看规范"** 查看完整字段说明。

## 👤 账号管理 / Account

### 微软账号

- **登录**：触发设备代码流（见[笨蛋广场](#笨蛋广场onedrive-共享--sharepoint)登录说明）
- **查看信息**：显示用户名、微软账号 ID、头像
- **Xbox 玩家代号**：登录后自动同步，可手动修改
- **Xbox 好友**：右侧卡片显示好友在线状态
- **退出登录**：清除本地加密令牌

### 离线模式

- 启动时选择 **"跳过登录"** 即进入离线模式
- 离线模式下：主页、实例、包管理、备份、DLC、设置均可用；**笨蛋广场与账号页面禁用**

## ⚙️ 设置 / Settings

设置页共 **6 张卡片**：

### 1. 反馈与建议

- QQ 1群 `1034243331`（复制群号 / 一键加群）
- QQ 2群 `1092671790`
- GitHub 仓库（Issues / Security Advisories）

### 2. 自定义 UI 布局

- **"🧭 编辑侧边栏"**：进入侧边栏编辑模式（拖拽重排 / 隐藏 / 重命名）
- **"📤 导出布局"**：保存为 YAML 文件
- **"📥 导入布局"**：从 YAML 恢复

### 3. 下载设置

- **"启用高速模式"**（默认关闭）：开启后提高单文件分片数（8→16）与并行文件数上限（5→8，含大文件 3→6），下载更快但更耗带宽与 CPU

### 4. 性能监控

- **"启用性能监控"**（默认开启）：记录启动耗时、页面构建、内存采样等
- **"📊 生成性能报告"**：输出 PERF 级别日志，便于排查卡顿

### 5. 关于 HMOL

- 名称 / 版本（v3.2.0）/ 作者
- 功能特性列表
- **法律与协议**：EULA 状态显示；"立即接受 / 重新接受"（接受）、"仅查看 / 重新查看"（查看全文）；EULA 版本随启动器版本更新，升级后需重新接受
- **"🔄 检查更新"**：手动检查新版本

### 6. 程序日志

- 日志级别筛选：全部 / INFO / WARN / ERROR / DEBUG / PERF
- 关键字搜索
- **"📤 导出 TXT"** / **"📊 导出 CSV"**
- **"🗑️ 清理旧日志"**：删除 30 天前的日志

> **自动更新**：程序启动约 3 秒后自动静默检查更新（每 24 小时最多一次），有新版本时弹出提示；也可在"关于"卡片手动检查。

## 🎨 主题 / Themes

Wine 版内置 **浅色 / 深色双主题**，自动跟随 Windows 系统深色/浅色模式。

| 模式 | 说明 |

## 🖱️ 侧边栏编辑（高级） / Sidebar Editor

> HMOL 内置拖拽式侧边栏编辑（v2.4 起开放给用户）。

### 进入编辑模式

左侧"设置" → "自定义 UI 布局" → **"🧭 编辑侧边栏"**

### 拖拽重排

- 按住**任一按钮**拖动到新位置
- 6 px 移动阈值后视为拖拽
- 释放后自动吸附

### 重命名

- 右键 → "重命名" → 输入新名称

### 隐藏/显示

- 右键 → "隐藏"
- 在"已隐藏"区域可恢复

### 调整宽度

- 拖动侧边栏右边缘的 **`<img>`** **双箭头光标** 调整宽度
- 几何以**分数**存储，自动适配窗口大小

### 保存/取消

- "保存"：写入 `sidebar_layout.yaml`
- "取消"：回滚本次会话所有修改

### 导入/导出方案

- "导出"：保存为 `.yaml` 文件
- "导入"：从 `.yaml` 恢复布局

> 提示：布局编辑器功能详见「布局」章节。
