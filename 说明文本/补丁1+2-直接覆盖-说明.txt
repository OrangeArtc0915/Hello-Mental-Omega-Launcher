一、怎么用（不需要运行任何脚本）
  1. 完全关掉 MO 客户端和游戏（任务管理器里确认 clientdx.exe 已经没了）
  2. 建议先把下面几个原文件复制到别处备份：
        Resources\clientdx.exe
        Resources\clientogl.exe
        Resources\clientxna.exe
        Resources\Binaries\Windows\MonoGame.Framework.dll
        Resources\Binaries\Windows\Rampastring.XNAUI.dll
  3. 把本压缩包里的 Resources 文件夹整个复制到游戏根目录
     （就是有 MentalOmegaClient.exe 的那一层），提示「是否替换」时选「是」
  4. 启动客户端。主菜单右下角出现
        Patch v0.16.2  |  HMOL v1.5.16
     就说明补丁生效了

二、包里是什么
  Resources\clientdx.exe / clientogl.exe / clientxna.exe
      联机补丁：局域网直连、游戏内中继、踢人、聊天 @ 高亮 + 提示音、
                开赛前 3 秒检查、隐藏 CnCNet 线上入口、主菜单右下角版本号
  Resources\Binaries\Windows\MonoGame.Framework.dll
      中文输入补丁（只对应 clientdx.exe 用的 Windows 渲染器；
      OpenGL / XNA 渲染器的 MonoGame 不是同一套构建，本补丁不适用）
  Resources\Binaries\Windows\Rampastring.XNAUI.dll
      聊天框输入法修正：组词过程中按回车选词，不再同时触发「发送聊天」；
      按 Esc 取消组词，也不会再把已经打好的字整行清空（见第六节）
  Resources\MoLanRelay.dll
  Resources\Binaries\MoLanRelay.dll
      游戏内 UDP 中继（两个位置都放，客户端会从 Resources\ 加载）。
      房主判定以大厅自己的房主状态为准，连接状态兜底；客机不会再被误判成房主去转发。

  「下载音乐包」按钮已删除。
  · 「联机补丁」页有 19 个开关：@ 提示音、Tab 名字补全、掉线提示、
    进房间报版本、开赛前 3 秒检查、显示状态条，状态条里的 FPS / Ping /

  顶部状态栏上**不再有**日志/导出按钮。

四、地图同步
  按钮在**底部按钮行**（房主和客机布局不同，各放在自己的空档里，
  不压在聊天框 / 地图列表 / 预览图上）：
    · 房主：在「锁定房间」左边
    · 客机：在「开始游戏」右边
  外观和旁边那个原版按钮一致：
    · 房主看到的是「同步地图」，传输中变成「取消同步」
    · 客机看到的是「接收地图」，接收中变成「接收中…」并置灰
  1. 房主先在地图列表里选好这一局要打的地图；
  2. 房主点「同步地图」——只把**这一张图**需要的文件清单发给房间里的人
     （客机也可以点自己的「接收地图」主动要：只给房主发一条请求，
       房主收到后按他自己选中的那张图发清单，效果与房主主动点一样）：
        · 地图文件本身（.map / .mpr / .yrm）
        · 同目录同名的 .ini、预览图等附加文件
     所以地图不一定在 Maps\Custom 也能对上：文件按「相对游戏根目录」的路径发送，
     房主那边在哪、客机就写到同一个位置。
  3. 客机本地已经和房主一致（大小 + SHA-256 都相同）→ 什么都不做，聊天区提示一句；
     确实缺文件 → 弹窗显示地图名、文件数、总大小，点「是」才开始接收。
  4. 接收完成后逐个校验 SHA-256，写入前先写 .mosync-part 临时文件，校验通过才替换。
  5. 传完后**地图列表会自动刷新**，不用重启客户端。
     同步时会把房主 `INI\MentalOmegaMaps.ini` 里这张图的注册段一起带过来
     （MapsMO\ 下的官方图靠这段登记，只传 .map/.png 是不会出现在列表里的）。
     万一列表没刷新（比如游戏正卡在别的界面），重启客户端也能看到。
  注意：
   · **省流量**（樱花 Frp 按流量算，这几项都是为它做的）：
       - 只传客机缺的文件（大小 + SHA-256 比对），已有的直接跳过
       - 传之前先 deflate 压缩，地图文件常见能压到一半以下
       - 编码用 Ascii85 而不是 Base64：每 4 字节占 5 个字符（+25%），
         Base64 是 3 字节占 4 个字符（+33%），同样的数据少传 6% 左右
       - **默认不传预览图**（同名的 .png 等，动辄几百 KB~3 MB，只是列表缩略图）。
         想要预览图：在 Resources\MoLanPatch.ini 里加一行 `SyncPreview=1`
   · **断点续传**：没收完的部分存在 `Resources\MoMapPart\`，断线/取消后
     再点一次「接收地图」，只补剩下的字节，已收到的不会重传。
   · **地图版本核对**：房主每次换图都会广播这张图的 SHA-256；
     开局前客机会拿本地算的比对，不一致就拦下并提示「版本不一致」，
     不会再出现"两边都有图但读条直接崩"。
   · **多图批量同步**：房主点「同步地图」会弹出一个选择框——
        「推送当前地图」= 只发当前选中的那张（原来的行为）
        列表里选一行点「加入选中」，可以攒多张，再点「推送已选」一次全发
        （也可以在聊天框敲 `/maps` 看序号、`/push 1,3,5` 直接推）
   · 传输会自动压缩（deflate）、每帧 32 KB、并且去掉了人为限速：
     实测 4.4 MB 的图压到 219 KB，所以 2 MB 左右的图**几秒**就传完（以前要半分钟以上）。
     客户端读连接的缓冲也从 1 KB 提到了 64 KB（在 exe 里），
     所以这一项要**整个包一起换**，只换 dll 不换 exe 提速不明显。
     地图文件本身不会变小，压缩只在传输过程中，客机收完解开再校验 SHA-256。
   · 传输期间房主别关客户端。状态条会显示「地图同步 发送 45%」这样的进度。
     弹窗里显示的仍是地图真实大小，后面括号里才是压缩后的传输量。
   · **传的过程中再点一次按钮就是「取消同步」**（按钮文字会自己变）。
   · 客机没有这张图时点开始游戏会被拦住，同时房主聊天区会提示
     「XXX 没有当前这张地图，已阻止开局。请点「同步地图」把图发过去」。
   · 客户端原来那句「房主需要更换地图」的提示，已改成「房主需要同步地图」。
   · 只发地图相关文件，不动 MO 本体；同名文件只有在内容不同时才会被覆盖。

五、聊天框打中文（本轮修复）
  以前用微软拼音在聊天框打字，候选条正常，但按回车选词后整行字会消失：
  回车被聊天框当成「发送」、Esc 被当成「清空」，而这两个键本来该由输入法吃掉。
  现在组词过程中（候选条还开着）回车/Esc 只作用于输入法，不会再清空输入框；
  组词结束后再按回车才是发送。

六、本版新增的几个小功能
  1. `/diag` 诊断包
     在大厅聊天框里输入 `/diag` 回车（不会发出去），会把
     MoLanRelay.log、client.log、最近的崩溃日志、spawn.ini、MoLanPatch.ini
     以及关键文件的版本哈希打成一个 zip，放到**桌面**：
         MO诊断-20261115-2003.zip
     出问题时直接把这个 zip 发出来就行，不用再问「要哪些日志」。
  2. 进不去房间会给原因
     以前房主锁房/满员时，客机表现为「刚进去就自动退」，什么提示都没有。
     现在会弹一个框写明「房主锁了房间」或「房间人数已满」。
  3. 客机进房自动准备
     客机会自动勾上「自动准备」，不用每局手动点。
     但**本地还没有可用地图时不会勾**（房主没选图、或选了本地没有的图）——
     那种情况勾了也开不了局。等房主选好图、本机也有了这张图，会自动勾上。
     不想要的话，在 Resources\MoLanPatch.ini 里加一行 `AutoReady=0`。
  4. 同名提醒
     房间里出现两个同名玩家时，聊天区会提示一次「@ 和踢人会认错人」。
  5. `/sync` 也可以同步地图
     效果和点「同步地图」按钮一样，房主在聊天框敲 `/sync` 即可。
  6. 局域网端口可以改（默认仍是 1233）
     以前房主监听端口写死 1233，1233 被占用或隧道只能映射到别的端口时就开不了房。
     现在房主监听、房主自连、客机双击加入三处都读同一个值：
        · 优先 Resources\HMOL.session.txt 里的 `LANPORT=端口`（HMOL 启动器写）
        · 其次 Resources\MoLanPatch.ini 里的 `LANPort=端口`（手改也行）
        · 都没有 → 1233
     有效范围 1~65535，填错会自动回退 1233（MoLanRelay.log 里会写实际用的是哪个）。
     注意：**双方要一致**。房主改 1234，客机也用局域网列表双击时也得是 1234；
     不一致就走底部的地址输入框直连（那里填的端口优先）。
  7. 删除已同步的地图（设置窗口 →「地图」页）
     这一页列出本机**通过地图同步接收来的**文件（一行一个文件，两列：文件名 / 位置）。
        · 「删除选中」→ 删掉列表里选中的那一个文件
        · 「全部删除」→ 弹「是/否」确认后，把清单里的全删掉
        · 「刷新」→ 重新读一次清单
     三个按钮的外观和设置窗口自己的「保存」按钮一致。
     删除范围只限清单里的文件：同步时会把收到的路径记在
     Resources\MoLanSyncedMaps.txt 里，清理就按这份清单删；
     你自己放进去的地图、MO 本体带的地图，一个都不会动。
     删地图文件时会同时清掉 INI\MentalOmegaMaps.ini 里这张图的注册段和
     [MultiMaps] 登记行，以及因为同步而建出来的空目录。
     注意：**地图列表要重启客户端后才更新**（客户端启动时就把地图读进内存了）。
     没有同步过任何地图时，列表里显示「（还没有同步接收过地图）」。
  8. 聊天增强
     `/w 名字 内容` 私聊、`/r 内容` 回复上一条私聊、`/me 动作`、`/room` 看房间信息；
     快捷语 `/gg /gl /hf /afk /brb /wait /1 /2 /3`。
  9. 快捷语面板
     大厅底部的「快捷语」按钮，选中一条点「发送」，不用记命令。
     游戏根目录如果有 MOExperience.ini，会自动合并里面 `[MsgText] QuickText`
     的预设（只读文本，不读代码）。
  10. 房间公告与小游戏
     房主用 `/motd 内容` 设置公告，之后每个新进房的人会自动私聊收到一次；
     `/motd -` 清除。小游戏：`/dice [面数]`、`/coin`、`/rps 石头|剪刀|布`、
     `/8ball 问题`，结果房间所有人都能看到。
  11. 对局记录
     每局开局 6 秒后把 spawn.ini 复制到 `对局记录\时间_地图.ini`，
     并在 `对局记录\index.txt` 追加一行（时间 / 地图 / 模式 / 玩家）；
     大厅聊天同时留档到 `对局记录\聊天_日期.txt`。
     设置页的「对局记录」按钮直接打开这个目录。
  12. 主页精简
     推特 / 油管 / 脸书 / Discord 四个图标、左下角更新状态、
     以及「制作人员」（点进去是 mentalomega.com 官网地址）都关掉了；
     关于窗口里的 ModDB / 论坛 / CnCNet 链接也一并隐藏。
     另外主菜单右上角那个 24×24 的「附加」小方块（点开只有一个「返回」，
     MO 里 Extras 全是关的，纯占位）也关掉了。
  13. 主页布局
     设置 →「联机补丁」→ 右列「主页布局：xxx」，点一下切换一种：
     左侧竖排 / 底部横排 / 居中竖排 / 右侧竖排，立即生效并记住。

七、主题与壁纸（美化）
  设置窗口 →「联机补丁」页 → 右列底部「主题与壁纸…」：
    · 列表里是 Resources\MoThemes 下的主题，显示主色和内容
    · 选一个点「应用」：按游戏原背景的尺寸，把主题里的 bg.png / bg.jpg
      居中裁切生成全套 9 张背景（大厅、在线大厅、设置、快捷键、载入、
      战役选择、campsite×2、主菜单）。首次应用会先把原图备份到
      Resources\MoThemes\_原图备份\，「还原默认」就是把原图拷回去
    · 「打开目录」直达 Resources\MoThemes
    · 点「应用」后会**热加载**：直接改写已载入的贴图，不用重启客户端；
      极少数还没进过的界面会在第一次进入时用新图
  壁纸按原尺寸居中裁切后**原样铺满**，不压暗、不去饱和、不加暗角。
  按钮改成玻璃拟态：半透明主题色渐变 + 圆角 + 高光边，悬停时变亮。
  8 种通用按钮（普通 + 悬停）直接生成；主菜单的文字按钮保留原图里
  烘焙的白字，只换背景。全部跟随主题主色，「还原默认」一起还原。
  不用手动点「应用」：更新后第一次进主菜单会自动生成并热加载；
  点过「还原默认」之后就不再自动套用（直到你再应用一次主题）。
  下拉框箭头、滚动条（滑块+两端箭头+底槽）、复选框、滑杆按钮、
  筛选/排序图标也会一起换色。
  自己做主题：在 Resources\MoThemes 下建一个文件夹（名字随意），
  放一张 bg.png 或 bg.jpg 即可；想单独指定某张背景，就按原名放
  （gamelobbybg.png / optionsbg.png / MainMenu\mainmenubg.png 等）。
  本包附带 8 套主题，主色由程序从壁纸里提取，写在各自的 theme.ini
  （Accent / Dark / Light / Text）；状态条平时显示的颜色就取自 Text。
  用了整套主题时，单张 Resources\MoLobbyBg.png 的替换会自动跳过。

  在 HMOL 里换壁纸（推荐）：
    HMOL → 设置 →「高级」→「游戏壁纸」，选 HMOL 壁纸库里的壁纸，
    或者直接挑本地图片 / 视频 / 动图，点「应用为游戏壁纸」。
    HMOL 会写出一个 HMOL-<壁纸名> 主题（bg.png + 自动提取的两种颜色 + 动图源），
    并把它设成当前主题；下次启动客户端时补丁会自己套用一整套背景、
    玻璃按钮和控件配色，不需要再进设置点「应用」。
    没装这个补丁的游戏实例，该页只显示「敬请期待」。
    HMOL 里导入新的壁纸/壁纸包后，这个列表会自动刷新，不用退出设置页。

  动态壁纸（GIF / 视频）：
    · 只有主菜单播放视频；局域网大厅（房间列表）和房间内改成纯色（自动取主题色：Dark，没有就压暗主色）
    · 视频走 Media Foundation 硬解（NV12），4K 实测约 25fps；
      配置一般的机器建议用 1080p 视频，能跑满 30fps
    · 动图按 GIF 自己的帧间隔播放
    · 画面按「实际显示区域」等比裁切铺满，不会拉伸变形
    · 视频只是引用原文件（不复制）：源文件被移动/删除，会自动退回静态壁纸，
      MoLanRelay.log 里会写一行原因
    · 壁纸包里 254×254 的 preview.gif 只是缩略图，别当壁纸用，会糊

八、怎么还原
  用第一步备份的原文件覆盖回去，再删掉这两个文件：
      Resources\MoLanRelay.dll
      Resources\Binaries\MoLanRelay.dll
  主题：在「主题与壁纸」里点「还原默认」，或把 Resources\MoThemes\_原图备份\
  里的图片按原路径拷回去；不想要主题包可以直接删掉 Resources\MoThemes
  （先还原，不然背景会停在最后一套主题上）。
  （可选）再删掉同步清单 Resources\MoLanSyncedMaps.txt ——不删也不影响游戏。

九、注意
  · 参与联机的每一台机器都要用同一个包。主菜单右下角对一下 Patch 版本
    （`Patch v0.16.2`），MoLanRelay.log 第一行也会写同一个号。
    只换 DLL 不换 exe（或反过来）会出现「客机回的信房主收不到」这类怪问题。
  · 开赛前 3 秒检查需要从新版 HMOL 启动游戏才能核对；直接双击客户端时，
    主菜单会显示 `HMOL not running`，开局前同样会弹「没法核对」的确认框。
  · 检查发现双方不一致、或根本没法核对时，都会停下来弹「是/否」确认框：
    选「是」才继续开始，选「否」停在局域网大厅（差异会列在聊天区）。

    许可原文见本包 LICENSE / LICENSE-CnCNet-Client.md。
