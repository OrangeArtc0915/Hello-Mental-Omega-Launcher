================================================================
 Mental Omega 补丁 2／联机（局域网修复 + 樱花 Frp 直连）
 适用版本：MO 客户端 2.6.10.3（Resources\clientdx.exe 那一套）
================================================================

【这个包修什么】
 · 局域网大厅：解锁「队伍 A/B/C/D」选择
 · 局域网：修加入者开战后崩溃（spawn.ini 队伍索引越界）
 · 局域网：修 "The client is already connected!" 崩溃
 · 局域网：补齐「加入时裁掉超过 8 人的 AI」
 · 局域网大厅底部新增「地址输入框」—— 粘 IP:端口 回车直连（给樱花 Frp 用）
 · 樱花 Frp：新增「游戏内 UDP 中继」，让只开一条 TCP 隧道也能真正开打
 · 局域网：修「退出大厅重新建房后，收到残留连接发来的旧消息就崩溃」
   （KABOOOOOOOM → 调用的目标发生了异常。 → 未将对象引用设置到对象的实例。）
   这是上游 CnCNet 局域网大厅本来就有的漏判空（在线大厅同一处有判空，只有局域网漏了），
   原版客户端也会崩，本补丁补上了这个判断。
 · 局域网：让「踢人」真正生效
   （玩家名字下拉框里选「踢出」以前"点了没反应" —— 在线大厅重写了 KickPlayer，
     局域网大厅用的是基类空实现。本补丁补上了局域网的实现：房主点踢出后，
     该玩家会被断开并退回局域网大厅，其余人界面上的玩家列表会自动更新。）
 · 局域网：@ 功能
   聊天里写「@某人」（如 @mmm），被 @ 的人会看到那条消息变金色 + 听到提示音。
 · 局域网：截图（**暂时停用**）
   上一版是按 F8 弹一个小窗口显示缩略图，会抢走客户端焦点导致看起来"卡死/没鼠标"，
   所以先撤掉了。正在改成**像聊天软件那样直接显示在聊天区里**，做完再放出来。
 · 局域网：语音聊天
   在局域网大厅里**按住 F7** 说话（松开即停），房间里所有人都能听到。
   8kHz/16bit 单声道，约 16KB/s，局域网带宽压力很小。
   没麦克风的机器也能**听**别人说话；声卡整个不可用时会自动静默停用语音
   （日志里会写原因），不影响其他功能。

 · 中继版本自检
   进大厅后每 15 秒广播一次自己的中继版本；发现有人版本不一致，会红字 + 聊天区提醒
   （就是"有人能收不能发 / 不读条"那类问题的根因）。
 · 游戏文件一致性提示
   房主那边一旦发现某人的游戏文件哈希和自己不一样，会红字 + 聊天区提示双方哈希，
   并提醒核对 MO 版本与补丁 —— 不再是原来那句含糊的"他可能在作弊"。

【热键（局域网大厅里、以及游戏内都能用；只要前台窗口是客户端或游戏本体）】
   F7（按住）   语音说话
   F6          把剪贴板内容当聊天发出去 —— HMOL 复制的 IP:端口 直接就能发到房间里
   F5          发一条「大厅 + 中继」体检报告到聊天区（省得再去翻 MoLanRelay.log）

================================================================
 一、为什么需要「游戏内 UDP 中继」
================================================================

原版局域网：大厅靠 UDP 广播发现，加入靠 TCP 1233 握手，
**进游戏后靠 UDP 1234 点对点互发数据**。
樱花 Frp 只把 TCP 1233 映射出来，所以：
    能进大厅、能看到玩家列表，但**一点开始就卡在同步／不读条**。

本补丁把 gamemd 发出的 UDP 包**封进大厅已有的那条 TCP 连接**里转发（不新增隧道、
不新增端口），对端解包后再注入它本机的 gamemd：

    gamemd ─UDP→ 127.0.0.1:1234x ─┐
                                 │ 封成 MO-RELAY 帧
    大厅聊天/选项 ────────────────┴─→【同一条 TCP 连接】─→ 隧道(1233) ─→ 房主
                                                                        │
                       房主按目标分发（2 人直接转发；3 人以上经房主中转）
                                                                        ↓
    对端中继 ─解帧→ 从 1234x 注入 ─UDP→ 对端 gamemd:1234

安装后无需任何设置，开打时自动生效。
**参与联机的每一台机器都必须装过本补丁，且版本号要一致。**


【怎么确认它在工作】
 游戏根目录会生成 `MoLanRelay.log`，正常应该看到：

    ======== MoLanRelay v2026-10-04.4 ========      ← 几台机器这一行必须一模一样
    载入的 DLL: D:\...\Resources\MoLanRelay.dll
    register host client: connected / 127.0.0.1:xxxxx
    start: self=<你的名字> host=True/False (byOrder=.. byConn=..) 玩家数=N 本机端口表=[名字→端口]
    peer[1] <对端名字> listening 127.0.0.1:12341
    stats: 本机游戏发出的包=.. 已注入本机游戏=.. 已发出帧=.. 已转发帧=.. 已收到帧=.. | 分对端: 名字(收X/注Y)

 判断标准：两边的 `已发出帧` 和 `已收到帧` 都持续上涨（差距在个别包以内）= 通了。
 出问题时把这个日志发出来即可定位。

 ⚠️ 排错第一步永远是看第一行版本号：只要有一台是旧版，就会莫名其妙地
    「它发的帧对面收不到」，直接表现为不读条。版本不一致就重新覆盖本包
    （两个 MoLanRelay.dll 位置都要换）：
        Resources\MoLanRelay.dll
        Resources\Binaries\MoLanRelay.dll

 ⚠️ 已知代价：这是**用 TCP 承载 UDP**，网络抖动时**可能卡顿**（TCP 有队头阻塞，
    而 RA2 锁步对延迟敏感）。这是方案固有代价，不是 bug。
    **想要手感最好，请用虚拟局域网方案（EasyTier / n2n）** —— 那是 UDP 承载，本补丁不参与。


================================================================
 二、局域网大厅新增的「直连」输入框
================================================================

【界面在哪】
 进局域网大厅后，看窗口**底部那一排**，靠右（「返回主菜单」左边）多了一个输入框：

     [创建房间] [加入游戏]  ......  [ 输入 地址:端口 后回车直连 ]  ...  [返回主菜单]

【怎么用】
   1. 点一下输入框
   2. 填 地址:端口（樱花 Frp 复制出来的 IP:端口 直接 Ctrl+V 粘贴即可）
   3. 按回车 → 立刻尝试连过去

   容错：支持 Ctrl+V 粘贴；中文冒号「：」也能认；粘贴内容带前后缀
        （如 "服务器: 1.2.3.4:1234"）也能认出地址；只填 IP 不填端口 → 默认 1233；
        地址不合法 → 聊天区提示格式并清空输入框；只支持 IPv4 字面量，不支持域名。


================================================================
 三、怎么还原
================================================================
"原版备份" 文件夹里是改动之前的一整套原版文件，目录结构和游戏根目录一致：
   原版备份\Resources\...  →  游戏根目录\Resources\...
需要回退时，把里面的 Resources 覆盖回游戏根目录即可
（也可以顺手删掉 Resources\MoLanRelay.dll 与 Resources\Binaries\MoLanRelay.dll）。


================================================================
 四、注意事项
================================================================
· gamemd.exe / Syringe.exe 仍保留「以管理员身份运行」（原安装自带），
  开打时可能弹一次 UAC，点「是」即可。
· 中继会占用本机 127.0.0.1 的 12341~12348 端口（UDP，仅回环，8 人上限）。
· 如果客户端自带的更新器之后把 Resources 里的文件重新下载覆盖了，
  重新把本包覆盖一次即可（包括两个 MoLanRelay.dll）。
· 本包**不含**中文输入修复，那部分在「补丁 1／中文输入」里，两个包互不冲突。
