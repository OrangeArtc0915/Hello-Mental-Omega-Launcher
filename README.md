## ✨ 主要特点

### 🎯 ：多实例管理
- **独立实例管理**：可以创建多个游戏实例，每个实例拥有独立的MOD包和设置
- **一键切换**：轻松在不同游戏配置之间切换，满足不同的游戏需求
- **完全隔离**：每个实例的包、设置、备份都完全独立，互不干扰
- **智能命名**：导入实例时可自由命名，方便识别和管理

### 📦 全面的包管理支持
- **INI包**：INI文件管理
- **地图包**：自定义地图安装和管理
- **任务包**：任务模组一键安装
- **语音包**：语音文件管理
- **插件包**：各种插件支持
- **美化包**：界面和视觉效果优化
- **音乐包**：背景音乐管理

### 🛠️ 实用工具
- **一键备份**：安全备份游戏文件
- **快速恢复**：快速恢复游戏到备份状态
- **游戏启动**：直接启动心灵终结游戏

## ❓ 常见问题

### Q1: 路径检测失败怎么办？
**A1:**
- 确认选择的文件夹是心灵终结的根目录
- 尝试重新安装心灵终结到另一个位置

### Q2: 如何正确安装MOD包？
**A2:**
- 确保MOD包格式正确（.zip）
- 注意查看MOD说明，有些MOD有特殊安装要求
- 建议先备份游戏再安装新MOD

### Q3: 实例之间的数据会互相影响吗？
**A3:**
- 不会！每个实例的数据完全独立
- 包、设置、备份都存储在各自的目录中
- 可以放心创建多个实例

### Q5: 支持哪些游戏版本？
**A5:**
- 理论上支持心灵终结的所有版本
- 不同版本的兼容性可能略有差异

## 🔧 故障排除

### 启动问题
- **权限问题**：以管理员身份运行

### 功能问题
- **包安装失败**：检查文件格式和完整性

- **响应迟钝**：检查硬盘空间是否充足
