## 📖 使用指南

### 第一次使用

#### 1️⃣ 创建游戏实例
- 启动程序后，点击 **"➕ 添加"** 按钮
- 输入实例名称（建议使用描述性名称，如"我的标准版"、" PVP专用版"等）
- 选择心灵终结游戏文件夹
- 点击 **"✅ 添加实例"** 完成创建

#### 2️⃣ 设置游戏路径
- 在路径设置区域输入心灵终结的安装目录
- 或者点击 **"📂 浏览"** 按钮选择文件夹
- 点击 **"🔍 一键检测路径"** 验证路径有效性

#### 3️⃣ 开始使用
- 选择要使用的游戏实例
- 在包管理标签页中选择需要的MOD包类型
- 点击 **"📥 导入"** 添加本地文件，或 **"⬇️ 下载"** 访问在线资源
- 选择包后点击 **"🚀 安装"** 完成安装

### 🔧 实例管理

#### 创建多个实例
不同的实例可以用于：
- **不同游戏模式**：PVP模式、PVE模式、测试模式
- **不同版本**：稳定版、测试版、mod包合集
- **不同需求**：单人模式、多人联机、录像回放

#### 实例切换
- 在主界面顶部的实例选择框中切换
- 每次切换都会自动加载对应的设置和已安装的包

#### 实例操作
- **重命名**：右键实例管理窗口中的实例进行重命名
- **删除**：移除不需要的实例（不会影响游戏文件）
- **查看目录**：用资源管理器打开实例的数据目录

### 📦 包管理操作

#### 导入本地文件
1. 在对应的标签页中点击 **"📥 导入"**
2. 选择文件（支持.zip、.rar、.7z格式）
3. 等待导入完成

#### 在线下载
1. 在任意标签页点击 **"⬇️ 下载"**
2. 浏览器将打开下载页面
3. 下载后使用导入功能添加

#### 安装和卸载
- **安装**：选择包后点击 **"🚀 安装"**
- **卸载**：点击 **"🗑️ 卸载"** 移除已安装的包
- **查看已安装**：点击工具栏中的 **"📋 查看已安装"**

### 🛠️ 实用工具

#### 游戏控制
- **🚀 启动游戏**：直接启动心灵终结游戏
- **🧹 清理缓存**：清理游戏临时文件，提升性能
- **🔧 修复游戏**：检查并修复游戏文件

#### 备份管理

## ❓ 常见问题

### Q1: 路径检测失败怎么办？
**A1:**
- 确认选择的文件夹是心灵终结的根目录
- 检查文件夹中是否包含 `gamemd.exe` 或类似文件
- 尝试重新安装心灵终结到另一个位置

### Q2: 如何正确安装MOD包？
**A2:**
- 确保MOD包格式正确（.zip、.rar）
- 注意查看MOD说明，有些MOD有特殊安装要求
- 建议先备份游戏再安装新MOD

### Q3: 实例之间的数据会互相影响吗？
**A3:**
- 不会！每个实例的数据完全独立
- 包、设置、备份都存储在各自的目录中
- 可以放心创建多个实例

### Q4: 如何卸载程序？
**A4:**
- 直接删除程序文件即可
- 程序不会在系统中留下注册表项
- 实例数据存储在程序目录中，如需清理请手动删除

### Q5: 支持哪些游戏版本？
**A5:**
- 理论上支持心灵终结的所有版本
- 建议使用最新版本以获得最佳体验
- 不同版本的兼容性可能略有差异
