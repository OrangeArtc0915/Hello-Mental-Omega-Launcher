# Hello Mental Omega Launcher（HMOL）

面向《心灵终结》（Mental Omega）的 Windows 桌面启动器，基于 **C# / .NET 8 / WPF**，
以**自包含单文件** `HMOL.exe` 发行（无需另装 .NET 运行时）。

## 下载与运行

1. 到 [Releases](https://github.com/OrangeArtc0915/Hello-Mental-Omega-Launcher/releases) 下载 `HMOL-v1.2.0-win-x64.zip`。
2. **完整解压**到任意目录（绿色便携，不要只把 exe 拖出来，旁边需要 `runtime\`）。
3. 双击目录内的 `HMOL.exe` 启动。

`HMOL.exe` 已带**代码签名**（自签证书 `CN=mmm`，含 DigiCert 时间戳）。该证书由发布方自建、并非公共 CA
签发，因此没把证书装进本机「受信任的根证书颁发机构 / 受信任的发布者」的机器上，SmartScreen 仍可能拦
一次，点「更多信息 → 仍要运行」即可。

设置、实例、插件包与日志默认放在 exe 同目录的 `Data\`，可用环境变量 `HMOL_DATA` 重定向。

## 构建

前置：.NET SDK 8（缺失时 `ensure-dotnet-sdk.bat` 会自动下载）。

```bat
build.bat                :: 完整构建（含混淆与代码签名）
build.bat --skip-sign    :: 跳过签名（没有证书时用）
```

- 版本号的**唯一来源**是 [src/HMOL.Core/App/AppInfo.cs](src/HMOL.Core/App/AppInfo.cs)，由 `build.bat` 读出后传给 MSBuild，不在 csproj 里写死。
- 签名需要私钥 `签名\HMOL-mmm.pfx`，口令从环境变量 `HMOL_PFX_PASSWORD` 读；未设置时会交互询问，证书缺失或跳过签名只告警不中断。
- 产物在 `publish\`：`HMOL.exe` 与 `HMOL-v<版本>-win-x64.zip`。

## 联机适配（面向其他启动器作者）

这一节写给**想把 HMOL 的联机能力接进自己启动器**的人。旧版联机能力是一个独立 Python 插件包
（`HMOL联机模块`，PyInstaller 打包，v3.2.0），新版 HMOL 已把它重写进 C#（[src/HMOL.Core/Multiplayer](src/HMOL.Core/Multiplayer)）。
两边互通的关键不是内部代码，而是**组网分享文本**这一个纯文本协议。

### 组网分享文本

房主点「分享给队友」生成一段文本，队友把它粘进「联机 → 组网」页的「一键加入」即可自动填好参数并入房。
格式（`\n` 分行，标签与值用**英文冒号**分隔）：

```
HMOL联机模块 组网分享
版本: 1.2.0
方案: EasyTier
节点: udp://39.108.52.138:11010
房间名: ABC123
密钥: (无)
房主: 否
IP: 自动
官方QQ群：
    1群：1034243331
从其他渠道下载的资源我们无法保障其安全性！
```

- **第 1 行是固定首行** `HMOL联机模块 组网分享`，用于识别文本类型。
- `版本` 行可省略；`房间名` 与 `节点` 是**必需字段**，缺任一个则视为无效分享文本。
- `方案`：`EasyTier` 或 `n2n`。旧版还会写 `ZeroTier` / `Anywherelan`，新客户端已裁剪这两个引擎，解析时**一律回落到 EasyTier**。
- `密钥`：无密钥写 `(无)`（旧版也出现过 `(可选)`），解析时空值等价于空字符串。
- `房主`：生成时固定写 `否`，表示「通过这段文本加入的人是成员而不是房主」。
- `IP`：`自动` 或 `手动:<虚拟IP>`。
- 末尾两行是官方 QQ 群与安全提示，解析时忽略。

权威实现在 [ShareCode.cs](src/HMOL.Core/Multiplayer/ShareCode.cs)（`Build` / `Parse`），对应旧版
`share.py` 的 `build_share_text` / `parse_share_text`。

### 解析时的两个坑

1. **不要用 `房主` 字段判断谁当房主。** 旧版解析逻辑是 `v != '是'`，因此文本里写「房主: 否」解析出来反而是 `true`；
   旧版 `_apply_share` 也是无视该字段、一律按成员加入，新客户端同样应**一律按成员加入**。
2. **标签名兼容**：旧版用过 `小组:` 标签，新客户端按 `房间名` 与 `小组` 两者都认；旧版还有缺少版本行的文本。

### 组网方案与默认参数

| 方案 | 层 | 服务器依赖 | 额外安装 | 默认节点 / 网段 |
| --- | --- | --- | --- | --- |
| **EasyTier**（默认，推荐） | 三层 | 公共节点 | 无 | `udp://39.108.52.138:11010`，虚拟网段 `10.0.0.x` |
| **n2n** | 二层 | 公共 / 自建 supernode | TAP 虚拟网卡驱动 | `n2n.aobacore.com:9555`，网段 `192.168.100.0/24` |
| ZeroTier（旧版，已裁剪） | 三层 | ZeroTier 官方服务 | 无界面核心服务 | 网段 `172.24.1.0/24`，节点栏填 16 位 hex 网络 ID |
| Anywherelan（旧版，已裁剪） | 三层 | 无（完全去中心化） | 无 | 网段 `10.66.0.0/16`，节点栏填 Peer ID |

- EasyTier 默认节点历史上是 TCP 协议，因被防火墙拦截已迁移为同主机 UDP。
- n2n 的虚拟 IP 支持**自动**（supernode 地址池分配）与**手动**（如房主 `192.168.100.66`、队友 `.67`，需互不冲突）。
- 二楼层的 n2n 对老游戏的局域网广播发现更友好；EasyTier 免装驱动、开箱即用。

### 其他启动器怎么接

- **只做互通**：按上面的格式生成 / 解析分享文本即可与 HMOL 联机模块互换房间信息，不需要复刻内部实现。
  生成端注意首行、字段顺序与 `房主: 否`；解析端注意必需字段校验与旧标签兼容。
- 老版本的 Python 源码（含 `share.py`）已不在本仓库中，本仓库只跟踪 C# 实现；
  C# 实现的注释里保留了对应的旧版文件与行号引用，可直接对照。
