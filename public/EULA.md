## 1. 本软件是什么

**HMOL（Hello Mental Omega Launcher）** 是一款面向《心灵终结》（Mental Omega）玩家的第三方桌面启动器，使用 **C# / .NET 8（WPF）** 编写，以**自包含单文件 `HMOL.exe`** 的形式分发。

它在同一个程序里提供：游戏启动、游戏实例管理、资源包管理（INI / 地图 / 任务 / 插件四类）、备份还原、内置联机组网（EasyTier / n2n）、以及用 JSON 清单声明的扩展模块。
